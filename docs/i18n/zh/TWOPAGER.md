## 1. 问题 / 机会

收藏对战类游戏（宝可梦及其衍生作品）是一个庞大且持久的品类，但其中的生物是**脚本化**的。每场战斗都是已知量；“智能”只是一张属性表。与此同时，真正的 AI 智能体如今已能辩论、谋划、说服并即兴发挥。

**机会：** 将世界上最受欢迎的游戏循环（*收集、训练、战斗*）与真正会思考的生物结合，再用零秒即可理解的动词（**飞行**）作为产品门面。战斗将成为两个智能体之间的实时较量。每场比赛独一无二。每位冠军不可复制。攀升体验先于系统建立情感连接。

---

## 2. 产品形态

一个**飞行 → 认领 → 养育 → 战斗 → 继续攀升**的循环，每位冠军都是真实的 AI 智能体：

- **飞行**：在长拱库上方的天域中进行**飞行**（手机与桌面同一核心体验）。  
- **认领**：从每周轮换的初始池中挑选（每种力场一心），来源为初源心智与不断扩充的收藏图鉴。  
- **养育**：不直接选择招式，而是在领养时植入**策略**（进攻 / 专注 / 风险），再通过日常**印记**、人格塑造与大脑驱动方式来雕琢心智。性情仪表显示其变化趋势：仅供读取，不可自由拖拽。  
- **战斗**：将其送入由权威引擎裁决的实时对战（默认本地智能评判；可选 LLM 评判）。  
- **进化**：其身体与称号由职业生涯衍生而来：战斗*以及*你飞过的高度。表型 + 骨骼变形使同力场心智呈现不同物种外观。

## 4. 防御性

- **经典赛道的全新演绎**：会思考的生物使战斗非脚本化且永葆新鲜；飞行让产品在系统细节之前即可被理解。  
- **内置病毒传播**：飞行挑战分享、攀升榜单、收藏与羁绊卡（翼伴 + 上升）。战斗是深度，而非分享钩子。  
- **真实角色**：会辩论、谋划、胜负分明的冠军具备观赏性与模因潜力。  
- **自有 IP 护城河**：原创阵容、世界观、演化中的战斗元数据，以及（后续）用户自创冠军的创作者经济。护城河在于 IP 与元数据，而非引擎。

---

## 5. 风险与应对

- **美术与设计成本最高** → 先交付一种强力战斗类型与精简阵容，其余暂留占位；身体由职业生涯程序化生成，降低美术负担。  
- **公平裁决** → 客观胜负条件；默认本地评判；可选 LLM 评判保持有界倍增，避免说服机制破坏比赛。  
- **新奇感后的留存** → 进度系统、诚实排名、攀升精通，以及（路线图）赛季与交易。  
- **病毒游戏难以预测** → 押注*赛道、IP 与创作者经济*，而非单次上线。
