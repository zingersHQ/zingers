# 08 · 经济：王冠币与所有权底层

> **简述：** 游戏完全免费游玩。**王冠币** 是你在游戏内通过游玩赚取的货币。你永远无法购买或提现王冠币。底层可选接入加密代币，供收藏者使用，但它仅用于炫耀资格与访问权，绝不提供战力，也绝不兑现。两种货币永不互通。

核心规则：**无需任何链上持有或消费，游戏已完整且免费。** 加密层位于游戏之下，供有需求者选择，绝不成为门槛。玩家可以养成传奇、攀登赛季、收集图鉴、参与对决，却从未接触过钱包。

以下一切遵循同一设计律：**代币购买的是地位、访问权与持久性，绝不产生收益。** 没有质押年化收益，没有“质押即赚”，没有赢家拿走输家资金的奖池。打破这条律令，我们就成了证券与赌场；守住它，我们仍是独立游戏，附带可收藏的传奇层。

第二条纪律，来自圣典的典律规则：**我们不发明新的顶级名称。** 链上层复用世界已有的词语——**赛季**（编年史，[`06-seasons.md`](./06-seasons.md)）与**区域**（主题竞技场，[`05-regions.md`](./05-regions.md)）。而非铸造“纪元/世界”，以免与典律冲突。

---

## 两种经济，永不桥接

| | **王冠币** | **代币**（暂名 `$ZING`） |
|---|---|---|
| 性质 | 软性，游戏内 | 硬性，链上（Solana / SPL） |
| 获取方式 | *通过游玩* 赚取 | *在市场购买*，或因游玩空投 |
| 用途 | 训练、入场、支持、 cosmetic 重铸 | 链上排名入场、铸造卡牌、赞助者地位 |
| 现金价值 | 永无 | 市场价值（非我们的承诺） |
| 可提现？ | **永不** | 仅可在公开市场，绝不*通过我们* |

两种余额**永不相互兑换，也永不共享钱包。** 一旦王冠币可用代币购买，或代币可从王冠币赚取，我们就构建了资金传输与博彩货币的提现通道。两者之间的墙是本文档中唯一最重要的不变式。

实际而言：新玩家仅接触王冠币。大多数玩家永远不会触碰代币。代币是可选加入的收藏者/忠诚度层，面向忠实玩家。

---

## 王冠币（世界内货币，免费）

**王冠币** 是软通货，通过游玩赚取：

| 来源 | 奖励 |
|--------|--------|
| 赢得一场战斗 | 王冠币 + 经验 + 评分 |
| 按下连战 | 递增奖池，冒险机制（**连战** 是一系列连续战斗，奖励逐步攀升，但一次失败即结束） |
| 训练 | 消耗王冠币 → 经验 + 身体进化，朝向你的策略（你已设定的战斗风格） |
| 排名战（积分榜入场） | 消耗王冠币 → 一场对随机对手的计分榜战斗（无免费评分刷取） |
| 飞行里程碑（百战、初光） | 一次性奖池；百战是日常赚取上限之外的大型庆典奖池 |
| 每日/赛季目标 | 稳定细流 |

王冠币购买**训练、入场与 cosmetic 重铸**。这些会影响*你的*账号进度。它们是游戏货币：丰裕，永不出售，永不提现。来自飞行、竞技场、缓存与目标的可变赚取共享每日上限，使世界保持慷慨却不无限；里程碑奖池位于该上限之外，因此百战仍如巅峰。技艺榜名次是荣耀，不是王冠奖池——进步可以发奖，名次不行。

### “支持”，而非“下注”

在王冠币经济内，玩家动词是**支持**。你*支持*一位冠军获胜（竞技场/每日连胜、排名战场地赌注）。我们在 UI 与文案中全面弃用“下注”一词。“支持你的冠军”读作信念，而非赌博，且与代币层使用同一动词（你*支持*一位冠军一个赛季）。底层机制不变；仅语言改变。

## 代币（`$ZING`，暂名）

游戏之下存在一项硬资产。它仅做三件事，且无任何类似投资回报的表现：

1. **支付链上榜单入场费**。通过少量燃烧或更多质押（见下）。
2. **铸造持久性**。燃烧以将冠军永生化为链上卡牌。
3. **授予地位**。赞助者纹章、图鉴出处、下一赛季分配权重。

供应量通过构造通缩：每次入场燃烧与每次铸造燃烧均移除代币，而质押入场则将流通量锁定一整个赛季。我们可能为空投预留一笔 treasury，但绝不将其作为收益支付。

---

## 链上排名（代币所守之门）

免费游戏已在**赛季**时钟上运行：赛季即拱库开启又一扇门。生成式、带种子，伴随*软*排名重置，因此你始终可将姓名带入下一季（[`06-seasons.md`](./06-seasons.md)）。**该免费赛季不受影响，对所有人保持免费。**

代币守住**可选加入的链上排名，运行于同一赛季时钟。** 进入它是代币为游玩所解锁的唯一功能；战役、王冠币排名、图鉴与每日仍无需钱包。链上排名：

- **按赛季运行**。赛季开启时开放，赛季转换时**链上关闭**（铸造结算、纹章授予、下一赛季空投权重统计）。铸造卡牌会打上永生化所在赛季的戳记。
- **按区域限定（可选，后续）**。区域已是带有力场偏好的主题竞技场（[`05-regions.md`](./05-regions.md)）。成熟版本可按**区域**定价入场，因此玩家可选择要争夺的竞技场。V1 保持为**单一赛季范围排名**；区域限定是经证明循环后的扩展，而非上线内容。

> **v1 范围：** 单一赛季范围链上排名，采用燃烧或质押入场，并链上关闭。按区域榜单在循环证明价值后推出。勿在循环证明前构建分类法。

## 入场：燃烧或质押

进入赛季链上排名有一项价格，可通过两种方式支付。*选择* 会自我分层玩家，且两种路径均减少流通供应。

| 路径 | 成本 | 结果 | 谁选择 |
|------|------|---------|--------------|
| **燃烧** | 少量（`N`） | 代币永久销毁 | 休闲/单赛季玩家 |
| **质押** | 较大（`约 5–10·N`） | 锁定至赛季结束，**全额返还** | 忠实/复购玩家 |

- **燃烧** 是消耗性访问费。是一次*购买*，而非赌注。纯通缩；自然滋养“买即烧”叙事。
- **质押** 是**可退还的入场押金**。本金在赛季结束时完整返还，且**无额外代币**。唯一“成本”是流动性冻结（资本为赛季锁定）。质押者临时移除流通量；燃烧者永久移除。

单赛季玩家更适合燃烧 `N`。复购玩家更适合一次质押。这导向忠诚循环。

### 忠诚循环：保持质押，跳过燃烧

质押在赛季间**持久**：

- 质押一次 → 你自动进入所有后续赛季，**无需燃烧**，只要保持锁定。
- **仅允许在赛季边界解除质押**（锁定运行至当前赛季结束）。撤出后，你需重新燃烧以进入。

净效应：忠诚玩家无限期锁定资本并永久免费游玩（不断增长、永久锁定的**供应地板**）；休闲流失支付**燃烧**。两者均通缩。两者均非收益。这与软排名重置呼应：你赛季间保留地位，如今也可保留*席位*。

## 赛季关闭：质押的*目的*

赛季转换时，战斗在公平种子规则下结算，链上排名关闭。**所有奖励均非金融性。** 质押者取回本金*加*地位；无人获得多于投入的代币。

- **铸造即永生化。** 顶级冠军（及任何选择加入的拥有者）**燃烧代币以铸造**其冠军为永久链上卡牌。艺术从生涯记录确定性生成，因此*代币即战绩*。这填充了每张卡牌已存在的惰性出处字段：谁拥有、何时铸造、哪个赛季打戳。
- **赞助者纹章。** 若你**支持**（质押于后）一位冠军一个赛季，你将在其卡牌上获得 cosmetic **纹章**，你的 handle 记录于其赞助者中。权重依冠军排名。但奖励是*荣耀*，而非 payout。
- **空投权重。** 参与度（评分攀升、观战、每日连胜、王冠币赚取、赛季质押）决定你对下一笔 seeded treasury 空投的**分配权重**。因此代币*通过游玩赚取*，而非售入。

因此一个赛季可读作：*在王冠币中游玩整个赛季 → 赛季链上转换 → 赞助者获得纹章 → 顶级冠军铸造为永久卡牌 → 入场燃烧与铸造燃烧收紧供应 → 下一赛季空投奖励到场玩家。* 加密是奖杯柜，而非老虎机。

## 设计约束（以便干净接入）

- **墙壁稳固。** 王冠币与代币永不兑换，也永不共享余额。
- **出处已命名。** 卡牌已携带铸造 id、拥有者、链与铸造赛季字段。添加链是*填充*，而非重写。纹章落地时添加赞助者列表。
- **区域，而非新世界。** 按竞技场限定复用典律区域，而非发明平行容器。
- **绝不出售任何影响游戏的战力。** 代币与所有权购买出处、入场、纹章与 cosmetic。绝不购买属性，绝不购买胜利。付费即拥有，而非付费即胜利。
- **确定性是先决条件。** 链上赛季关闭仅因战斗可证明公平（带种子、确定性）而成立。守护此不变式为神圣。

## 监管护栏（独立安全边界）

我们精简上线，但有意停留在此边界内：

- **无收益。** 质押仅返还*本金*。绝不“质押以赚更多代币”，绝无年化收益，绝无他人燃烧的分成。这是可退还押金与未注册证券/彩票之间的界线。
- **燃烧是费用，而非赌注。** 你燃烧以*访问*排名，且“获胜”无以代币计价的货币奖品。
- **奖励为 cosmetic/地位/分配**。纹章、铸造、图鉴出处、空投权重。非现金，非按表现缩放的代币 payout。
- **不营销价格。** 我们谈论传奇、赛季与收藏。绝不“数字上涨”，绝不回报。
- **王冠币永不提现。** 软经济与任何具市场价值之物保持隔离。

停留在此边界内，代币即为具通缩汇的实用/收藏品。这是未注册独立上线可得的最低压力姿态。（仅当我们添加以代币计价的*奖品*时才需 Geo/KYC 与法律包装。本设计刻意回避。）

## 开放问题（构建前待定）

- **代币名称与代码。** `$ZING` 为占位符。符合 lore 的候选：与 relic/ember/sigil 相邻。（注：“王冠币”已被软通货占用。避免冲突。）
- **入场数值。** 具体的 `N`（燃烧）与质押倍数（`5–10·N`），需依预期代币价格调校，使两种路径均非显而易见。
- **赛季范围 vs 按区域入场。** 区域到来时，一次质押覆盖所有区域，还是按区域定价入场？
- **铸造资格。** 仅限 Top-N，还是任何选择加入者？铸造成本（燃烧量）？
- **赞助者上限。** 一位冠军可有多少赞助者支持；纹章层级如何随排名缩放。
- **空投公式。** 游玩信号 → 分配的确切权重。
- **链/标准。** 铸造卡牌的链与卡牌标准；铸造是否自第一天起可交易。
