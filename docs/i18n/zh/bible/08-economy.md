# 08 · 经济：王冠币与底层所有权

> **简述：** 游戏完全免费游玩。**王冠币** 是通过游玩赚取的游戏内货币。你永远无法购买或提现它。下方可选的加密代币仅供收藏者使用，它只购买吹嘘权与准入权，而不购买力量，也不会产生收益。两种货币永不互通。

核心规则：**无需花费或链上持有任何物品，游戏即可完整体验。** 加密层位于游戏之下，供有需求者使用，绝非前置门槛。玩家可以培养传奇、攀登赛季、收集图鉴、破解拱库，却从未接触过钱包。

以下所有内容都遵循一条设计法则：**代币仅购买地位、准入与持久性，绝不产生收益。** 没有质押 APY，没有“质押即赚”，没有赢家拿走输家资金的奖池。打破此法则，我们就成了证券与赌场；遵守它，我们就仍是带收藏传奇层的独立游戏。

第二条纪律来自圣典规则：**我们不发明新的顶级名称。** 链上层复用世界已有的词汇——**赛季**（编年史，参见 [`06-seasons.md`](./06-seasons.md)）与**区域**（主题竞技场，参见 [`05-regions.md`](./05-regions.md)）。我们不会铸造“纪元/世界”这类会与圣典冲突的词。

---

## 两种经济，永不桥接

| | **王冠币** | **代币**（暂名 `$ZING`） |
|---|---|---|
| 性质 | 软性，游戏内 | 硬性，链上（Solana / SPL） |
| 获取方式 | *通过游玩赚取* | *在市场购买，或因游玩空投* |
| 用途 | 训练、入场、支持、装饰重铸 | 链上排名入场、铸造卡牌、赞助者地位 |
| 现金价值 | 永无 | 市场价值（非我们承诺） |
| 可提现？ | **永不** | 仅可在公开市场提现，绝不*通过我们* |

两种余额**永不互相兑换，也永不共用钱包。** 一旦王冠币可用代币购买，或代币可由王冠币赚取，我们就构建了资金传输与博彩货币的提现通道。两者之间的墙是本文档中最重要的不变式。

实际体验：新玩家仅接触王冠币。大多数玩家永远不会触碰代币。代币是面向忠实玩家的可选收藏/忠诚层。

---

## 王冠币（世界内免费货币）

**王冠币** 是通过游玩赚取的软货币：

| 来源 | 奖励 |
|------|------|
| 赢得战斗 | 王冠币 + 经验 + 积分 |
| 按下连战 | 递增奖池，冒险机制（**连战** 是一系列连续战斗，奖励随次数攀升，但一次失败即结束） |
| 训练 | 消耗王冠币 → 经验 + 身体进化，朝向你设定的策略（战斗风格） |
| 排名战（入场） | 消耗王冠币 → 榜上一场有评级的对战（`RANK_FIGHT_COST`；不可免费刷分） |
| 每日/赛季目标 | 稳定 trickle |

王冠币购买**训练、入场与装饰重铸**。这些仅影响*你*账号的进度。它们是游戏货币：充裕、永不售卖、永不提现。（规范数值位于 `lib/economy.ts`；服务端持有余额，客户端镜像之。`/standings` 的排名战是**入场**消耗。）

### “支持”，而非“下注”

在王冠币经济中，玩家动词是**支持**。你*支持*一位冠军获胜（竞技场/每日连胜、排位战场赌注）。我们在 UI 与文案中全面弃用“下注”一词。“支持你的冠军”读作信念，而非赌博；代币层也使用同一动词（你*支持*一位冠军一个赛季）。底层机制不变，仅语言调整。

---

## 代币（`$ZING`，暂名）

游戏下方存在一种硬资产。它仅做三件事，且绝不呈现任何投资回报：

1. **支付链上排行榜入场费**。通过少量燃烧或更多质押（见下）。
2. **铸造持久性**。燃烧以将冠军永生化为链上卡牌。
3. **赋予地位**。赞助者纹章、图鉴出处、下一赛季空投权重。

供应量在设计上通缩：每次入场燃烧与每次铸造燃烧都会移除代币，而质押入场会将流通量锁定一整个赛季。我们可能预留一笔国库资金用于空投，但绝不将其作为收益支付。

---

## 链上排名（代币所控制的）

免费游戏已在**赛季**时钟上运行：赛季即拱库再开一扇门。生成式、带种子、*软性*排名重置，因此你始终能将名字带入下一赛季（[`06-seasons.md`](./06-seasons.md)）。**该免费赛季不受影响，对所有人保持免费。**

代币控制一个**与同一赛季时钟同步的可选链上排名**。进入它是代币唯一解锁的游玩功能；战役、王冠币排名、图鉴与每日仍无需钱包。链上排名：

- **按赛季运行**。赛季开启时开放，赛季转换时**链上关闭**（铸造结算、纹章颁发、下一赛季空投权重统计）。复用 `mintedSeason` 出处，因此铸造卡牌会打上其永生化所处的赛季戳记。
- **按区域限定（可选，后续）**。区域已是带力场偏好的主题竞技场（[`05-regions.md`](./05-regions.md)），通过 `/api/battle` 以 `regionBias` 接入。成熟版本可按**区域**定价入场，让玩家选择要争夺的竞技场。V1 保持**单一赛季范围排名**；区域限定是经证实的循环扩展，而非首发内容。

> **v1 范围：** 单一赛季范围链上排名，采用燃烧或质押入场，并链上关闭。区域排行榜将在循环证明价值后推出。不要在循环验证前构建分类法。

## 入场：燃烧或质押

进入赛季链上排名只有一种价格，可用两种方式支付。*选择* 本身会自我分层玩家，且两种路径均会减少流通供应。

| 路径 | 成本 | 结果 | 谁选择 |
|------|------|------|--------|
| **燃烧** | 小额 (`N`) | 代币永久销毁 | 休闲/单赛季玩家 |
| **质押** | 较大 (`~5–10·N`) | 锁定至赛季结束，**全额返还** | 忠实/复购玩家 |

- **燃烧** 是一种消耗性准入费。是一次*购买*，而非下注。纯通缩；自然契合“买即烧”叙事。
- **质押** 是一种**可退还入场押金**。本金在赛季结束时完整返还，且**无额外代币**。唯一“成本”是流动性锁定（资金被锁定一个赛季）。质押者暂时移除流通量；燃烧者永久移除之。

单赛季玩家更适合燃烧 `N`。复购玩家更适合质押一次。这就形成了忠诚循环。

### 忠诚循环：保持质押，跳过燃烧

质押在赛季间**持久存在**：

- 质押一次 → 你将自动进入所有后续赛季，**无需燃烧**，只要保持锁定状态。
- **仅允许在赛季边界解除质押**（锁定期至当前赛季结束）。取出后，你将回到通过燃烧重新进入的状态。

净效果：忠诚玩家无限期锁定资金并永久免费游玩（形成不断增长、永久锁定的**供应下限**）；休闲流失玩家支付**燃烧**。两者均通缩。均不产生收益。这与软性排名重置相呼应：你赛季间保留排名，现在也能保留*席位*。

## 赛季结束：质押的*目的*

当赛季转换时（确定性。战斗通过带种子的 RNG 实现可证明公平，`lib/engine/xai.ts:makeRng`），链上排名结算。**所有奖励均非金融性。** 质押者取回本金*加*地位；无人获得超出投入的代币。

- **铸造永生化。** 顶尖冠军（及任何选择加入的持有者）**燃烧代币以铸造**其冠军为永久链上卡牌。美术从生涯记录确定性生成，因此*代币即战绩*。这填充了已存在的惰性出处字段。`mintId`、`owner`、`chain`、`mintedSeason` 于 `CardProvenance`（`lib/cards/card.ts`）。无需修改 schema。
- **赞助者纹章。** 若你**支持**（质押于其后）一位冠军一个赛季，你将在其卡牌上获得装饰性**纹章**，你的句柄/钱包将被记录在卡牌的出处/赞助者列表中。权重依冠军名次而定。但奖励是*荣耀*，而非收益。
- **空投权重。** 参与度（积分攀升、观战、每日连胜、王冠币赚取、赛季质押）决定你下一轮空投的**分配权重**，空投来自预留国库。因此代币是*通过游玩赚取*，而非售卖获得。

因此一个赛季的流程为：*在王冠币中游玩整个赛季 → 赛季链上转换 → 赞助者获得纹章 → 顶尖冠军铸造为永久卡牌 → 入场燃烧与铸造燃烧收紧供应 → 下一赛季空投奖励到场玩家。* 加密是奖杯柜，而非老虎机。

## 设计约束（确保无缝接入）

- **墙保持完整。** 王冠币与代币永不兑换，也永不共用余额（`lib/economy.ts` 保持无代币；代币存在于其独立模块/合约）。
- **出处已接线。** `CardProvenance` 从第一天起就携带惰性 `mintId`、`owner`、`chain`、`mintedSeason`。加入链是*填充*，而非重构。纹章上线时添加赞助者列表字段。
- **区域，而非新世界。** 按竞技场限定复用 `regionBias` 与规范区域，而非发明平行容器。
- **绝不售卖影响游戏的力量。** 代币与所有权购买出处、入场、纹章与装饰。绝不购买属性，绝不购买胜利。付费即拥有，而非付费即胜利。
- **确定性是先决条件。** 链上赛季结束仅因战斗可证明公平（带种子、确定性 RNG）才成立。保持此不变式神圣。

## 监管护栏（独立安全边界）

我们精简启动，但有意保持在此边界内：

- **无收益。** 质押仅返还*本金*。绝不“质押赚更多代币”，绝无 APY，绝无他人燃烧的分成。这是可退还押金与未注册证券/彩票之间的界线。
- **燃烧是费用，而非下注。** 你燃烧以*进入*排名，且“获胜”没有以代币计价的货币奖品。
- **奖励为装饰/地位/分配。** 纹章、铸造、图鉴出处、空投权重。不是现金，不是按表现缩放的代币支付。
- **不营销价格。** 我们谈论传奇、赛季与收藏。绝不谈论“数字上涨”，绝不谈论回报。
- **王冠币永不提现。** 软经济与任何具市场价值的事物保持隔离。

保持在此边界内，代币即为带通缩汇点的实用/收藏品。这是非法人独立启动的最低压力姿态。（仅当我们添加以代币计价的*奖品*时才需要地理/KYC 与法律包装。本设计刻意避免此情况。）

## 开放问题（构建前需解决）

- **代币名称与代码。** `$ZING` 是占位符。符合圣典的候选：与遗物/余烬/徽记相关的词。（注意：“王冠币”已被软货币占用。避免冲突。）
- **入场数值。** 具体的 `N`（燃烧）与质押倍数（`5–10·N`），需根据预期代币价格调整，使两种路径均非显而易见的最优解。
- **赛季范围 vs 按区域入场。** 区域上线后，一次质押是否覆盖所有区域，还是按区域定价入场？
- **铸造资格。** 仅限前 N 名，还是任何选择加入者？铸造成本（燃烧量）？
- **赞助者上限。** 一位冠军可被多少赞助者支持；纹章层级如何随名次缩放。
- **空投公式。** 游玩信号 → 分配的确切权重。
- **链/标准。** SPL 代币 + 铸造卡牌采用哪种 NFT 标准（如 Metaplex）；铸造是否从第一天起即可交易。
