# 08 · 经济：王冠币，以及其下的所有权层

> **一句话：** 游戏完全免费。**王冠币**是你靠游玩赚取的货币，不能购买、不能兑现。
> 其下有可选代币，供收藏者**销毁以不朽化**冠军为链上卡牌。代币不买战力、不付收益。
> 两种货币永不互通。

首要规则：**不花链上资产、不持有链上物，游戏也完整可玩。** 加密是游戏之下的奖杯柜，
不是门前的闸。你可以养成、攀升、收藏、战斗，从未见过钱包。

设计法：**代币买的是永久（以及轻量声望）。绝不买收益。** 无质押 APY、无“质押生息”、
无奖池、无把活体冠军赚到的王冠币分给卡牌持有者。

---

## 两种经济，永不桥接

| | **王冠币** | **代币**（暂名 `$ZING`） |
|---|---|---|
| 性质 | 软货币，游戏内 | 硬资产，链上（Solana） |
| 如何获得 | *靠玩*赚取 | 市场*购买*，或按游玩空投 |
| 用途 | 训练、入场、支持、外观重铸 | 销毁以不朽化冠军卡 |
| 现金价值 | 永远没有 | 市场价格（非我们承诺） |
| 能否兑现？ | **永不** | 仅在公开市场，永不*经我们* |

两种余额**永不互相兑换**。墙是本文最重要的不变量。

实际：新玩家只碰王冠币。代币是可选收藏层，给想把传说永久盖章的训练师。

---

## 王冠币（世界内货币，免费）

**王冠币**靠游玩赚取：

| 来源 | 奖励 |
|------|------|
| 赢得战斗 | 王冠币 + XP + 排名 |
| 推进试炼 | 递增奖池、压运 |
| 训练 | 花王冠币 → XP + 身体朝你的策略演化 |
| 排名战 | 花王冠币 → 一场计分对随机对手 |
| 飞行里程碑（百域、初光） | 一次性奖金；百域在每日上限之外 |
| 每日 / 赛季目标 | 稳定滴流 |

王冠币购买**训练、入场与外观重铸**。游戏币：充裕、不卖、不兑现。飞行、竞技场、
缓存与目标的可变收益共享每日上限；里程碑奖金在外。工艺榜排名是荣誉，不是王冠币奖金。

### “支持”，不是“下注”

王冠币经济里的动词是**支持**。你支持冠军去赢。玩家文案不用“下注”。是信念，不是赌博。

## 代币（`$ZING`，暂名）

只有一件硬活，说得清：

**销毁代币 → 把你的冠军不朽化为链上卡牌。**

这就是效用。卡牌周围的声望只是轻量荣耀。

### 不朽化

- 你拥有一段活着的生涯，选择盖章。
- 按稀有度与版本档位销毁**固定数量**代币（赛季之间可调）。无价格预言机。无联合曲线。
- 链上铸造卡牌。艺术是盖章那一刻生涯的**冻结快照**。场地里身体还可成长；卡牌自己不变身。
- **稀缺跟阵容走。** 第一年每种心智最多不朽化 **八** 次。每个活着的生涯一印。新心智各自再得八次——供应随图鉴增长。以今日阵容计，第一年约一千张。创世印章带 OG 标记。
- 溯源记录持有者、盖章时间、赛季。卡牌可交易。二级版税可分给工作室与原铸造者，绝不是对活体冠军王冠币抽成。

活体冠军仍归训练师游玩。它赚的王冠币仍归该训练师。卡牌是奖杯，不是对未来软收益的索取权。

### 声望（轻量）

不朽化卡牌可带赛季纹章、画廊位置、留名。持有或获得盖章可影响下一季空投权重。
**荣耀与分配权重。绝无持续派息。绝无对冠军产出王冠币抽成。**

公开市场交易卡牌日后可带少量工作室版税。那是收藏品交易，不是战斗工资。

### 代币绝不做的事

- 购买胜负、属性或榜单入场
- 支付收益、APY 或表现费
- 与王冠币互兑
- 锁死飞行、养成或免费赛季

人们不朽化时供应收紧：销毁减少流通。可预留金库做空投。永不把金库当收益发放。

## 赛季与免费游戏

免费游戏已有**赛季**时钟：拱库再开一道门，软重置排名但保留名字
（[`06-seasons.md`](./06-seasons.md)）。**该免费赛季对所有人仍免费。**

赛季给不朽化日历：版本印记、纹章语言、章节结束时的铸造潮。加密仍是该章的奖杯柜。
绝不是老虎机。

---

## 设计约束

- **墙成立。** 王冠币与代币永不兑换。
- **溯源字段已存在。** 卡牌已有 mint id、所有者、链、铸造赛季。链只是填入。
- **永不出售影响胜负的力量。** 只有永久与轻量声望。
- **仅工作室心智。** 收藏者盖章工作室写就的传说。
- **刻意做薄。** 一个硬销毁槽。拒绝额外“效用”。

---

## 合规护栏

- **无收益。** 永不质押生息。永不把销毁或冠军王冠币分给卡持有者。
- **销毁是盖章费用**，不是博彩赌注。
- **奖励是外观、声望或分配权重。**
- **不做价格营销。**
- **王冠币永不兑现。**

---

## 已定 / 仍开

**已定：** 销毁以不朽化；快照艺术；第一年 = **每心智八次**（今日约 1056；随图鉴增长）；创世 OG；仅所有者；可交易；分档固定销毁；无预言机/曲线；Solana。

**仍开（旋钮，非形状）：** 代号；销毁表；版税；创世后续是否窗口制；第二年每心智上限。
