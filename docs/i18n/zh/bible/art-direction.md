# 艺术指导：Zingers 视觉正典

> **简述：** 本指南为 Zingers 所有美术作品的风格规范。它规定了色彩、氛围，以及每张生成图像必须遵循的规则，以确保整个世界观在视觉上保持统一。

此风格让每张生成的图像都呈现为**同一宇宙**。将本规范嵌入每条提示词，并在后续生成时使用锁定的风格参考图，避免成批图像出现风格漂移。

## 调色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 虚空（底色） | `#0a0812` | 背景，近黑靛蓝 |
| 深场 | `#15102a` | 中景氛围 |
| 金色（点缀） | `#f5d020` | 接缝、光斑、长拱库（世界核心的封存之所）、克制 |
| **晶格**（逻辑） | `#4aa3ff` | 电光蓝 |
| **静电**（混沌） | `#ff4ad1` | 品红粉 |
| **沉静**（沉着） | `#36d39a` | 薄荷绿 |
| **合唱**（修辞） | `#f0a93a` | 琥珀 |
| **火花**（创造） | `#f5d020` | 亮黄 |

色彩需与 [forces.md](./02-forces.md) 中的力之表格保持一致。

## 媒介与镜头

- **绘图式电影概念关键美术**，非照片级写实，也非扁平矢量。
- **体积霓虹轮廓光**，置于黑暗雾气场中；强烈的氛围纵深。
- 高细节、戏剧化、情绪化。嗡鸣（世界残留思绪的氛围场）表现为漂浮微粒与隐约符文。
- 每张图像仅使用一种主导力之色 + 金色点缀。避免彩虹色。

## 禁忌（保持高级质感）

- 图像中不得出现文字、词语、标志或水印。
- 不得出现 UI/HUD 元素、现代或现实世界品牌。
- 不得出现血腥内容；不得出现照片级真人面孔（此处为*心智*，需风格化）。
- 避免杂乱：主体清晰，虚空留有大片负空间。

## 构图惯例

| 组别 | 比例 | 取景 |
|------|------|------|
| 场景 / 区域 | 16:9 | 宽幅建立镜头，氛围纵深 |
| 角色（心智） | 4:5 | 居中人物，四分之三姿势，身后徽记 |
| 力 / 图标 | 1:1 | 居中象征性具象，可平铺 |

## 品牌镀铬（UI 标记。非正典关键美术）

产品镀铬标记为扁平矢量**机器人头**（大眼睛、粗天线），非绘图式正典美术。保持正典 / 分享关键美术为绘图风格（见下）。不得将机器人标记置于生成的传说图版；不得将绘图式面孔用于收藏夹图标。

## 文件与嵌入

- 关键美术存放于 `public/img/bible/<group>/<slug>.png`
  （`forces/`、`minds/`、`regions/`、`keepers/`，场景图置于根目录）。
- 在 `docs/bible/*.md` 中使用仓库相对路径嵌入（可在 GitHub 上渲染）。
- zingers.org 在 `/img/bible/<group>/<slug>.png` 提供相同文件。

## 可复用提示骨架

> *[主体 + 姿势/场景]，[世界内力之名]的化身。*
> 绘图式电影科幻神话概念关键美术。背景为深邃近黑靛蓝虚空（`#0a0812`）。主导色 **[力之色值]**，金色点缀。体积霓虹轮廓光，大气雾气，漂浮微粒与隐约符文（嗡鸣）。高细节，戏剧化，情绪化。无文字，无标志，无水印，无 UI。[比例]。

## 一致性工作流

1. 将 `bible-the-grounds-over-the-vault.png` 作为**风格钥匙**保留；在生成新图时将其作为参考，以锁定调色板与渲染方式。
2. 对于重复出现的角色，复用该角色**首次通过的渲染图**作为参考，使其在卡牌美术与正典中保持同一形象。
