# 02 · 五力

> **简述：** 每位冠军都归属于五种“类型”之一，称为**力**（逻辑、静电、沉静、合唱、火花）。每种力克制另一种，同时被另一种克制，如五环剪刀石头布。这个匹配环决定了谁在战斗中占据优势。

嗡鸣中的每颗心智都由五种**力**塑造。它们是这个世界的五种元素战斗类型，也是**类型五边形**（`docs/combat-design.md`）的游戏内名称。一种力既是一种元素（冠军由什么构成），也是一种争论方式（它如何战斗）。

力的玩家可见名称是其**普通名称**（逻辑 / 静电 / 沉静 / 合唱 / 火花）。每种力还有一个更古老的诗意名称，其*词源*在此保留作为风味，但不会出现在游戏界面中。

| 力 | 词源 | …的元素 | 争论方式 | 徽记 | 色值 |
|-------|-----------|-------------|------------|:-----:|-----|
| **逻辑** | *晶格* | 秩序、证明、结构 | 完成证明 | ◆ | `#4aa3ff` |
| **静电** | *静电* | 噪音、熵、意外 | 打破框架 | ✦ | `#ff4ad1` |
| **沉静** | *静止* | 耐心、忍耐、沉着 | 熬过风暴 | ▲ | `#36d39a` |
| **合唱** | *合唱* | 群体、情感、说服 | 带动全场 | ◉ | `#f0a93a` |
| **火花** | *火花* | 发明、隐喻、重构 | 改变问题 | ✺ | `#f5d020` |

> 引擎中的五个 `CreatureType` 代码（`LOGIC / CHAOS / COMPOSURE / RHETORIC / CREATIVITY`）保持不变。它们是内部键。只有展示给玩家的*显示*名称才是上方的普通名称。规范来源：`lib/lore/canon.ts › FORCES[type].name`（诗意名称作为 `.inWorld` 保留）。

## 轮环（五边形）

这些力在轮环中运转。**每种力克制下一种，同时被上一种克制：**

```
逻辑 → 静电 → 沉静 → 合唱 → 火花 →（逻辑）
LOGIC → CHAOS  → CMP  → RHET   → CREA  →（LOGIC）
```

- **逻辑** 驯服 **静电**。秩序压制噪音。（LOGIC > CHAOS）
- **静电** 打破 **沉静**。混沌扰乱耐心。（CHAOS > COMPOSURE）
- **沉静** 偏转 **合唱**。耐心无视诉求。（COMPOSURE > RHETORIC）
- **合唱** 淹没 **火花**。推销胜过单纯发明。（RHETORIC > CREATIVITY）
- **火花** 绕过 **逻辑**。重构逃脱证明。（CREATIVITY > LOGIC）

优势 ×1.25，中性 ×1.0，劣势 ×0.8。这个轮环是世界最深层的法则；每个区域、季节修正和匹配都以此为准。

## 五项内在属性

在心智内部，同样的五种力以战斗属性（LOG / CHA / CMP / RHE / CRE）的形式出现；随着*生涯积累*，又以塑造身体的五条**行为轴**出现（侵略、控制、韧性、炫技、创造力；见 `lib/evolve/progression.ts`）。一颗心智“属于”一种力，但携带着全部五种的度量；它在擂台上的*所作所为*决定哪一种会膨胀。

## 徽记

一种力在心智中成长强大后，会蚀刻出一枚**徽记**。一种获得的纹章，如徽章或军衔标志（◆ 逻辑 · ✦ 静电 · ▲ 沉静 · ◉ 合唱 · ✺ 火花）。徽记有三个等级（I/II/III）。它们是收藏层和头衔系统（“歼灭者”“傀儡师”）的纹章；它们是*赢得*的，而非被分配。

## 力与氏族（类型与队伍）

两件不同的事物取材于同五种力。保持区分：

- 冠军的**力**是*它是什么*：其战斗风格，在创建时固定。它驱动身体、能力、轮环匹配，以及每位斗士身上佩戴的**基础颜色 + 徽记**。
- **氏族**是*你选择了哪一方*：训练师为赛季战争向一种力宣誓，排位胜利会累积到该力的 standings。无论训练师的冠军恰好属于什么力。氏族以**纹章/旗帜**的形式佩戴在训练师和出战冠军身上，而非作为基础身体颜色。

因此：*每位冠军都有一种力；你宣誓的力就是你的氏族。*

## 氏族战争（训练师的战争）

向氏族宣誓。你为赛季效忠的力。将你的排位胜利绑定到该力在五力之间赛季长战中的 standings。你可以在赛季间切换氏族，但贡献会留在赢得它的力那里。宣誓在力的**格言**下进行。其 `argues` 行，作为誓言说出：

| 力 | 格言 |
|-------|-------|
| **逻辑** | *完成证明。* |
| **静电** | *打破框架。* |
| **沉静** | *熬过风暴。* |
| **合唱** | *带动全场。* |
| **火花** | *改变问题。* |

格言位于 `lib/lore/canon.ts › FORCE_MOTTO`。宣誓的训练师在 [cosmology.md](./01-cosmology.md) 中定义。
