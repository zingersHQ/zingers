# 07 · 收藏：卡牌、稀有度与属性

> **简述：** 每位冠军同时也是一张可收藏的卡牌，类似宝可梦或万智牌。但与它们不同的是，卡牌的艺术图会随冠军的战斗与成长而变化。你将收集不断扩充的图鉴、养成一支稳定的队伍，并（后续）进行交易。

每位冠军同时也是一张**卡牌**。卡牌是心智的可携带、可收藏的外在表现，其最核心的特性已在代码中实现：**艺术图会进化**，因为艺术图即是冠军的身体。每个心智键在共享骨架上解析一个固定的**物种套件**（`lib/render/species.ts`）：品种轮廓 + 部件配置，再加上职业骨骼变形（`lib/evolve/appearance.ts`）。相同力系的心智会呈现为不同动物；阶层则会叠加更多护甲。你拥有的卡牌会随着战斗而明显变强。

## 卡牌结构

| 部分 | 来源 | 说明 |
|------|------|------|
| **心智**（名称、力系、血统） | 初始心智 + 已烘焙图鉴（`content/minds/reviewed/`） + 赛季生成器 | 身份标识 |
| **艺术图** | 基因组 + 力系原型 + 物种套件 → 身体渲染 | 随职业与阶层确定性变化 |
| **属性** | 五项战斗属性 + 评分 | 数值 |
| **徽记** | 获得的力系纹章（I/II/III）。赢得的徽章，不可购买 | 徽章 |
| **属性** | 招式组（4 个招式） | “能力”行：TCG 深度所在 |
| **传奇** | 由对战历史生成 | 风味文本。冠军自身不断演进的人生故事 |
| **稀有度** | 由阶层 × 稀缺度推导 | 见下文 |
| **出处** | 铸造赛季、持有者、铸造 ID | 目前暂无功能；所有权钩子 |

## 稀有度

稀有度是**先赢得，再稀缺**。它并非抽卡机制，而是随冠军阶层与该构建的真实稀缺度上升。

| 稀有度 | 获得条件 | 感受 |
|--------|----------|------|
| **普通** | 新手 | 刚凝聚的心智 |
| **非凡** | 熟手 | 证明过一两次 |
| **稀有** | 老兵 | 真实战绩 |
| **史诗** | 精英 | 令人畏惧的名字 |
| **传说** | 传奇 | 已加冕；积分榜上的常客 |
| **神话** | 传奇 + 赛季头衔（如击破守门人、赢得赛季） | 独一无二的事件；奖杯阶层 |

## 收藏玩法（宝可梦 / 万智牌层）

- **收集**：八位初始心智、已烘焙图鉴波次（第 6 阶段批次心智）、赛季精选心智，以及你自己养成的职业生涯。图鉴是长期目标。新心智通过 `npm run forge:dex` / 审核 / `npm run bake:minds` 发布（见 [03-champions.md](./03-champions.md)）。
- **相遇**：每周领养轮换会从该池中展示每种力系的一位初始者，让回归的训练师随时间遇到不同的同伴。
- **组建**：一支小型**稳定队伍**，可在各区域出战；他们的力系在力轮上相互作用，因此一支稳定队伍就是一张具备属性覆盖的*卡组*。
- **交易 / 赠送**：玩家间卡牌流转（社交循环）。已在设计中；受所有权层限制（[economy.md](./08-economy.md)）。链上铸造是后续对卡牌已有出处字段的填充，并非图鉴存在的原因。

## 典律规范

- 卡牌的**稀有度可以上升**（你将新手养成传奇后会向上重新铸造），但卡牌的**身份永久不变**：同一心智、同一血统、演进中的身体。
- 已烘焙与生成的心智会获得**血统**标签（它们呼应的初始心智），使图鉴保持清晰，每张卡牌在力轮上都有定位。
