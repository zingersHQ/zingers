# 07 · 收藏：卡牌、稀有度与属性

> **简述：** 每位冠军同时也是一张可收藏的卡牌，卡牌上的艺术会随冠军的战斗与成长而变化。你将收集不断扩充的图鉴，养成一支稳定队伍，并（后续）进行交易。

每位冠军同时也是一张**卡牌**。卡牌是心智的可携带、可收藏的外在表现，其最出色的特性已然成真：**艺术会进化**，因为艺术即是冠军的身体。每位心智在共享框架上佩戴稳定的**物种标记**：品种体型（高跷、坦克、敦实、纤细、演说家、长肢或典范）加上部件配置，再加上随战斗与阶层成长的生涯躯体。相同力系的心智会呈现为不同动物；阶层则会叠加更多护甲。你拥有的卡牌会随着你使用它战斗而变得明显更强。

## 卡牌结构

| 部分 | 来源 | 说明 |
|------|------|------|
| **心智**（名称、力系、血统） | 初源心智 + 图鉴 + 赛季生成器 | 身份标识 |
| **艺术** | 生涯 + 力系 + 物种标记 → 身体 | 游玩中随战斗与阶层变化；链上不朽化印章冻结快照 |
| **数据** | 五项战斗属性 + 评分 | 数值 |
| **徽记** | 获得的力系纹章（I/II/III）。赢得的徽章，而非购买 | 徽章 |
| **属性** | 招式组（4个招式） | 能力行：战斗中能做什么 |
| **传奇** | 由对战历史生成 | 风味文本。冠军自身不断演进的生命故事 |
| **稀有度** | 由阶层 × 稀缺度推导 | 见下 |
| **出处** | 铸造赛季、持有者、铸造编号 | 目前未激活；所有权钩子 |

## 稀有度

稀有度是**先赢得，再稀缺**。它不是随机抽取，而是随冠军的阶层以及该构筑的真实稀缺度而上升。

| 稀有度 | 获得于 | 感受 |
|--------|--------|------|
| **普通** | 新手 | 刚凝聚的心智 |
| **非凡** | 熟手 | 曾证明一两次 |
| **稀有** | 老兵 | 真实的战绩 |
| **史诗** | 精英 | 令人畏惧的名字 |
| **传说** | 传奇 | 加冕；积分榜的常客 |
| **神话** | 传奇 + 赛季冠军（例如赢得赛季、封印编年碑业） | 独一无二的事件；奖杯阶层 |

## 收藏玩法

- **收集**：八位初源心智、后续的图鉴回响、赛季精选心智，以及你自己养成的生涯。图鉴是长期游戏。新心智会随世界成长而分波次到来（见 [03-champions.md](./03-champions.md)）。
- **相遇**：每周领养轮换会从该池中展示每种力系的一位初始者，因此回归的训练师会随时间遇到不同的同伴。
- **构筑**：一支小型**稳定队伍**，用于在各区域出战；他们的力系在轮盘上相互作用，因此五种力系的覆盖很重要。你招入的成员会随你的训练师印记跨设备跟随，只要你恢复该印记（恢复码或已绑定钱包）。它们不会困在一块玻璃里。
- **交易 / 赠予**：卡牌的玩家间流转（社交循环）。已在设计中；受所有权层级限制（[08-economy.md](./08-economy.md)）。
- **不朽化**：销毁可选代币，将生涯盖章为链上卡牌（[08-economy.md](./08-economy.md)）。印章冻结当下艺术；版本随赛季与稀有度跃迁。出处字段是钩子。图鉴本身仍为游玩而存在。

## 正典准则

- 卡牌的**稀有度可以上升**（你从新手养成到传奇），但**身份永久**：同一心智、同一血统、游玩中演进的身体。链上，更高稀有度可以是一次新的**版本**盖章；旧版留下作历史。
- 图鉴与生成的心智会获得**血统**标签（它们回响自哪位初源心智），因此图鉴保持清晰，每张卡牌在轮盘上都有位置。
