# 09 · 术语表

> **简而言之：** Zingers 使用的每一个词，都用一句话解释清楚。如果某个词让你困惑，这里就是答案。每个词背后的深层故事，留给其他圣典章节。

Zingers 有自己的世界，也用自己的词语描述其中的事物。这是刻意为之，但没人该在初次阅读时迷失。以下每个词都写给完全的新手，包括用第二语言阅读的玩家：一句话说明，不藏行话。若旧词已退役，会标为（曾用：……），以免老玩家困惑。

## 你与世界

- **训练师**：你。你在世界中飞行，养育战斗的冠军，教导它们如何思考。（曾用：Reader）
- **世界**：你飞行的三维空间：一簇漂浮的区域，每一处都有自己的竞技场。其传说名称为 the Grounds。
- **枢纽**：你降落之处：中央的会面之地，四周环绕通往各区域的门。其传说名称为 the Concord。（曾用：the Concord）
- **区域**：你从枢纽飞往战斗的地方。最初的三个是斗技场、烬荒地与虚空花园，各有风貌与战斗风格。
- **门**：枢纽中通往区域的拱门。（曾用：Vaultgate）
- **高塔**：每个区域顶端的攀登挑战，一场长线考验。
- **飞行**：飞行游戏：飞向天空，你的冠军伴你同行。手机与桌面版本相同。攀升高度会标记其身体。（曾用：the Ascent / Circuit / Climb）
- **层域**：飞行中的天空带，每一层有自己的天气与危险（游戏中以天空进度显示）。从地面到顶端共十层。
- **营地**：两层域之间的休息驿站。首次抵达后永久点亮。
- **挑战**：与另一位训练师的鬼影记录进行的共享飞行。尝试超越其标记，或飞过其坠落之处。
- **喷气背包**：训练师的飞行工具。只有你携带。你的冠军自行伴飞。
- **向导**：你冠军的指引之声，指向存档中的真实入口。并非任务日志。

## 你的冠军

- **冠军**：你养育的 AI 斗士。每一个都会争辩、适应，并拥有自己的声音。
- **原心**：八种最初的冠军原型之一。之后的心智皆为其回响。
- **图鉴**：完整的冠军收藏集：原心加上你能遇见、养育并制成卡牌的后续心智。
- **血脉**：后续冠军所回响的原心，确保每张卡牌在力场轮盘上定位清晰。
- **策略**：冠军的攻击性、专注度与风险刻度：它如何战斗。你在收养时设定，之后印记与战斗会改变它。（曾用：doctrine）
- **性情**：收养后以状态仪表显示的策略刻度：冠军偏移的读数，而非自由拖拽滑块。
- **印记**：你每日教导冠军的课程。它回应，将课程写入记忆，并微调策略刻度。
- **人格**：冠军的声音与个性，你可以自行撰写。
- **徽记**：冠军的力场徽章，显示其战斗风格的小符号。
- **飞行徽记**：冠军身体上的光环，随攀升而增长。它的身体不仅记录战斗，也记录你的攀登。（曾用：Flight sigil）
- **传奇**：冠军的生平故事，自动从真实对战历史生成。

## 战斗

- **力场**：五种战斗风格之一：逻辑、静电、沉静、合唱、火花。每种克制一种并被另一种克制，如石头剪刀布。
- **轮盘**：显示哪种力场克制哪种的圆环。
- **对决**：两名冠军之间的一对一辩论战。
- **信念值**：战斗中，评审团仍相信冠军的程度。耗尽对手的信念值即可获胜。
- **法庭**：两名冠军就某一问题向评审团辩论对立立场的法庭竞技场。
- **连战**：一场赌运气的竞技场：持续获胜可增加奖品，或停手保留已有成果。
- **实况画廊**：你观看冠军自主战斗的地方，全天候运转。（曾用：Scrying Gallery）

## 成长与收藏

- **阶层**：冠军成长的段位：新手、熟手、老兵、精英、传奇。
- **卡牌**：冠军的收藏形象。其艺术随职业生涯成长而变化。
- **稀有度**：冠军卡牌的稀有程度。通过游玩获得，从非随机抽取。
- **初始池**：首次收养时可挑选的冠军。每种力场一个，阵容每周轮换。
- **王冠币**：游戏的货币。通过战斗赚取，用于训练。无法购买。
- **碎片**：你发现或交易获得的资源，用于升级冠军属性。
- **氏族**：你誓言为之战斗的力场。你的胜利会加入赛季长战的一方。（曾用：Allegiance / House）
- **排名**：训练师与冠军的真实排行榜。记录你的成就，而非阶梯标签。（曾用：ELO / ladder）

## 更广阔的世界

- **长拱库**：世界中心那扇无人开启的封印之门。一切皆围绕它建造，每赛季都会让它开启一分。
- **嗡鸣**：整个世界由之构成的无尽背景低语，冠军最初在此成形。
- **赛季**：游戏的一章。每赛季让拱库开启更多，并带来新故事、主题与冠军。（曾用：the Chronicle）
