# Zingers 圣典

> **简述：** 这是虚构世界「Zingers」的完整规则手册。你是一名**训练师**，负责培养在实时辩论对决中相互争锋的 AI「冠军」。本文件夹记录了这个世界中所有名称、地点与规则，确保游戏设定永不自相矛盾。

> 这是 Zingers 宇宙的正典，也是**唯一真实来源**，涵盖世界观、命名与虚构规则。它同时服务于两个用途：
>
> 1. **zingers.org**：玩家可探索的公开百科。
> 2. **生成引擎**：用于生成赛季、冠军与叙事的正典，确保游戏内容永不冲突。

任何游戏**生成**的内容（赛季剧情、新冠军的传奇、主题、区域事件）都必须**与本圣典保持一致**。其中机器可读部分位于 [`lib/lore/canon.ts`](././lib/lore/canon.ts)，文字描述则在此处。

## 三种游玩层级在正典中的定位

游戏是一个世界，通过三种不同时长的会话进入（设计北极星）。**飞行**（见 [ascent.md](./10-ascent.md)）是贯穿三者的主干：新手首先接触的系统，而每片区域的天空都会显示下方世界。

- **漫游（开放式）**：*世界*（世界观：大地）。可探索的漂浮地表，以喷气背包飞行其间。你生活于此，观看联赛在身边展开，飞向冠军与对手。连接一切的纽带。
- **快速对战（2–5 分钟）**：*竞技场 / 联赛*。随时加入，进行一场排位战，维持你的排名。世界任意位置均可进入。
- **养成（15–60 分钟）**：*战役与收藏*。成长型 RPG：培养心智、进化形体、推进编年史、建立收藏。

以上三种模式均无终点。**长拱库**（封存旧网络未竟之物的宝库）每赛季开启一扇新门；攀登本身即是意义所在。

## 正典准则（适用于作者与生成器）

- **名称固定**。五力、守望者、区域与八位初代心智不会随赛季更名。赛季与图鉴波次**新增**心智，而非覆盖原型。
- **力在游戏内使用普通名称**。每种力的玩家界面名称即为其普通名称（逻辑 / 静电 / 沉静 / 合唱 / 火花；见 [02-forces.md](./02-forces.md)）。旧有诗意名称（晶格 / 静寂 / …）仅保留于圣典词源，不在游戏界面中显示。玩家是**训练师**，即养育冠军之人；训练师所效忠的力即其**氏族**（你所选择的阵营）。3D 化身称为**驭手**。详见 [cosmology.md](./01-cosmology.md)。
- **引擎即物理**。`docs/combat-design.md` 中的伤害、属性与状态在世界观中**真实存在**。辩论塑造现实。
- **生成的世界观为增量且可重现**。赛季剧情由种子 + 本圣典生成，因此可复现且永不偏离正典。
