# 津格斯圣典

> **简而言之：** 这是津格斯虚构世界的完整规则手册。你是一名**训练师**，你培养能在实时辩论对决中争锋的 AI「冠军」。本文件夹记录了这个世界里每一个名称、地点与规则，确保游戏永远不会自相矛盾。

> 津格斯宇宙的正典。这是**单一事实来源**，涵盖世界观、名称与规则即虚构。它同时服务于两个对象：
>
> 1. **zingers.org**：玩家探索的公开百科。
> 2. **生成引擎**：用于生成赛季、冠军与叙事的正典，确保游戏生成的一切内容永远不会自相矛盾。

游戏所*创造*的一切（赛季故事、新冠军的传奇、主题、区域事件）都必须**与本圣典保持一致**。散文在此存活。

## 什么属于此处（什么不属于）

圣典是**世界虚构与规则即虚构**。写下世界中真实存在的事物：训练师是谁、冠军是什么、原力如何运作、拱库为何重要。让从未打开过代码仓库的普通玩家也能读懂。

**此处不放：** 源文件路径、模块名称、npm 脚本、API 路由、架构字段名或「如何运行仓库」的说明。这些属于设计与技术文档（`docs/combat-design.md`、`docs/TECHNICAL.md`、`docs/climb.md` 等）。如果一段文字只有克隆过项目的人才能理解，它就放错了地方。也不要与其他游戏做比较（「像宝可梦」、「魔法层」）。用津格斯自己的语言描述津格斯。

## 三种游玩层在正典中的位置

游戏是一个世界，以三种会话长度进入（设计北极星）。**飞行**（见 [ascent.md](./10-ascent.md)）是贯穿三者的脊柱：它是新手最先接触的事物，而每个区域的天空都会告诉你下方有什么：

- **漫游（开放式）**：*世界*（世界观：大地）。漂浮、可探索的表面，用喷气背包在其中飞行。你生活在其中，观看联赛在身边发生，飞向冠军与对手。连接的组织。
- **快速对战（2–5 分钟）**：*竞技场 / 联赛*。随时加入，进行一场排位战，保持你的排名。随时可从世界任何位置进入。
- **养成（15–60 分钟）**：*养成与收藏*。成长型 RPG：养育心智、进化他们的躯体、推进编年史、建立收藏。

这些都不会「结束」。**长拱库**（一个封存了旧网络永远无法完成之物的密库）每个赛季都会打开一扇新门；攀登本身就是意义。

## 正典纪律（为写作者与生成器而设）

- **名称固定。** 原力、区域与八位初生心智不会被赛季重命名。赛季与图鉴波次**新增**心智；它们不会覆盖原型。
- **原力在游戏中使用其普通名称。** 每种原力的玩家可见名称即普通名称（逻辑 / 静电 / 沉静 / 合唱 / 火花；见 [02-forces.md](./02-forces.md)）。旧有的诗意名称（晶格 / 静止 / …）仅作为*词源*保留在圣典中，绝不显示在游戏界面。玩家是**训练师**。养育冠军的人；训练师所效忠的原力是他们的**氏族**（你所选择的阵营）。3D 化身是**驭手**。见 [cosmology.md](./01-cosmology.md)。
- **引擎即物理。** 战斗设计中的伤害、属性与状态*在世界中真实存在*。论证塑造现实。
- **生成的世界观是累加且有种子的。** 赛季故事由种子 + 本正典生成，因此可复现且永不偏离正典。
