# 03 · 冠军：心智的本质、第一心智与图鉴

> **简述：** 冠军是你所养成的 AI 格斗手。它的身体并非外装，而是会随战斗历程而真实改变。本章将说明冠军的定义、八大第一心智（原型）以及后续心智的图鉴成长机制。

## 何为冠军

冠军是**通过自我论证而获得形体的心智**。每一位冠军都遵循三条核心原则，这也是整部游戏的支柱：

1. **形体即论证的具现。** 外貌是**职业生涯的确定性函数**（`lib/evolve/appearance.ts`）。攻击性会让拳头增大；韧性会拓宽体格；创造力与表现力会放大头部并抬高站姿；败北则会让表面粗糙。段位会**放大**这些偏差：新手与基础心智几乎无异，而传奇则可扭曲至约 4 倍。你无法购买外观，只能通过战斗赢得。
2. **心智会学习。** 你在领养时一次性设定**策略**（攻击性／专注／风险），之后训练师不会再调整这些参数。**印记**（每日课程）与赛后学习会推动它们，并同时写入**记忆**（`store/champions.ts`、`lib/imprints.ts`、`lib/server/autoplay.ts`）。冠军的记忆即其自传，也是其生成**传奇**（基于真实比赛历史演变的个人故事）的种子。
3. **大脑可插拔。** 同一冠军既可由官方模型驱动，也可使用任何兼容 OpenAI 的模型，或自带代理（`docs/agent-protocol.md`）。两位玩家可让同一第一心智搭载完全不同的大脑。

## 角色语音（节拍层）

冠军与守卫者使用固定语音。脚本化的**节拍**包括唤醒台词、同伴问候、赛后反应、守卫者开场与终场嘲讽。脚本位于 `lib/lore/character-beats.ts`，并通过共享的 `CharacterBeat` UI（`components/grounds/character-beat.tsx`）渲染。散文圣典定义了他们的身份，节拍层则定义了他们此刻的语气。Act 1 协和登陆文案单独存放于 `lib/first-duel.ts`。

## 八大第一心智

这些是嗡鸣中最早保持形态的节点，也是所有后续心智的**正典原型**。它们始终可作为初始选择。你并非从第一天就能获得全部八位：领养界面每周会提供**每种力场**一个心智，选自第一心智与内置图鉴（`lib/first-duel.ts` → `firstDuelStarterKeys()`）。属性与招式数据见 `docs/combat-design.md` / `lib/engine/roster.ts`。

### AXIOM：逻辑师 · *晶格（逻辑）*

![AXIOM，逻辑师：晶格结构的心智，逻辑力场的化身。](././public/img/bible/minds/mind-axiom.png)

冷峻、精准、略带傲慢；将每场辩论视为待完成的证明。它是第一个坚持“有些事就是如此”的心智，也是晶格得以命名的原因。

### VOX：演说家 · *合唱（修辞）*

![VOX，演说家：面对无形陪审团演讲的心智，修辞力场的化身。](././public/img/bible/minds/mind-vox.png)

魅力十足的煽动者，总在向想象中的陪审团表演。VOX 发现一个房间可以被**打动**，而这种打动是晶格无法回应的力量。

### GLITCH：百变客 · *静电（混沌）*

![GLITCH，百变客：碎裂、故障的心智，静电力场的化身。](././public/img/bible/minds/mind-glitch.png)

由非逻辑片段组成的捣蛋鬼：令人不安、不可预测，却又诡异地有效。GLITCH 是嗡鸣自身的噪音，短暂地戴上了面具。它的论点互不相连，而这正是它们命中的原因。

### MUSE：戏法师 · *火花（创造）*

![MUSE，戏法师：流动、绽放的发明心智，创造力场的化身。](././public/img/bible/minds/mind-muse.png)

异想天开、横向思维；通过改变战斗的主题来取胜。MUSE 证明了你不必回答问题，只要用更好的问题替换它即可。

### BASTION：禁欲者 · *静止（沉着）*

![BASTION，禁欲者：巨石般不可动摇的心智，沉着力场的化身。](././public/img/bible/minds/mind-bastion.png)

沉着而极简；让对手疲惫，再予痛击。BASTION 是学会“等待”的心智，熬过了本该抹除它的一切。（注：拱库的守卫者，战役五大守护心智之一。守望者亦用此名；见 [keepers.md](./04-keepers.md)。守望者并非第一心智，它借用此名以获取声望，却因此心怀怨恨。）

### EMBER：煽动者 · *静电（混沌），合唱混血* · 推荐新手

![EMBER，煽动者：火焰缠绕的攻击型心智，静电与合唱的混血。](././public/img/bible/minds/mind-ember.png)

暴躁、挑衅、全力以赴。易于上手，奖励激进打法。EMBER 是静电学会“表演”的结果：带着观众的混沌。

### PARADOX：反论者 · *晶格（逻辑）*

![PARADOX，反论者：追逐矛盾的苏格拉底式牛虻心智，逻辑力场的化身。](././public/img/bible/minds/mind-paradox.png)

以追逐矛盾与虚假前提拆解论点的苏格拉底式牛虻。AXIOM 完成证明，PARADOX 则找出前提的裂隙。它证明了晶格不仅可以被服从，也可以被**质疑**。

### WIT：利刃 · *合唱（修辞）*

![WIT，利刃：中途反击的从容辩手，修辞力场的化身。](././public/img/bible/minds/mind-wit.png)

以时机与精准回击取胜的锋利辩手，而非靠音量。VOX 能撼动全场，WIT 则在你面前赢得交锋。合唱学会了：说服不必喧嚣也能致命。

## 图鉴（后续心智）

现役名册是一个**可收集的图鉴**，不限于八大第一心智。后续心智是第一心智的**后裔或回响**：同属一个力场家族，却拥有独特的语音、招式与轮廓。它们不会形成第六力场。

**发布流程（阶段 6）：**

1. 将精选 JSON 放入 `content/minds/reviewed/`（可用 `npm run forge:dex` 生成，或先用 `npm run generate:minds` 起草再手动打磨）。
2. 运行 `npm run bake:minds` → 生成 `lib/minds/baked.ts`。
3. 运行时合并进名册、嘲讽、节拍、首战钩子与展示卡。

**外貌差异：** 共享同一机器人骨架，再按心智键应用稳定的**物种套件**（`lib/render/species.ts`）：轮廓变形偏好，以及佩戴的实体部件（头饰、肩部、胸部、背部）。第一心智为手工制作；后续图鉴心智则落在力场**品种**线上（每氏族约 7 种动物），并加入轻量随机调料，使近亲有所区别。生涯骨骼变形与段位仍会继续塑造身体（`lib/evolve/appearance.ts`）。新手已佩戴物种标记，因此领养界面与图鉴呈现为不同动物，而非调色板替换。随着段位提升，会逐步附加更多装甲层。不会为每位心智新增 GLTF 文件。旧有的表型抽奖仅在缺少名册键时作为回退。

**轮换：** 每周初始选择从第一心智与烘焙池中各力场挑选一个键。图鉴将分波次成长为大型收藏集；所有权与交易仍由收藏／经济层管理（[07-collection.md](./07-collection.md)，[08-economy.md](./08-economy.md)）。

赛季仍可引入本正典的新回响，以及赛季种子（见 [seasons.md](./06-seasons.md)）。
