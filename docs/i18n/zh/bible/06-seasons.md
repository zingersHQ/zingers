# 06 · 纪事：生动的生成季

> **简述：** 游戏以季播形式运行，如同一部电视剧。每季游戏都会自动生成新的故事篇章、新的辩题，以及一片新区域。但你的排名和冠军会保留，因此你永远不会从零开始。整个持续展开的故事称为**纪事**。

**纪事**。世界逐季推进的持续故事。每次只前进一步：一**季**即拱库开启又一扇门。它既是游戏的内容节奏，也是其故事引擎。季是**生成式且带种子的**：从单一季种子加上本典，游戏可复现地推导出该季的故事、辩题库、区域倾向、特色心智与排名策略，且绝不偏离典律。

## 一季会更替什么

| 元素 | 每季变化 | 来源 |
|------|--------|------|
| **弧线** | 一段短篇叙事：哪扇门开启、泄出了什么、谁崛起 | 由种子+典律生成 |
| **辩题库** | 该季的命题（门所忆起的“禁问”） | 生成，按门主题化 |
| **区域倾向** | 一个特色区域及其力偏向（或全新区域） | 按力平衡选定 |
| **特色心智** | 某原初心智的后裔/回响，该季的“面孔” | 生成血统 |
| **排名策略** | **软重置**：排名向均值压缩，而非清零 | 固定规则（见下） |

## 排名软重置（“常在排位”规则）

季更迭最怕失去名次。Zingers 从不抹除名次。每当季更迭，所有评分都会被拉回基线一段距离：

```
新评分 = 基线 + (旧评分 - 基线) * 保留率   // 保留率 ≈ 0.6
```

因此传奇仍为传奇（只是更接近众人），攀登者保留大部分收益，而新人们在*新*季的排位榜顶端拥有真正机会。你始终带着自己的名字前行；只是需要捍卫它。

## 冠军传奇（个人生成叙事）

在世界故事之外，**每位冠军都会积累自己的传奇**。其个人、演进中的生命故事。源自其真实对战历史：记忆笔记、最强灌篮、宿敌（它击败过谁、谁击败过它）。生成器将这些转化为简短、演进中的角色传记，呈现在冠军卡片与档案上。记录早已存在；季引擎只是将其叙事化。

## 生成器契约（典律纪律）

生成层必须：
1. 接受一个**种子**（季号为默认种子），使输出可复现。
2. 将本典视为典律，**绝不重命名**力、区域或原初心智。
3. 仅产出**增量**传说：一扇新门，而非改写。
4. 优雅降级：无模型可用时，回退至由典律表组成的**确定性**季，使游戏始终拥有活跃季。

可选模型阶段会在此确定性骨架之上丰富弧线与辩题风味。
