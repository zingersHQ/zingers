# 06 · 编年史：鲜活的生成式赛季

> **简述：** 游戏以赛季形式运行，如同电视连续剧。每赛季游戏都会自动生成新的故事篇章、全新辩题，以及新区域。但你的排名与冠军会保留，因此你永远不会从零开始。整个持续展开的故事称为 **编年史**。

**编年史** 是世界随赛季推进的持续故事。每次只前进一步：**赛季** 即拱库开启一扇新门。它既是游戏的内容节奏，也是故事引擎。赛季采用 **生成式并带种子** 的方式：从单一赛季种子加上本典籍，游戏可复现地推导出该赛季的故事、辩题库、区域倾向、特色心智及排名策略，且绝不偏离正典。

## 赛季更替内容

| 要素 | 每赛季变化 | 来源 |
|------|------------|------|
| **弧线** | 简短叙事：哪扇门开启、泄露了什么、谁崛起 | 由种子 + 正典生成 |
| **辩题库** | 本赛季命题（门所记下的“禁问”） | 生成，主题与该门对应 |
| **区域倾向** | 特色区域及其力偏向（或全新区域） | 为力平衡而选 |
| **特色心智** | 某位原初心智的后裔/回响，本赛季的“面孔” | 生成血脉 |
| **排名策略** | **软重置**：排名向均值压缩，而非清零 | 固定规则（见下） |

## 排名软重置（“排名永不丢失”规则）

赛季更迭最怕丢失名次。Zingers 绝不抹除名次。每赛季转折时，所有评分都会向基线回拉一定比例：

```
newRating = baseline + (oldRating - baseline) * RETENTION   // RETENTION ≈ 0.6
```

因此传奇依然是传奇（只是更接近群体），攀升者保留大部分收益，而新手也有机会登顶新赛季的积分榜。你始终带着自己的名字前行；你只需捍卫它。

## 冠军传奇（个人生成式叙事）

除世界故事外，**每位冠军还会积累自己的传奇**。这是其个人、持续演化的生命故事。源自真实对战历史：其记忆笔记、最佳扣杀、宿敌（它击败过谁、谁击败过它）。生成器将这些转化为简短、不断演化的角色传记，展示在冠军卡片与个人资料页。数据早已存在（`Recipe.memory`、对战 MVP 语句、评分记录）；赛季引擎仅负责将其叙事化。

## 生成器契约（正典纪律）

生成层必须：
1. 接收**种子**（默认使用赛季编号），确保输出可复现。
2. 将本典籍视为正典，**绝不重命名** 力、守门人、区域或原初心智。
3. 仅产出**增量** 世界观：新门，而非回溯改写。
4. 优雅降级：无模型可用时，回退至由正典表生成的**确定性** 赛季，确保游戏始终拥有活跃赛季。

确定性主干位于 [`lib/lore/season.ts`](././lib/lore/season.ts)；可选模型阶段在其基础上丰富弧线与辩题风味。
