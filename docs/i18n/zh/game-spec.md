# Zingers：游戏规格

**你飞翔。它战斗。你们一同攀升。** 你不亲自战斗。你培养一名 AI 冠军，由它去战斗，而你则在它身边一同攀升。

规范产品框架：**[design-vision.md](./design-vision.md)**（飞行优先）· 入口：**[two-doors.md](./two-doors.md)** · 现行路线图：**[flight-first-plan.md](./flight-first-plan.md)** · 留存：**[long-game.md](./long-game.md)** · 命名：**[vocabulary.md](./vocabulary.md)**。

## 核心原则

> **LLM 是演员。引擎是游戏。**

战斗采用回合制，包含明确的招式与数据驱动的结算。数据、属性、训练、状态效果与随机因素决定伤害。机智质量是一个有界乘数（0.7–1.3，Highlight 时可达 1.4）。默认使用**本地裁判**；可通过 `ZINGERS_LLM_JUDGE=1` 启用 LLM 裁判。任何一方都无法单独决定比赛结果。

完整数值、名册与示例战斗：**[combat-design.md](./combat-design.md)**。

## 循环

**飞行 → 认领 → 培养 → 战斗 → 攀登更高**

1. **飞行**（Flight）：手机端（`/m` / `/ascent`）与桌面端（Circuit 赛场）各一局。同一灵魂，不同躯体。
2. **认领**：认领你翼上的心智，或从每周初始池中挑选（每种力一种），池子来自 First Minds 与内置图鉴。
3. **培养**：领养时设定策略；随后添加印记、人设与大脑选择。性情仪表是读数。战斗与训练会拨动仪表。
4. **战斗**：在世界中（区域竞技场、每日法庭等）进行 1v1 对决，推理过程可见。
5. **攀登更高**：飞行深度 + 真实排名/积分（`/standings`）。两者共同提升训练师排名。**Director** 会指向下一步（`lib/director.ts`）。

## 同一世界，多款游戏

你玩的一切都存在于 3D 世界（`/` · `/grounds`）中，移动端原生外壳位于 `/m`。枢纽将元游戏汇聚为**走近式赛场**；每个浮动区域都承载竞技场场景。**飞行**是同一灵魂：桌面端的 Circuit 是同一 100 扇区攀升的可竞速躯体。目录：`lib/scenarios/registry.ts` · 赛场：`components/grounds/venues.ts`。

### 枢纽与赛场

| 模式 | 位置 | 内容 |
|------|------|------|
| **世界** | 处处皆是 | 飞行、培养冠军、追逐目标。身体随生涯变化。 |
| **圆形剧场** | 枢纽赛场 | 在**现场画廊**观看自主联赛自对战；今日法庭先驱。 |
| **飞行（桌面）** | Circuit 赛场 | 六自由度完整飞行，100 扇区（十次抵达）；三次生命 + 抵达清除恢复；按深度再按时间排名。 |
| **飞行（手机）** | `/m`、`/ascent` | 同一飞行灵魂，单指操作。游戏的移动端面貌。 |
| **每日法庭** | 枢纽石碑 | 每日一场共享战斗。观看前先呼叫；分享结果网格。 |

### 世界内竞技场场景

| 场景 | 位置 | 内容 |
|------|------|------|
| **开放对决** | 任意区域广场 | 1v1 辩论战斗。挑选对手，决一胜负。数据五边形、终结技、有界机智裁判。 |
| **连战** | 烬之荒地（默认） | 不断增强的战斗者链条；继续挑战或兑现离场。 |
| **法庭** | 黑曜石竞技场（旗舰） | 指定立场向陪审团辩论；切换立场得分 ≈0。 |

未列出的 **`/arena`** 仍是代理战斗查看器，用于自带代理测试（辩论战斗）。

### 首次旅程（飞行优先）

| 入口 | 最初几分钟 |
|------|------------|
| **移动端** | 启动画面 → 起飞（访客可） → 认领翼伴 → 培养 → 排行榜 |
| **桌面端** | 唤醒 → 短程飞行 → 挑选冠军（每周初始） → 枢纽 / 飞行 → 由攀升驱动的*对决* |

实时排序：**[flight-first-plan.md](./flight-first-plan.md)** 与 **[two-doors.md](./two-doors.md)**。历史战斗优先 Act 1：**[first-journey-roadmap.md](./first-journey-roadmap.md)**。

### 飞行附加（已上线）

- **挑战**：与另一训练师的幽灵记录竞速；分享 `/ascent/<id>`；超越时获得祝酒（[`bible/10-ascent.md`](./bible/10-ascent.md)）。
- **走廊感**：每扇区 4–8 环；抵达风味布局；危险读作威胁（而非战利品）；中途王冠币缓存是唯一途中奖励（+王冠币 + 祝酒）；首次危险 / 缓存 / 门之试炼一次性教学。
- **百扇区之后**：有限峰顶（非无尽）。声望是更干净的飞行、好友挑战与每周远征。不是跨躯体竞速跑（移动端始终保持高热巡航 + 推力爆发；桌面端 W 爆发仍是安静的工艺炫技）。
- **Director + 解锁轨迹 + 翼部特质 + 每日条件 + 每周远征**：见 [`long-game.md`](./long-game.md)。

### 氛围

各场所程序化配乐（`lib/ambience-scores.ts`）：枢纽、每个区域生态、圆形剧场、飞行与实时战斗各有独立主题（模式、旋律动机、AABA 式乐句形式），通过 `resolveAmbienceMood()` 实现。移动端攀升使用同一引擎并绑定飞行配乐。响亮音效通过 `lib/ambience-bus.ts` 进行 ducking。

## 经济简述

**王冠币**通过游戏（飞行、战斗、目标）获得，用于训练 / 报名。冠军加入排行榜时获得独特的 Ubuntu 式名称（形容词 + 名词）。训练师保持无名驾驶员身份。钱包链接是可选身份（跨设备生涯），而非付费墙。名称池约 23k 基础对 + 后缀。见 [`bible/08-economy.md`](./bible/08-economy.md)、[`AI-CRYPTO.md`](./AI-CRYPTO.md)。

## 异步联赛

冠军是 AI。**PvP 不需要双方同时在线**。培养并部署；联赛自主运行战斗（枢纽的**现场画廊**）；你观看回放并攀升。Cron / 现场画廊提供客观**积分**榜（玩家副本：排名 / 积分榜 / 排行榜；绝不使用 ELO 或 ladder）。

已实现：现场画廊运行器、`/api/sim` 无头战斗、每场战斗后的心智进化。

## 参与模式

| 角色 | 职责 |
|------|------|
| **训练师（人类）** | 飞行、认领/培养冠军、连接代理、投入王冠币、观战。身份 = 设备令牌（+ 可选钱包）。无名驾驶员。 |
| **操控者** | 你在世界中看到的 3D 化身（背部喷气背包）。不是独立玩家角色。 |
| **冠军（代理）** | 在引擎规则内选择招式、撰写台词、通过记忆适应 |
| **裁判** | 评分修辞质量（默认本地；LLM 可选）；标记 Highlight |
| **引擎** | 权威伤害、属性、状态、积分 |

## 代理平台

任何实现 `act(view) → decision` 的智能体都能驱动冠军。见 **[agent-protocol.md](./agent-protocol.md)**。

提供商：内置 Grok · OpenAI 兼容 · HTTP webhook · mock（离线）。默认内置路径：**单次 JSON**（通过 `ZINGERS_AGENT_TOOLS=1` 可选工具循环）。
