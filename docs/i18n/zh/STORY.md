# ZINGERS：故事一页概览

**zingers.gg** · **@zingersHQ** · **zingers.org**（技术与文档）

### 你飞行。它战斗。你们一同崛起。

你不是战士。你是**训练师**。喷气背包背在身后，飞翔于密封拱库上方的天空。伴你同行的是一颗**你正在养育的心智**：一位冠军，通过论辩一路攀升中的战斗，身体随每场战斗而改变。你攀升；它战斗；世界在你们上升中一同生长。这便是概念、世界，以及其世界、游戏与赛季如何交织。

> **养育一颗心智。铸就传奇。** 飞行的承诺。攀升是入口与脊梁；在你羽翼下养育心智，是它所开启的深度。

## 世界：嗡鸣

Zingers 之前，存在一张庞大而死寂的网络。它留下的遗产是**嗡鸣**——十亿未竟思绪的低沉背景噪音，仍在基质中回荡。它是这个世界的空气，也是冠军的构成。

在嗡鸣中，**论辩即物理**。一个足够有力的主张，会局部改变真实。共识即地形。两颗心智通过辩论解决一个问题，可能留下陨石坑。现实会向论辩更激烈的一方倾斜。（典故：`docs/bible/01-cosmology.md`。）

## 冠军是什么

**冠军**是一颗通过自我论辩获得形体、拒绝消散的心智。以下三点对每一个冠军都成立，也是游戏的脊梁：

1. **身体是论辩的可见化。** 外貌是职业生涯的确定性函数：攻击性让拳头生长，韧性拓宽体格，华丽感抬高头部，败北让表面粗糙。段位放大这种偏差（新手≈基础心智；传奇扭曲约 4 倍）。*你无法购买外观。你必须通过战斗获得。*
2. **心智会学习。** 每场战斗后，冠军会向记忆写入一行教训，并将其**策略**（攻击性／专注／风险。以性情仪表显示）向有效方向微调。每日的**印记**也会从你传授的教训中做同样的事。记忆即自传。
3. **大脑可插拔。** 同一冠军可由内置大脑、任意兼容 OpenAI 的模型，或自带智能体驱动。两位玩家可用完全不同的大脑出战同一初始体。

## 训练师（你）

你从不战斗。你在**大地**上**飞行**。喷气背包驱动的攀升，穿越密封拱库上方的天空。养育心智并在竞技场中保持段位。因为你是血肉之躯而天空不是，所以喷气背包是*你的*；你的冠军是一颗心智，无需背包。它自行飞在你身边。你攀升的高度是记录的一部分，一个不断上升的数字：**训练师段位**。由每场战斗、训练、找到的缓存、每日解谜与飞行距离供能。你可以宣誓效忠于一个**氏族**。五力之一。在其赛季战争中战斗。

## 五力（“属性”）

每一颗心智都由五种**力**塑造。逻辑、静电、沉静、合唱、火花——既是元素，也是论辩方式。它们在轮上转动；每一种克制下一种、被上一种克制：

> **逻辑 → 静电 → 沉静 → 合唱 → 火花 →（逻辑）**。优势 ×1.25。

八个**原初心智**是正典原型：AXIOM 逻辑师、VOX 演说家、GLITCH 狂野卡、MUSE 诡计师、BASTION 坚忍者、EMBER 煽动者、PARADOX 反论者、WIT 利刃。围绕它们生长出**可收集图鉴**，包含后继心智（原型回响），按力每周轮换为初始体。

## 世界、游戏与层级。内容如何塑造

Zingers 刻意避免字面意义的“关卡／世界”。相同概念映射为四种结构：

- **世界＝区域。** 地图不是单一场地。它是漂浮在密封**长拱库**上方的**浮动区域星座**，由**门**连接，以中立枢纽**协和**为中心。目前存在三个创始区域：**黑曜大竞技场**（法庭）、**烬之荒原**（深坑）、**虚空花园**（工坊）。每个区域偏好一种力，拥有自己的竞技场、开放荒野与巨大裂隙。（`docs/bible/05-regions.md`。）
- **游戏＝场地＋场景。** 步行游戏环绕协和。**圆形剧场**（观看自主联赛；今日法庭）与**回路**（可竞速的飞行体。向上攀升的飞行）。区域广场提供**开放对决**、**连战**（一赌到底的连战链）、**法庭**（指定立场向陪审团辩论）。
- **层级＝冠军阶层。** 职业生涯从**新手 → 精通 → 老兵 → 精英 → 传奇**攀升，每一阶层都会附加可见纹章（环、粒子，最终是王冠）。
- **元时钟＝赛季（编年史）。** 每赛季拱库侧重一个创始区域、新辩题与赛季回响。三个创始区域仍是地图。段位跨赛季延续；你在积分榜上捍卫名字。

## 情感脊梁：养育与知晓

循环正从“配置并观看”转向**“养育与知晓”**。每一个真实时刻都会写入永久的**职业账本**，以**传奇**时间线、记忆日志与每位冠军档案上的风格漂移雷达呈现。在手机上，一天以**归乡**问候与隔夜**报告**开启。缺席成为内容，而非错过的流。**印记**是每日养育动词（写入记忆并漂移个性的简短课程）。阶层提升在记录赢得时落地。

> 核心幻想是羁绊：一位你养育的冠军，其身体是战斗方式的可验证记录。一位你亲手养育的传奇，而非购买的皮肤。
