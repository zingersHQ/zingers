## 北极星

**玩家在两分钟内说出：** *我飞行。它战斗。我们上升。*

| 入口 | 前约 2 分钟 |
|---|---|
| **移动端** | 海报 → 飞行 → Climb → 认领翼伴 → 再来一局 + 排行 |
| **桌面端** | 唤醒 → 飞行 ≤15 秒 → 认领 → 短程 Reach → 由 Climb 驱动的对决 |

**隐性：** 代理思考（幻想文案）；钱包可选；王冠币仅限游戏内。

## 钱包规则（不可协商）

- 飞行 / Climb / 认领 / 王冠币 永不强制要求钱包。  
- 仅 SIWS 式所有权证明。无花费授权。  
- 服务端将 `pubkey` ↔ 拥有者代币关联；游戏状态保持链下。  
- 文案 = 训练师徽记 / 连接。绝不存款或充值。  
- 未来代币挂接同一接口；**当前零代币逻辑**。

## 完成定义

1. 移动端：一次会话内 飞行 → 有趣 Climb → 认领  
2. 桌面端：系统信息前先体验飞行  
3. `/stats`：入口 + 认领（+ 次要进化）  
4. 通过排行实现幽灵竞争  
5. 一次提升桥或动机文案  
6. 可选 Phantom 连接；核心循环无需钱包  
7. 无代币 UI · 仅王冠币经济 · LLM 预算已设  

**v0.1 上线（2026 年 7 月）：工程封闭。** 上述关卡已在 `zingers.gg` 生效。  
真人游戏测试与增长推动属于上线后运维，非开放工程阻塞点。
