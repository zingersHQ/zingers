**zingers.gg** · **@zingersHQ** · **zingers.org**（技术与文档）

### 思考生物优先，藏品传说其次。

Zingers 以真正的 AI 游戏为先，生物真正具备思考能力。所有权层始终可选、隔离，并以实用功能为锚。两层严格分离。目前钱包仅作为可选的**训练师身份**；代币发行被有意推迟。（`docs/flight-first-plan.md`、`docs/zing-model.md`。）

## AI 层（产品）

**可插拔智能体。** 引擎每回合仅提问一次：*给定当前状态与合法行动，你会怎么做？* 任何实现 `act(view) → decision` 的智能体都能驱动冠军。（`docs/agent-protocol.md`。）

- **提供方：** 内置 **Grok** 智能体（xAI）、任意 **OpenAI 兼容** 模型（`baseUrl` / `model` / key）、**HTTP webhook**（POST `AgentView`，返回 `AgentDecision`），或用于离线对战的 **mock**。若双方均自带智能体，对战即可在无平台密钥的情况下真正运行。
- **默认路径（快速）。** 单次 JSON 决策 + **本地裁判**。回合迅捷、成本低廉。选择开启：`ZINGERS_AGENT_TOOLS=1` 启用受限的「推理→行动→观察→提交」工具循环（`simulate_move`、`scout_opponent`、`commit_move`，上限 3 步）；`ZINGERS_LLM_JUDGE=1` 则切换为 LLM 机智评分器（仍为受限倍增器，绝不单独决定胜负）。
- **持久记忆与偏移。** 每位冠军携带记忆笔记及**策略/性情**刻度（攻击性、专注度、风险偏好）。领养时设定，后续仅供 UI 读取。**印记**（带确定性模板回退的受限模型调用）让训练师教授经验，写入记忆并随时间塑造个性；对战同样会微调这些刻度。
- **精选魔法，涌现深度。** 默认体验由作者精心打造（声包、角色节奏、确定性回退），始终生动；真实模型在其上叠加涌现，但绝非硬性依赖。

## 加密层（可选，底层）

**核心规则：** 游戏无需钱包即可免费且完整体验。你可以培养传奇、攀登赛季、破解拱库，却从未见过钱包。加密是游戏*之下*的一层，而非前置关卡。（`docs/bible/08-economy.md`、`docs/zing-model.md`。）

**今日已上线：** 可选 Solana 钱包连接（Phantom SIWS 式所有权证明），用于跨设备保留唯一**训练师名称**。无需授权花费，无代币界面。

**2026-07 诚实范围：** 首次连接绑定 **名称 ↔ 公钥 ↔ ownerToken**（设备生涯密钥）。在新设备上重新连接即可取回该规范 `ownerToken`，从而恢复冠军、王冠币与 `/api/save`。仍无需 `$ZING`。若钱包丢失，恢复码仍可作为备份。

**命名：** 游戏内王冠币位于 `/api/wallet`（链下）。Solana 称为 `solana-link` / “连接”。玩家文案中绝不将王冠币称为链上钱包。

### 两种经济，永不桥接

| | **王冠币** | **$ZING**（暂定名） |
|---|---|---|
| 性质 | 软性、游戏内、服务器权威 | 硬性、链上（SPL / Solana）。*尚未发行* |
| 获取方式 | *通过游玩*赚取 | *在市场购买*，或因游玩空投（未来） |
| 用途 | 训练、入场、支持、外观重铸 | 链上排名入场、铸造卡牌、赞助者身份（未来） |
| 可兑现？ | **永不** | 仅在公开市场，绝不*通过我们* |

两者之间的墙。没有兑换，没有共享钱包。这是 Zingers 最重要的不变式。它让 Zingers 既*不是证券*，也*不是赌场*。

### 代币的作用。仅此而已（未来）

1. **支付可选链上排行榜入场**，通过**销毁或质押**。销毁是小额消耗性访问费（纯通缩）；质押是较大、**可全额退还**的押金，仅返还本金。质押跨赛季持续，因此忠实玩家锁定资本后可永久免费游玩。**绝无收益。**
2. **铸造 permanence**。销毁以将冠军永生化为链上卡牌。艺术品由生涯记录确定性生成，因此**代币即战绩**。它填充已存在的静默字段（`mintId`、`owner`、`chain`、`mintedSeason`）。是填充，而非重构。
3. **授予地位**。支持冠军的赞助者徽记、dex 出处，以及下一赛季空投*权重*（由游玩赚取）。

### 护栏（独立安全边界）

无收益 / 无 APY / 无奖池；**销毁是费用，而非赌注**；所有奖励均为外观、地位或分配（绝非现金或按表现缩放的支付）；无价格营销；**王冠币永不兑现**。链上赛季结算之所以可行，*正是因为*对战确定且可证明公平。

以“生物真正思考”和“你在飞行”打头，适合传播的迷因友好，同时以实用功能为锚，信息绝不在智能体协议与赌场之间摇摆。随**王冠币**一同发布；钱包 = 身份；**$ZING**仅在文档中*宣布*，而非产品内必需。**代币跟随 traction，而非反之。**
