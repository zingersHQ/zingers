# 长局：Zingers 为什么在 40 分钟后结束，以及如何阻止

> **状态：已上线 0–6 阶段（2026 年 7 月）。** 设计圣经的配套文档。  
> 面向玩家的「飞行」设定见 [`bible/10-ascent.md`](./bible/10-ascent.md)；命名规则见 [`vocabulary.md`](./vocabulary.md)。配套文档：  
> [`design-vision.md`](./design-vision.md)、[`essence.md`](./essence.md)、[`flight-first-plan.md`](./flight-first-plan.md)。

本文只回答一个问题：**玩家在多久后会耗尽继续玩的理由？我们需要改动什么？**  
以下阶段除特别标注外均已上线。

---

## 1. 真实时钟

按当前版本对冷启动玩家的估算：

| 时间窗口 | 时长 | 结束原因 |
|----------|------|----------|
| 首次游玩 | **35–45 分钟** | 飞行 → 认领 → 一场战斗 → “……现在做什么？” |
| 第 2 天 | **约 8 分钟** | 每日任务、一次飞行后关闭 |
| 第 4 天 | **约 0 分钟** | 没有理由再回来 |
| 深度绑定玩家 | **每周 3–5 小时** | 真正的高分拉力（前提是手感到位） |

这听起来像是一款内容贫瘠的游戏。  
其实不是。见 §2。  
问题出在**表面可读性**：内容已经存在，但玩家从未发现它们存在。

## 2. 实际已完成的内容（惊喜）

对线上代码（而非文档）的审计显示：

- **飞行**：10 个「领域」共 100 个扇区，含危险、营地、初光宝箱、王冠币缓存、侦察、幽灵、分享链接、2500 王冠币的「百人钱袋」。  
  （`components/grounds/climb/*`、`lib/climb-campaign.ts`）
- **冠军**：首批「心智」+ 已烘焙图鉴（第 6 阶段第 1 波）、五角属性、5 个阶层、职业衍生体型 + 表型、传奇账本、印记。  
  （`lib/engine/roster.ts`、`lib/minds/baked.ts`、`lib/imprints.ts`、`lib/evolve/*`）
- **回归钩子**：每日战斗、每日缓存、赛季目标、28 天赛季、氏族战、预测连胜、通过定时任务自运行的全球积分榜、导演引导、解锁轨迹、翼部特质、状况、远征。
- **已搁置**：5 名「守护者」已完整编写并测试，通过 `KEEPERS_PLAYABLE = false` 关闭（`lib/features.ts`）。另有一款带类型与商店钩子的「宅邸」游戏，但无 UI。

这些内容相当于**在首 30 分钟内就提供了约 15 小时的内容**，却几乎不可见。问题从来不是体量。

## 3. 诊断：四项结构性缺陷

1. **没有指向「下一步」的指引**。没有任何函数回答「我现在该做什么？」所有钩子都必须先知道才能发现。
2. **开局即全开放**。所有区域、所有场景、全部 100 个扇区、全部 8 名招募者。15 小时的揭秘在瞬间耗尽。真正「长」的游戏大多只是把更好的东西藏起来。
3. **养成对实际动词没有可见影响**。训练花费 60 王冠币，却只移动三个看不见的刻度。玩家从未看到一次飞行或战斗因养成而产生不同。
4. **重复动词缺乏变化**。每次飞行都一样，每次战斗都一样，只是文案不同。

## 4. 标尺（别再拿宝可梦做对比）

宝可梦与塞尔达是**内容量级**游戏，由数百人手工打造世界。我们在这一赛道已永久落后，对比只会制造绝望。

我们的真正同类是：  
**Balatro**（一张牌戏，约 150 种修饰，数百小时）、**吸血鬼幸存者**（单一机制 + 解锁树）、**足球经理**（没有世界，只有职业摩擦）。  
三者都用极少资源，通过**局内变化、逐步解锁、带后果的职业状态**，榨出巨量时长。

**目标**：首月 10–15 小时，每天真实 8–12 分钟的回归理由。  
不是塞尔达。只要把现有资产利用率提升 5–10 倍即可，无需新美术。

## 5. 方向决策（创始人，2026 年 7 月）

> **飞行即游戏。冠军即存档。战斗是标点。**

反复阅读 LLM 辩论稿的新鲜感会在重复中消散。深度应放在玩家真正操作的地方——飞行。这不是放弃冠军，而是**因果倒置**：

| | 今天 | 之后 |
|---|---|---|
| 飞行 → 冠军 | 深度盖印 | 不变（保留） |
| 冠军 → 飞行 | **无影响** | 你飞行的心智**改变飞行方式** |

一旦养成成为对「实际动词」的构建系统——操控、侦察范围、第二条命、金币拉力、危险判读——「养成心智」就不再是侧边标签，而是继续养成的理由。这正是「宝可梦感」（组队、意义选择、可见后果）被迁移到正确动词上。

战斗保留：「你飞，它打」是差异化点，异步联赛是玩家睡觉时仍在运行的内容。但它们将被**压缩为可一眼看清、带赌注的已解决时刻**，绝不出现大段文字。守护者保持关闭；一个被关闭的文字游戏不是免费内容。

## 6. 计划

按投入产出比排序。每阶段均可单独上线。

### 阶段 0. 导演 *(1–2 天)* ✅ 已上线

一个纯函数，读取现有存档状态，用一行文字 + 一个按钮回答「现在做什么？」，渲染在玩家落地的每一处界面。不创造内容，只让已有内容可见。  
`lib/director.ts` + `components/director/*`。

### 阶段 1. 解锁轨迹 *(3–5 天)* ✅ 已上线

一条训练师轨迹，所有活动均会推进。每级按名称开放内容：分批开放领域、然后是法庭、连战、掮客、第二区域、招募位、侦察。不是新内容，而是定量供应。把现有构建重构为 15 小时的揭秘，并给导演一个可指向的脊柱。

上线模块：`lib/unlock-ladder.ts`。已在飞行天花板（移动端 + 桌面）、枢纽大门、掮客、侦察、招募位强制执行；导演主/次提示可指向下一个命名之门。领域 II 的深度证明门保持不变。已飞过的深度已 grandfathered，避免现有存档被软锁。

### 阶段 2. 冠军 → 飞行因果 *(1–2 周)* ✅ 已上线（v1）

§5 的核心。每个冠军授予**翼部特质**，可实际改变飞行；印记与里程碑可教授新特质；玩家在起飞前选择负载。把 8 个心智变成 8 套负载空间，让每一次养成都在真正重要的动词上获得回报。

上线模块：`lib/wing-traits.ts`。每种「力」类型 1 个**固有**特质 + 最多 1 个**获得**特质（轴/营地/性情）。效果：生命、金币几率、滑翔、踉跄、侦察营地加成、巡航速度。通过 `ascentSessionMods` 同时作用于飞行体。准备条显示 `WINGS · …` 与已获得切换。

### 阶段 3. 状况 *(3–5 天)* ✅ 已上线（v1 飞行）

一种数据驱动的修饰符，可作用于飞行或战斗：稀薄空气、迷雾、侧风、一条命、双倍金币、无侦察、敌对人群、突然死亡。二十多个状况只需一天写作 + 引擎钩子，就能让所有现有表面乘以倍数。这是目前最纯粹的参数化收益。

上线模块：`lib/conditions.ts`。13 个按排名排列的每日天空（UTC 日轮换），在翼部特质之后通过 `mergeRunMods` 合并。侦察练习保持「晴空」。准备条显示 `TODAY · …`；导演可将天空作为次要提示。战斗侧状况暂缓。

### 阶段 4. 职业摩擦与传承 ✅

上线模块：`lib/career-friction.ts`、`lib/legacy.ts`。形态/疲劳/伤痕在翼部 + 状况之后叠加到飞行（`applyCareerToMods` 作用于攀登 + 回路）。对手章节通过 `maybeEscalateRival` / `currentRival` 逐步升级。退役会封存传奇 + 为下次认领留下传家翼部特质（`retireOwned` → 长拱库）。导演会轮换已耗尽/损坏的马厩，并将「面对 / 退役」作为次要提示。

### 阶段 5. 远征 ✅

上线模块：`lib/expeditions.ts` + `lib/server/expedition.ts` + `/api/expedition`。  
UTC 周路线：种子（通过 `climbSector(i, seed)` 生成布局）、一个状况、20 个扇区、每个体型独立排行榜。攀登 + 回路模式为 `expedition`。无营地，经验/王冠币按比例。准备条显示 `WEEK · …`；导演可作为次要提示。#1 幽灵暂缓（`lib/climb-ghost.ts` 中编解码器已就绪）。

### 阶段 6. 批量内容 ✅（图鉴第 1 波已上线）

离线流水线：`content/minds/reviewed/*.json` → `npm run bake:minds` → `lib/minds/baked.ts`，合并进 roster / banter / beats / first-duel / showcase。  
波次工具：`npm run forge:dex`（精选名称库 + 语音套件）、`npm run generate:minds`（可选 XAI 草稿）。首批手工烘焙：**STILL**、**KEEL**、**PRISM**、**FABLE**。第 1 波在顶部锻造了相当于初代规模的可收集集合（见 `docs/bible/03-champions.md`）。新手阶层提供表型部件目录 + 物种标记，让同「力」心智读作不同动物。无新 GLTF。后续波次 = 更多已审核 JSON + 重烘焙 + 部件套件扩展。

## 7. 明确非目标

- **第四区域**。它很便宜（一个 `BiomeConfig` blob + 自然预设），这正是陷阱。三个没有工作的区域变成四个没有工作的区域，空虚只会变得更大、更亮。区域应先有「工作」，再考虑兄弟。
- **重新开启守护者**作为填充。它们只会在重新设计为「表演」而非「文字稿」时才回归。
- **任何破坏「飞行优先」手感门槛**的东西。在核心动词手感不佳的情况下堆叠留存支架，只会制造一个清晰可见的空排行榜。手感工作（见 [`flight-first-plan.md`](./flight-first-plan.md)）必须优先于此处的一切。
