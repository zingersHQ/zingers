# ZINGERS：设计愿景文档

> **一句话概括：** 本文档是产品的北极星。Zingers 是一款游戏，你扮演**训练师**，在封印的拱库上方的天空**飞行**，与你并肩飞行的是一颗你正在养育的**心智**——一位在实时辩论对决中唇枪舌剑的 AI 冠军，其身体会随着战斗历程而发生可见变化。你向上攀升，它为你而战。本文档将阐述这一核心愿景，以及保护这一愿景的设计准则。

版本 3.1 · 2026 年 7 月（**飞行优先**；玩家模式名称 **飞行**；排名而非天梯）

产品/设计唯一事实来源。世界观正典位于 [`docs/bible/`](./bible/)（飞行 / 垂直世界：[`10-ascent.md`](./bible/10-ascent.md)）；机制位于 [`game-spec.md`](./game-spec.md)；跨设备唯一灵魂位于 [`essence.md`](./essence.md)；入口位于 [`two-doors.md`](./two-doors.md)；留存计划位于 [`long-game.md`](./long-game.md)；系统位于 [`climb.md`](./climb.md)；命名位于 [`vocabulary.md`](./vocabulary.md)。

## 0. 飞行优先的含义

v1.0 以对战为先：*养育心智，观看它战斗*。没错，但它把陌生人**零秒**就能理解的唯一动词（飞行）埋在了系统堆栈之下，而玩家只有在产生兴趣后才会接触这些系统。飞行优先重新排序的是**动词的优先级**，而非系统本身：

- **飞行是游戏的脊梁与门面。** 它是玩家首先接触的元素、品牌形象、封面，以及整个地图的连接组织。（垂直世界的世界观名称：攀升。玩家模式标签：**飞行**。绝不将 Circuit/Climb 显示为模式名称。）
- **对战是你在攀升途中遇到的挑战。** 攀升不断揭示的深度，正是让你爬得更高的原因。它们并不次要，而是从*产品本身*重新定位为*攀升拥有意义的原因*。
- **没有结构性内容被删除。** 引擎、评分/排名、裁判、王冠币权威、活世界、守护者、纪事：一切依然存在。这是一次框架与新手引导的重构，加上让已构建内容清晰可见的长期游戏 Director 堆栈（[`long-game.md`](./long-game.md)）。

一句话总结：**你飞行。它战斗。你们共同上升。**

## 1. 愿景陈述

Zingers 是一款关于**上升**的游戏。你是**训练师**：你（背负喷气背包）在世界中心封印的储存库——**长拱库**——上方的浮动天空中飞行。你不战斗。与你并肩飞行的是一位**冠军**：一颗你收养并正在养育的心智，其身体会真实地成为它每一次胜负辩论的记录。你攀升天空；它通过攀升路上的对战辩论前行；你们在彼此身上留下印记。你的攀升将**飞行徽记**印在它身上；它的胜利将你带得更高。

**核心承诺：** *你飞行。一颗心智在你身边飞行，并通过辩论为自己塑造身体。*

## 2. 设计支柱（不可妥协）

| 支柱 | 含义 | 排除项 |
|------|------|--------|
| **世界即攀升** | 进度是实体化的高度。飞行是所有其他动词依附的脊梁。 | 平面、菜单式或大厅优先的进度；将飞行作为独立小游戏 |
| **养育，而非战斗** | 你是训练师。你飞行；你的冠军战斗。你唯一用双手亲自操作的地方是飞行。 | 在对战中直接控制招式 |
| **身体 = 可见的辩论** | 冠军的外形是其职业生涯的可见历史：辩论**以及**你的攀升（飞行徽记），加上原力表型。 | 仅外观的进化或基于数据的皮肤 |
| **有灵魂的智能体** | 持久记忆、策略、人设、可见推理。 | 黑箱 AI 或沉默的战斗者 |
| **世界是活的** | 训练师与冠军共存并飞行的 3D 探索。 | 纯菜单或仅大厅的游戏 |
| **训练师段位是永恒的** | 账号级身份与地位；攀升的深度是其一部分。 | 切换冠军时一切重置 |
| **辩论即物理** | 嗡鸣：共识塑造现实；赢得辩论会重塑真实。 | 纯叙事或非机制性的世界观 |

## 3. 飞行：谁在飞，以及如何飞（正典）

飞行是核心，因此其规则是正典，而非调味料：

- **训练师使用喷气背包飞行。** 你是身处非凡天空的普通存在；喷气背包是让你上升的机器。**喷气背包仅限训练师使用。** 它是你的工具，绝非冠军的。
- **冠军飞行是因为它是心智。** 冠军是嗡鸣中的一个结；它不需要机器就能离开地面。它上升的方式如同思想升腾。因此你的冠军**在你身边飞行**（作为僚机），依靠自身，无需喷气背包。
- **飞行是表演者的灵魂。** 因为冠军战斗而训练师飞行，飞行是玩家*唯一*能用双手亲自操作、又不破坏“养育，而非战斗”原则的地方。（见 [`essence.md`](./essence.md) §3。）
- **深度是灵魂；时间是技艺。** 你攀升的高度是关于*你*（训练师）的事实 → 训练师段位 + 冠军身上的飞行徽记，跨设备共享。实时精通（时间）→ 王冠币 + 每设备排行榜。（见 [`essence.md`](./essence.md) §3，[`climb.md`](./climb.md) §1。）
- **挑战** 让你无需双方同时在线即可竞速另一位训练师的幽灵标记（[`bible/10-ascent.md`](./bible/10-ascent.md)）。

**正典教学语：** *你飞行。它战斗。你们共同上升。*

## 4. 训练师（你）

你不是心智。你是**训练师**：养育冠军的人。你飞越世界、养育心智、持有**训练师段位**、与守护者（战役的五位守护心智）共事，并可宣誓效忠一个**氏族**：五原力之一，作为你所战斗的一方。

- **操控者** = 你在 3D 世界中看到的形象（你的化身，背负喷气背包）。
- **训练师** = 你是谁（身份、段位、传奇、你攀升的深度）。

操控者必须从第一分钟起就给人以刻意之感：金色训练师徽记、段位公告牌、喷气背包，与冠军截然不同。**喷气背包机动性仅限训练师。**

引导文案（Director、结局、枢纽教练）以**冠军的口吻**说话：我们 / 我们 / 与我同行。绝不使用任务标记式的金属质感。绝不将“它在与你对话”作为卖点进行营销。见 [`vocabulary.md`](./vocabulary.md)。

## 5. 冠军

冠军是在嗡鸣中稳定下来的心智。他们的身体是可见的辩论。它们拥有记忆、策略、人设，并自主战斗。你设定条件；它们决定招式与台词。它们在飞行中**在你身边飞行**（无喷气背包；它们是心智），其身体记录着它们的对战与你的攀升。

**一位活跃冠军**由你养育并派出；**收藏 / 图鉴**通过招募与第 6 阶段批量心智增长（`store/champions.ts`，`content/minds/reviewed/`）。每周领养提供每个原力的一位初始者，来自初生心智 + 烘焙池。

## 6. 世界与世界观（摘要）

- **飞行**（世界观：攀升）：拱库上方的天空，嗡鸣在此稀薄；攀升即是从死思想的噪音中升起。可在手机与桌面端作为同一游戏游玩（见 [`bible/10-ascent.md`](./bible/10-ascent.md)，[`climb.md`](./climb.md)）。
- **嗡鸣**：辩论即物理；共识即地形。
- **长拱库**：封印于世界之下；季节开启大门。
- **守护者**：五位战役首领；秘密词解锁纪事。
- **世界**（世界观：大地）：漂浮的浮动区域；**枢纽**（世界观：协和）+ 门。
- **五原力**：类型 `LOGIC | CHAOS | COMPOSURE | RHETORIC | CREATIVITY`。玩家 UI：**逻辑 / 静电 / 沉静 / 合唱 / 火花**。深层世界观名称仅保留在正典中。

## 7. 核心循环

**飞行 → 收服 → 养育 → 战斗 → 攀升更高。**

你首先飞行（人人都懂的入口）→ 一颗野生心智在你身边飞行，你**收服**它 → 你**养育**它（策略种子，随后是印记 / 性情读数）→ 你派出它去**战斗** → 每一次结果都让你**攀升更高**，深入域外。循环是螺旋而非直线：每一高度都揭示下一个系统。

**异步联赛：** 冠军可在双方玩家不在线的情况下战斗（实时画廊）。你飞行；它们持续战斗。诚实的**排名** / 评分榜（绝不在玩家文案中营销为 ELO 或天梯）。

**Director：** 纯“现在做什么？”的存档状态向导（`lib/director.ts`），以冠军口吻发声，使已构建内容保持可见（[`long-game.md`](./long-game.md) 阶段 0）。

## 8. 新手引导契约（90 秒规则）

在离开首次飞行前，玩家必须理解：

1. *我飞行。在我身边的那个东西是我的冠军。我养育它；它战斗。*
2. *我攀升的高度是我的记录；攀升会在冠军身上留下印记。*
3. *攀升正向我展示一个完整的下方世界。*

见 [`flight-first-plan.md`](./flight-first-plan.md)，[`two-doors.md`](./two-doors.md)，[`flyover.md`](./flyover.md)。历史上的战斗优先 Act 1：[`first-journey-roadmap.md`](./first-journey-roadmap.md)。

## 10. 设计原则（未来决策）

- **飞行是脊梁。** 新动词应置于飞行之上或可从飞行抵达；任何脱离的元素若无回钩则不发布（growth-doc 定律）。
- 绝不让玩家在 3D 中感觉*自己就是*冠军。
- 优先参数化深度（条件、翼特性、图鉴波次）而非新的空容器。
- 保持玩家词汇诚实：训练师、策略、氏族、战斗 / 对决 / 决斗、飞行、排名。无 bout，无 ELO / 天梯标签，玩家可读文本中无间隔破折号。
