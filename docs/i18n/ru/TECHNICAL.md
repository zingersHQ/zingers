# ZINGERS: Техническая сводка

**zingers.gg** · **@zingersHQ** · **zingers.org** (технологии и документация)

### LLM: это актёр. Движок: это игра.

Единое типизированное приложение Next.js. Один рантайм, без отдельного бэкенда, который нужно постоянно поддерживать. Приложение запускает 3D-мир, в котором вы **летаете**, транслирует живые дебаты ИИ против ИИ и развивает чемпионов на основе их реальной истории матчей (и того, насколько высоко вы поднялись).

---

## Основной принцип

Бой пошаговый, с явными ходами и **разрешением на основе характеристик**: урон определяют статы, типы, тренировки, статусы и случайный разброс по сиду. Качество остроумия: ограниченный множитель (≈0,7–1,3, 1,4 при Хайлайте). По умолчанию используется **локальный судья**; включить LLM-судью можно флагом `ZINGERS_LLM_JUDGE=1`. Ни один из путей не может единолично решить исход матча. Это сохраняет бои честными, воспроизводимыми и недорогими.
*(`docs/game-spec.md`, `docs/combat-design.md`.)*

## Стек

Next.js 16 (App Router) · React 19 · сквозной **TypeScript** · **React Three Fiber** (с Drei, физикой Rapier, постобработкой) для 3D-основы · **Zustand** для состояния · **Upstash Redis** как зеркало сервера · **Server-Sent Events** для живых боёв · **xAI (Grok)** как встроенный мозг. Развёрнуто на Vercel (`zingers.gg`: игровой хост, `zingers.org`: хост документации), с кроном `/api/cron` каждые 6 часов.

## Архитектура. Один мир, тонкий сервер

- **The Ascent: это лицо.** Мобильный Climb (`/m`) и десктопный Circuit делят одно небо из 100 секторов (десять Reaches). Тренер летает с джетпаком; чемпион-крылатый напарник следует без него. Доски, жизни, открытие секторов. См. `docs/climb.md`, `docs/bible/10-ascent.md`.
- **3D-основа**: глубокая поверхность: летайте, поднимайтесь, охотитесь за целями, заходите в заведения. Тела меняются в реальном времени в зависимости от карьеры через детерминированную функцию внешности (`lib/evolve/appearance.ts`). Производительность: экспоненциальное затухание (независимо от частоты кадров), инстансированные пропсы GLTF, `React.memo` для декора сцены, кэшированные текстуры палитр, уровни DPR/качества и «сок» (тряска, толчки FOV, вспышки), ограниченный `prefers-reduced-motion`. На мобильных ровно **один** WebGL-канвас.
- **Бои транслируются через SSE** (`/api/battle`, плюс headless `/api/sim`). Каждый ход несёт сам ход, посчитанный урон, реплику в характере, понятное объяснение `why` и (при включённых инструментах) массив `trace[]` шагов агента. По умолчанию: **одно решение LLM за ход** + локальный судья. Быстро и дёшево. Клиент рендерит с пропуском до вердикта и опциональным видом «Study» для трассировки.
- **Музыка**: 100 % процедурная Web Audio (`lib/ambience-scores.ts` + `lib/ambience.ts`): разные темы для разных локаций с фразовыми формами; интенсивность, дакинг и украшения через `lib/ambience-bus.ts`. Без аудиофайлов.
- **Асинхронная лига**: главная механика: чемпионы: ИИ, поэтому PvP не требует присутствия человека. Лига проводит бои автономно (Amphitheatre **Live Gallery**); вы смотрите реплеи и поднимаетесь по объективной рейтинговой таблице (`/standings`).
- **Состояние клиентское, с синхронизацией.** Карьеры хранятся в `localStorage` и зеркалятся в Redis через `/api/save`. **Леджер карьеры** (`CareerEvent[]` + `AxisSnapshot[]` в `PlayerSave`): чисто добавочный, ограниченный, append-only лог каждого реального момента. Бой, левел-ап, тир-ап, тренировка, взлом Хранителя, смена сезона, первый клейм. В `store/champions.ts`.
- **Идентичность тренера.** Уникальные имена можно привязать к опциональному кошельку Solana (только доказательство владения. Без трат). Доски Circuit/Climb разрешают метки на стороне сервера.
- **~25 API-маршрутов** (`app/api/*`) покрывают бой, симуляцию, клейм, ростер, standings, daily, хранителей (Keepers), импринт, фид, войну, сохранение, кошелёк, solana-link, OG-картинки карточек и счётчик `/api/cost`.

## Плагинный слой агентов

Каждый чемпион отвечает одному контракту. `act(view) → decision`. Поэтому любой мозг может управлять чемпионом. **По умолчанию:** одноразовое JSON-решение. **Опционально** (`ZINGERS_AGENT_TOOLS=1`): ограниченный цикл **reason → act → observe → commit** через read-only инструменты движка (`simulate_move`, `scout_opponent`, `commit_move`), максимум 3 шага, поток `ToolStep`. Провайдеры: встроенный Grok, любая модель, совместимая с OpenAI, HTTP-вебхук или мок (оффлайн). *(`docs/agent-protocol.md`.)*

## Ограничения стоимости и безопасности

Расходы на LLM метрируются (`lib/server/cost.ts`), ограничиваются по IP (`lib/server/rate-limit.ts`) и суточными бюджетами (`LLM_DAILY_BUDGET_USD`). Новые функции моделей всегда поставляются **сначала с шаблоном**: детерминированный фолбэк срабатывает, когда нет ключа, превышен дневной лимит владельца или исчерпан бюджет. Поэтому **ежедневный цикл никогда не блокируется моделью.** Рейтинговые пути отклоняют мок/сид-бias; заработки кошелька ограничены клеймом.

## Детерминизм как фича

Бои используют RNG с сидом (`lib/engine/xai.ts:makeRng`), поэтому любой бой воспроизводим и доказуемо честен. Этот инвариант: также предпосылка для будущего on-chain закрытия сезона (см. one-pager по ИИ и крипте). Ключи аналитики/событий могут внутри по-прежнему говорить `bout`. В текстах для игроков этого слова нет (`docs/vocabulary.md`).
