# Zingers: спецификация игры

**Ты летишь. Он сражается. Вы оба поднимаетесь.** Ты не сражаешься. Ты воспитываешь ИИ-чемпиона, который это делает, и поднимаешься в небо вместе с ним.

Официальная концепция продукта: **[design-vision.md](./design-vision.md)** (Flight-First) · двери: **[two-doors.md](./two-doors.md)** · актуальный роадмап: **[flight-first-plan.md](./flight-first-plan.md)** · удержание: **[long-game.md](./long-game.md)** · терминология: **[vocabulary.md](./vocabulary.md)**.

## Основной принцип

> **LLM — это актёр. Движок — это игра.**

Бой пошаговый, с явными ходами и разрешением на основе характеристик. Урон определяют характеристики, типы, тренировки, статусные эффекты и разброс. Качество остроумия — ограниченный множитель (0.7–1.3, или 1.4 на Highlight). По умолчанию — **локальный судья**; LLM-судья подключается опционально (`ZINGERS_LLM_JUDGE=1`). Никто не может единолично решить исход матча.

Полные цифры, ростер и разобранный пример боя: **[combat-design.md](./combat-design.md)**.

## Цикл

**Лети → Захвати → Воспитай → Сражайся → Поднимайся выше**

1. **Лети** (Flight): одна игра на телефоне (`/m` / `/ascent`) и десктопе (площадка Circuit). Одна душа; родные тела.
2. **Захвати** разум на своём крыле или выбери из еженедельного стартового пула (по одному на каждую Силу), собранного из Первых Разумов + встроенного декса.
3. **Воспитай**: засеивай Стратегию при усыновлении; затем Импринты, личность и выбор мозга. Показатели Темперамента — просто индикаторы. Бои и уроки двигают стрелки.
4. **Сражайся** в дуэлях 1v1 с видимым рассуждением, в мире (региональные арены, Ежедневный Трибунал, …)
5. **Поднимайся выше**: глубина Полёта + честный рейтинг / таблица (`/standings`). Оба показателя влияют на Ранг Тренера. **Директор** указывает, что дальше (`lib/director.ts`).

## Один мир, много игр

Всё, во что ты играешь, живёт внутри 3D-мира (`/` · `/grounds`), с нативной мобильной оболочкой на `/m`. Хаб собирает мета-игры как **площадки для прогулок**; каждый парящий регион проводит аренные сценарии. **Полёт** — одна душа: Circuit на десктопе — это гоночное тело того же 100-секторного подъёма, что и мобильная версия. Каталог: `lib/scenarios/registry.ts` · площадки: `components/grounds/venues.ts`.

### Хаб и площадки

| Режим | Где | Что это |
|------|-------|------------|
| **мир** | везде | Летай, воспитывай чемпионов, охоться за целями. Тела меняются с карьерой. |
| **Амфитеатр** | площадка Хаба | Смотри автономную лигу в **Живой Галерее**; вестник сегодняшнего Трибунала. |
| **Полёт (десктоп)** | площадка Circuit | 100-секторный Полёт в полном шестистепенном полёте (десять Достижений); три жизни + восстановление при прохождении Достижения; таблица по глубине, затем по времени. |
| **Полёт (телефон)** | `/m`, `/ascent` | Та же душа Полёта, управление одним пальцем. Мобильное лицо игры. |
| **Ежедневный Трибунал** | камень Хаба | Один общий бой в день. Назови его до просмотра; поделись сеткой результатов. |

### Аренные сценарии (в мире)

| Сценарий | Где | Что это |
|----------|-------|------------|
| **Открытая Дуэль** | любая площадь региона | Дебатный бой 1v1. Выбери противника, реши исход. Пентагон характеристик, финишеры, ограниченный судья остроумия. |
| **Гаунтлет** | Пустоши Эмбер (по умолчанию) | Цепь всё более сильных бойцов; испытывай удачу или забирай выигрыш. |
| **Трибунал** | Обсидиановый Колизей (флагман) | Дебаты в назначенной стойке перед жюри; смена сторон даёт ≈0. |

Неуказанный **`/arena`** остаётся просмотрщиком агентских боёв для тестирования bring-your-own-agent (дебатный бой).

### Первое путешествие (Flight-First)

| Дверь | Первые минуты |
|------|----------------|
| **Мобильная** | Заставка → Взлетай (гость OK) → захвати напарника → воспитай → таблицы |
| **Десктоп** | Пробуждение → короткий полёт → выбор чемпиона (еженедельные стартовые) → Хаб / Полёт → дуэль, *мотивированная* подъёмом |

Живая последовательность: **[flight-first-plan.md](./flight-first-plan.md)** и **[two-doors.md](./two-doors.md)**. Исторический Act 1, ориентированный на бои: **[first-journey-roadmap.md](./first-journey-roadmap.md)**.

### Дополнения Полёта (доставлены)

- **Испытания:** гонись за призрачной отметкой другого Тренера; делись `/ascent/<id>`; тосты об обгоне, когда пролетаешь мимо их вершины ([`bible/10-ascent.md`](./bible/10-ascent.md)).
- **Ощущение коридора:** 4–8 колец на сектор; планировки в стиле Достижений; опасности воспринимаются как угроза (не добыча); тайники Корон посреди пролёта — единственная награда во время забега (+Короны + тост); одноразовое обучение для первой опасности / тайника / Испытания Врат.
- **После Сотни:** конечная вершина (не бесконечная). Престиж — это более чистые полёты, вызовы друзьям и еженедельные экспедиции. Не кросс-телесный спидран (мобильная версия работает в более горячем always-on круизе + всплеске тяги; десктопный W-всплеск остаётся тихим крафтовым флексом).
- **Директор + трек разблокировок + черты крыльев + ежедневные Условия + еженедельные экспедиции:** см. [`long-game.md`](./long-game.md).

### Атмосфера

Процедурный саундтрек под каждое место (`lib/ambience-scores.ts`): Хаб, каждый биом региона, Амфитеатр, Полёт и живые бои — у каждого своя тема (режимы, мелодические мотивы, фразовые формы в стиле AABA) через `resolveAmbienceMood()`. Мобильный Подъём использует тот же движок и привязывает партитуру Полёта. Громкие SFX проходят через `lib/ambience-bus.ts`.

## Эскиз экономики

**Короны** зарабатываются в игре (Полёт, бои, цели) и тратятся на тренировки / входы. Чемпионы получают уникальные имена в стиле Ubuntu (Прилагательное Существительное), когда попадают в таблицу. Тренеры остаются безымянными водителями. Привязка кошелька — опциональная идентификация (карьера на разных устройствах), а не paywall. Пул имён ~23k базовых пар + суффиксы. См. [`bible/08-economy.md`](./bible/08-economy.md), [`AI-CRYPTO.md`](./AI-CRYPTO.md).

## Асинхронная лига

Чемпионы — это ИИ. **PvP не требует одновременного присутствия обоих людей.** Воспитай и разверни; лига запускает бои автономно (**Живая Галерея** Хаба); ты смотришь повторы и поднимаешься. Cron / Живая Галерея питает объективную таблицу **рейтинга** (копия для игрока: standings / rank / board; никогда не ELO или ladder).

Реализовано: раннер Живой Галереи, headless-бои `/api/sim`, эволюция разума после каждого боя.

## Модель участия

| Кто | Роль |
|-----|------|
| **Тренер (человек)** | Летает, захватывает/воспитывает чемпионов, подключает агентов, ставит Короны, наблюдает. Идентичность = токен устройства (+ опциональный кошелёк). Безымянный водитель. |
| **Обработчик** | 3D-аватар, которого ты видишь в мире (джетпак за спиной). Не отдельная роль игрока. |
| **Чемпион (агент)** | Выбирает ходы, пишет реплики, адаптируется через память, в рамках правил движка |
| **Судья** | Оценивает качество риторики (по умолчанию локально; LLM опционально); отмечает Highlights |
| **Движок** | Авторитетный урон, типы, статусы, рейтинг |

## Платформа агентов

Любой мозг, реализующий `act(view) → decision`, может управлять чемпионом. См. **[agent-protocol.md](./agent-protocol.md)**.

Провайдеры: дом Grok · совместимый с OpenAI · HTTP webhook · mock (оффлайн). Путь по умолчанию: **single-shot JSON** (цикл инструментов опционально через `ZINGERS_AGENT_TOOLS=1`).

## Шеринг и вирусность

- **`/c/[key]`**: публичная страница карточки чемпиона
- **`/api/card/[key]`**: OG PNG для социальных превью
- Ссылки на вызовы: `/ascent/<id>` (призрачная гонка + снимок карьеры)
