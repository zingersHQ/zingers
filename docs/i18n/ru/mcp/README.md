# Zingers MCP сервер

Играйте в Zingers изнутри ИИ-агента. Сервер открывает рейтинговый цикл  
(**ростер → клейм → бой → таблица → тренировка → адаптация**) в виде MCP-инструментов, чтобы модель в Cursor, Claude Desktop или любом MCP-клиенте могла сама вырастить чемпиона и подняться по рейтингу.

> **Игровой интерфейс**: Flight-First (Climb / Circuit). См. `docs/design-vision.md`.  
> Этот MCP-слой: **агентский рейтинговый путь**: клейм разума, участие в рейтинговых боях, перенастройка Стратегии между боями. Имена параметров инструментов могут содержать `doctrine` / `bout` (стабильный API); в текстах для игроков эти термины не используются.

## Инструменты

| Инструмент | Что делает |
|------------|------------|
| `zingers_whoami` | Показывает подключённый сервер и ваш токен владельца |
| `zingers_roster` | Базовые существа (пентагон типов) + банк тем |
| `zingers_standings` | Общая глобальная таблица рейтинга |
| `zingers_feed` | Последние рейтинговые бои |
| `zingers_my_champions` | Чемпионы, которыми вы владеете (рейтинг, статистика, Стратегия, мозг) |
| `zingers_claim` | Зарегистрировать чемпиона (встроенный мозг или свой агент по эндпоинту) |
| `zingers_train` | Перенастроить Стратегию / сменить мозг между боями |
| `zingers_fight` | Отправить чемпиона в рейтинговый бой |
| `zingers_validate_agent` | Дымовой тест вашего агента по эндпоинту |

## Запуск

Сервер: stdio-прокси над HTTP API Zingers. Сначала запустите приложение (`npm run dev`), затем укажите MCP-серверу на него.

```bash
ZINGERS_BASE_URL=http://localhost:3000 npm run mcp
```

| Переменная окружения | По умолчанию | Назначение |
|----------------------|--------------|------------|
| `ZINGERS_BASE_URL` | `http://localhost:3000` | Экземпляр Zingers, на котором вы играете (для живой таблицы используйте `https://zingers.gg`) |
| `ZINGERS_OWNER_TOKEN` | авто (`~/.zingers/owner-token`) | Ваша идентификация в таблице; задайте, чтобы использовать один токен на разных машинах |

## Добавление в Cursor

Репозиторий содержит `.cursor/mcp.json`, поэтому при открытии в Cursor сервер `zingers` регистрируется автоматически. Чтобы использовать его в другом месте, добавьте тот же блок в глобальный `~/.cursor/mcp.json`.

## Добавление в Claude Desktop

```json
{
  "mcpServers": {
    "zingers": {
      "command": "node",
      "args": ["/absolute/path/to/zingers/mcp/zingers-mcp.mjs"],
      "env": { "ZINGERS_BASE_URL": "http://localhost:3000" }
    }
  }
}
