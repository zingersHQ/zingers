Заметки по продакшену из предыдущего прохода Акта 1 (оставлены для справки / археологии).

## Поток Акта 1 (предыдущий проход — устарел)

```
FirstRun (кинематографическая заставка) → Первый поединок: Принять (5 Сил, еженедельная ротация, превью новичка)
  → Момент принятия (Тренер + чемпион) → начальная Стратегия → принять как новичка → Бой в Пустоте
  → Карта эволюции → Приземление в Конкорде (сначала Тренер) → Тренер разделяет коуча при спауне
  → Направляемая первая арена (подсвечен проход в Основания) → Свободное перемещение + коуч
```

## 60-секундный обучающий контракт (обновлён под «Сначала Полёт»)

Перед завершением первого полёта / выбора игрок должен понять:

- [ ] *Ты летишь. Он сражается. Вы оба растёте.*
- [ ] *Ты растишь этого чемпиона — ты не боец.* (мягкая идентичность; без хайпа о блокировке выбора)
- [ ] Тело новичка при принятии — это первый день арки, а не даунгрейд по сравнению с превью выбора

Канонический текст: `lib/player-copy.ts` · Видение: `docs/design-vision.md` · Словарь: `docs/vocabulary.md`

| Пункт | Статус | Примечания |
|-------|--------|------------|

| Направленные персонажные биты | ✅ | `CharacterBeat` улучшен: letterbox, поднимающийся/плавающий живой 3D-портрет, пульс свечения по строке, печатная машинка, параллаксное поле (учитывает reduced-motion) |

Сага (твоя история) и Хроника (история мира) намеренно разделены: сага продвигается по единственному числу ранга Тренера, поэтому движется независимо от стиля игры, а Хроника крутится по сезонным часам.

## Намеренно оставлено без изменений

- **Ключи событий кода/аналитики** — по-прежнему `bout` (стабильные серверные треки)
- **Имя хука `useBout`** — внутреннее; не имеет видимой игроку метки
- **Документация/README/MCP** — для разработчиков; не входит в проход игрового текста (см. синхронизацию `docs/` для канона)

## Саундтрек (процедурный, по месту)

| Настроение | Когда |
|------------|-------|
| `concord` | Хаб Конкорд |
| `colosseum` | Обсидиановый Колизей / регион Основания |
| `ember` | Тлеющий Гаунтлет |
| `void` | Сад Пустоты |
| `amphitheatre` | Амфитеатр |
| `circuit` | Полёт (Цепь / Набор высоты) |
| `battle` | Любой живой бой или дуэль Хранителя |

Партитуры хранятся в `lib/ambience-scores.ts` (режимы + формы в стиле AABA).  
`grounds-screen` вызывает `resolveAmbienceMood()`; мобильный подъём фиксирует `circuit`.
