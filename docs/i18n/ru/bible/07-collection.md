# 07 · Коллекция: карты, редкость и атрибуты

> **Коротко:** Каждый чемпион одновременно является коллекционной картой, как в Pokémon или Magic. В отличие от них, иллюстрация на карте меняется по мере того, как чемпион сражается и растёт. Вы собираете растущий покедекс, выращиваете конюшню и (позже) обмениваетесь.

Каждый чемпион — это ещё и **карта**. Карта — это портативное, коллекционное лицо разума, и её главный трюк уже заложен в коде: **иллюстрация эволюционирует**, потому что иллюстрация — это тело чемпиона. Каждый ключ разума разрешает стабильный **видовой набор** (`lib/render/species.ts`) на общей оснастке: силуэт породы + комплект частей, плюс карьерная морфология костей (`lib/evolve/appearance.ts`). Разумы одной Силы выглядят как разные животные; уровень добавляет брони. Карта, которой вы владеете, визуально становится сильнее по мере того, как вы сражаетесь с ней.

## Анатомия карты

| Часть | Источник | Примечания |
|------|--------|-------|
| **Разум** (имя, сила, происхождение) | Первые Разумы + запечённый покедекс (`content/minds/reviewed/`) + генератор сезона | идентичность |
| **Иллюстрация** | геном + архетип Силы + видовой набор → рендер тела | меняется с карьерой и уровнем, детерминированно |
| **Характеристики** | пять боевых статов + рейтинг | цифры |
| **Сигилы** | заработанная геральдика Силы (I/II/III). Значки, которые вы выигрываете, а не покупаете | значки |
| **Атрибуты** | набор приёмов (4 приёма) | строка «способностей»: здесь глубина TCG |
| **Сага** | генерируется из истории матчей | текст-атмосфера. Собственная развивающаяся жизненная история чемпиона |
| **Редкость** | выводится из уровня × дефицита | ниже |
| **Происхождение** | сезон чеканки, владелец, id чеканки | пока неактивно; крючок владения |

## Редкость

Редкость **зарабатывается, затем становится дефицитной**. Это не ролл гачи. Она растёт вместе с уровнем чемпиона и с тем, насколько редок этот билд на самом деле.

| Редкость | Зарабатывается на | Ощущение |
|--------|-----------|------|
| **Обычная** | Новичок | разум, который только-только обрёл форму |
| **Необычная** | Адепт | доказал себя раз-другой |
| **Редкая** | Ветеран | настоящая история |
| **Эпическая** | Элита | имя, которого боятся |
| **Легендарная** | Легенда | коронован; постоянный элемент таблицы |
| **Мифическая** | Легенда + титул сезона (например, Взломал Хранителя, выиграл сезон) | уникальные события; трофейный уровень |

## Как работает коллекционирование (слой Pokémon / Magic)

- **Собирать**: восемь Первых Разумов, волна запечённого покедекса (пакет разумов Этапа 6), сезонные избранные разумы и ваши собственные выращенные карьеры. Покедекс — это длинная игра. Новые разумы поставляются через `npm run forge:dex` / review / `npm run bake:minds` (см. [03-champions.md](./03-champions.md)).
- **Знакомиться**: еженедельная ротация усыновления показывает одного стартового чемпиона от каждой Силы из этого пула, поэтому возвращающиеся Тренеры со временем знакомятся с разными напарниками.
- **Строить**: небольшая **конюшня** чемпионов, которых вы выставляете по регионам; их Силы взаимодействуют на Колесе, поэтому конюшня — это *колоды* с покрытием типов.
- **Обменивать / дарить**: перемещение карт между игроками (социальный цикл). Спроектировано здесь; заблокировано за слоем владения ([economy.md](./08-economy.md)). Чеканка on-chain — это позднее заполнение уже существующих на карте полей происхождения, а не причина существования покедекса.

## Каноническая дисциплина

- **Редкость карты может расти** (Новичок, которого вы поднимаете до Легенды, перечеканивается вверх), но **идентичность карты постоянна**: тот же разум, то же происхождение, эволюционирующее тело.
- Запечённые и сгенерированные разумы получают тег **происхождения** (какого Первого Разума они отражают), чтобы покедекс оставался читаемым и у каждой карты было место на Колесе.
