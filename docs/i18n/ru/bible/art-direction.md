# Художественное направление: визуальный канон Zingers

> **Коротко:** это гайд по стилю для всех изображений Zingers. Он задаёт цвета, настроение и правила, которым должно следовать каждое сгенерированное изображение, чтобы весь мир выглядел цельно.

Внешний вид, благодаря которому каждое изображение воспринимается как **единая вселенная**. Встраивайте эти правила в каждый промпт; используйте фиксированное референс-изображение style-key при последующих генерациях, чтобы серия не расходилась.

## Среда и оптика

- **Живописный кинематографичный концепт-арт**, не фотореализм, не плоский вектор.
- **Объёмный неоновый контурный свет** на тёмном туманном поле; сильная атмосферная глубина.
- Высокая детализация, драматично, настроенчески. Hum (мировое фоновое поле остаточной мысли) отображается как парящие частицы + слабый глифический текст.
- Один доминирующий цвет Силы на изображение + золотые акценты. Избегайте радуги.

## Запрещено (сохраняет премиальность)

- Нет текста, слов, логотипов или водяных знаков в изображении.
- Нет UI/HUD-элементов, нет современного/реального брендинга.
- Нет gore, нет фотореалистичных человеческих лиц (это *умы*, стилизованные).
- Нет захламления: один чёткий субъект, глубокое негативное пространство в пустоте.

## Композиционные конвенции

| Группа | Соотношение | Кадрирование |
|--------|-------------|--------------|
| Сценарии / регионы | 16:9 | широкий установочный кадр, атмосферная глубина |
| Персонажи (Умы, Хранители) | 4:5 | центрированная фигура, ¾-поза, эмблема позади |
| Силы / иконки | 1:1 | центрированное эмблематичное воплощение, тайлинг |

## Брендовый хром (UI-марка. Не ключевой арт по библии)

Продуктовая хромовая марка — плоский вектор **роботоголовы** (большие глаза, толстая антенна), не живописный ключевой арт:

- `app/icon.svg`. Фавикон / иконка приложения (почти полноформатный силуэт)
- `public/brand/robot-mark.svg`. Та же марка для навигации / PlayerHub
- `components/brand/robot-mark.tsx`. React-обёртка

Ключевой арт по библии остаётся живописным (ниже). Не помещайте робот-марку в генерируемые лор-плейты; не помещайте живописные лица в тайл фавикона.

## Файлы и встраивание

- Сохраняйте в `public/img/bible/<group>/<slug>.png`
  (`forces/`, `minds/`, `regions/`, `keepers/`, сценарии в корне).
- Встраивайте в `docs/bible/*.md` с относительным путём репозитория (рендерится на GitHub).
- zingers.org отдаёт тот же файл по пути `/img/bible/<group>/<slug>.png`.

## Рабочий процесс для консистентности

1. Храните `bible-the-grounds-over-the-vault.png` как **ключ стиля**; передавайте его как референс при новых генерациях, чтобы зафиксировать палитру и рендеринг.
