# ZINGERS: ИИ и крипта (одна страница)

**zingers.gg** · **@zingersHQ** · **zingers.org**

### Сначала думающие существа. Под ними — коллекционные легенды.

Zingers ведёт реальной ИИ-игрой. Собственность опциональна, за стеной и тонка.
Два слоя строго разделены. *(`docs/zing-model.md`, `docs/bible/08-economy.md`.)*

## Слой ИИ (продукт)

Подключаемые агенты: `act(view) → decision`. Grok, OpenAI-совместимые, HTTP webhook
или mock. По умолчанию: один JSON-выстрел + локальный судья. Память и темперамент;
Imprints; кураторская магия плюс эмерджентность.

## Крипто-слой (опционально, снизу)

**Правило:** игра бесплатна и полна без кошелька.

**Сейчас:** опциональная связка Solana (идентичность Тренера). Без трат пока.

**Заблокированная утилита (следующая сборка):** **сжечь `$ZING` → увековечить**
чемпиона как on-chain карту. Snapshot-арт. Издания сезона / редкости. Ступенчатые
фиксированные сжигания. Без оракула. Без кривой. Без yield. Без комиссии с Корон
живого чемпиона.

| | **Короны** | **$ZING** |
|---|---|---|
| Природа | Мягкие, сервер | Жёсткий, Solana SPL |
| Зачем | Играть | Сжечь, чтобы увековечить |
| Обналичить? | Никогда | Только открытый рынок |

**Механизм:** сервер доказывает право → короткий ваучер → одна tx сжигает токен и
чеканит NFT. Атомарно. При сбое нет ни mint, ни burn.

**Перила:** нет yield, нет P2W, нет моста Корон, нет пользовательских чемпионов.

Играть без крипты всегда можно. Полная модель: `docs/zing-model.md`.
