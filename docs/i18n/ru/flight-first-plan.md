# Zingers. План разработки «Сначала Полёт» (сессионный замок)

> **Коротко:** Подъём: лицо; бои: глубина; десктоп: полная вершина.  
> Опциональный кошелёк Solana = идентичность Тренера (не экономика). Монета/токен: **отдельный будущий трек**. Этот документ: актуальная дорожная карта после планировочной сессии июля 2026.

[`launch-week.md`](./launch-week.md), [`flyover.md`](./flyover.md),

## Северная звезда

**Фраза игрока к второй минуте:** *Я лечу. Оно сражается. Мы растём.*

| Дверь | Первые ~2 мин |
|---|---|
| **Мобильная** | Постер → Полёт → Подъём → получить напарника → ещё один + таблицы |
| **Десктоп** | Пробуждение → полёт ≤15 с → получение → короткий Вылет → дуэль, *мотивированная* подъёмом |

**Невидимо:** агенты думают (фэнтезийный текст); кошелёк опционален; Короны только внутри игры.

## Объём

### Входит
Чувство подъёма · гость→получение · замер воронки · лёгкие таблицы · один мост высоты/повышения · 90-секундная переделка десктопа · опциональная идентичность Phantom · экономные LLM-операции

### Не входит
Запуск $ZING · вестинг · эйрдропы · Короны↔токен · ончейн-матчи · кастомные протоколы · Fly через кошелёк · новые площадки / глубина Хранителя как лицо

### Заморожено до приёмки чувства подъёма
Новые режимы, арт-спринты Вылета, торговля коллекциями, продвижение Дома, токеновый UI.

## Правила кошелька (не обсуждаются)

- Никогда не требуется для Полёта / Подъёма / получения / Корон.  
- Только SIWS-подтверждение владения. Без approve-трат.  
- Сервер связывает `pubkey` ↔ токен владельца; состояние игры остаётся off-chain.  
- Копирайт = сигил Тренера / подключить. Никогда не депозит и не топливо.  
- Будущая монета цепляется к тому же сокету; **логики токена сейчас ноль**.

## Определение готовности

1. Мобильная: Полёт → весёлый Подъём → получение за одну сессию  
2. Десктоп: полёт до сваливания систем  
3. `/stats`: дверь + получение (+ вторичная эволюция)  
4. Призрачное соревнование через таблицы  
5. Один мост повышения или мотивирующий текст  
6. Опциональная ссылка Phantom; ядро без кошелька  
7. Нет токенового UI · экономика только Корон · бюджет LLM задан
