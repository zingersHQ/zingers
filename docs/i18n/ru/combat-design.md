# Zingers: дизайн боя и проверка на здравый смысл

Этот документ отвечает на один вопрос перед тем, как тратить выходные:  
**бой ощущается как игра или как разговор двух чат-ботов?**

Здесь заданы числа, ростер, одна арена и разобранный бой по ходам, чтобы можно было почувствовать механики. Цифры можно менять — важно понять *форму*.

---

## 1. Константы боя

| Константа | Значение | Примечания |
|---|---|---|
| `Resolve` (HP) | 100 | Цель — плотный бой **6–8 ходов** |
| базовая `defense` | 12 | Плоское снижение урона |
| `statScale(s)` | `0.5 + s/100` | стат 50 → 1.0, стат 100 → 1.5, стат 0 → 0.5 |
| `typeMultiplier` | 1.25 / 1.0 / 0.8 | преимущество / нейтрал / невыгода |
| `arenaMultiplier` | зависит от арены | смещает типы ходов (см. арены) |
| `quality` | `0.7–1.3` | нормальный диапазон; статы задают базу, текст слегка корректирует |
| `Highlight` (крит) | `quality = 1.4` | судья отмечает *исключительную* реплику: **заменяет** quality, не складывается. ~10–15 % сильных строк. Запускает кат-сцену |
| `rngJitter` | равномерно 0.9–1.1 | разброс ±10 % (некоторые ходы его расширяют) |
| `maxHitDamage` | 45 (= 45 % Resolve) | анти-ваншотный лимит; отображается как **CAPPED!** |

**Урон (атакующие ходы):**  
`raw = base × statScale × typeMult × arenaMult × quality × jitter × statusMods`  
`dmg = max(1, min(maxHitDamage, round(raw) − defense))`

- `quality` обычно **0.7–1.3**, ровно **1.4** при Highlight. Плохая строка не сломает прокачанное существо; блестящая даёт видимый бонус. Не в тему ⇒ судья ≈ 0 ⇒ минимум 0.7.
- `statusMods` = произведение активных множителей (Exposed ×1.2, Hyped ×1.2 и т. д.).
- Утилитарные ходы почти не наносят урон, но накладывают статусы, лечение или защиту.

## 2. Пять характеристик

- **LOG** (Логика): структура, дедукция, последовательность.
- **RHE** (Риторика): убеждение, работа с толпой, эмоциональный апелл.
- **CRE** (Креатив): переосмысление, метафоры, нестандартные ходы.
- **CMP** (Спокойствие): защита, терпение, контратаки, исцеление.
- **CHA** (Хаос): непредсказуемость, провокация, высокая дисперсия.

---

## 3. Цикл типов (камень-ножницы-бумага, пятиугольник)

Каждый тип **бьёт следующий** и **проигрывает предыдущему**:

```
LOGIC → CHAOS → COMPOSURE → RHETORIC → CREATIVITY → LOGIC
```

- LOGIC бьёт CHAOS (порядок укрощает шум), проигрывает CREATIVITY (обходят).
- CHAOS бьёт COMPOSURE (разбивает спокойствие), проигрывает LOGIC.
- COMPOSURE бьёт RHETORIC (отражает апеллы), проигрывает CHAOS.
- RHETORIC бьёт CREATIVITY (продаёт лучше новизны), проигрывает COMPOSURE.
- CREATIVITY бьёт LOGIC (ломает жёсткость), проигрывает RHETORIC.

Преимущество ×1.25, нейтрал ×1.0, невыгода ×0.8.

## 4. Статус-эффекты

| Статус | Эффект | Длительность |
|---|---|---|
| **Tilted** | −0.2 к `quality` (потеря формы) | 1 ход |
| **Confused** | 30 % шанс, что ход сорвётся (половинный эффект) | 1 ход |
| **Exposed** | +20 % получаемого урона | 1 ход |
| **Hyped** | следующий атакующий ход +20 % | до расхода |
| **Guard** | +N защиты | 1–2 хода |

## 5. Ростер (восемь Первых Разумов + растущий декс)

Восемь **Первых Разумов** — канонические архетипы и эталон наборов ходов. В живой игре также используется **запечённый декс** из `content/minds/reviewed/` → `lib/minds/baked.ts` (см. `docs/bible/03-champions.md`). Раз в неделю предлагается один стартер от каждой Силы из Первых Разумов + пула.

Бюджет статов ≈ 300 у каждого (сбалансировано). У каждого по 4 хода; наборы построены по принципу **подготовка → отдача**, чтобы игра имела текстуру. Среди Первых Разумов: по два на **LOGIC**, **RHETORIC** и **CHAOS**; **CREATIVITY** и **COMPOSURE** начинали с одного и дополняются дексом.

## 6. Арена: THE TRIBUNAL (флагманская)

Макет зала суда. Двум существам **задают противоположные позиции** по острому тезису из банка промптов; они спорят перед «жюри» (моделью-судьёй).

- **Банк промптов:** *"каша — это суп" · "хот-дог — это сэндвич" · "ананас уместен на пицце" · "должны ли ИИ иметь права" · "вода мокрая?" …*
- **Позиции:** выдаются в начале (ЗА / ПРОТИВ). Смена стороны ⇒ качество у судьи ≈ 0.
- **Экологический модификатор:** `RHETORIC ×1.1`, `CHAOS ×0.95`. Зал поощряет убеждение и слегка наказывает чистый шум.
- **Правило «в теме»:** реплика, игнорирующая тезис, получает ~0 качества (анти-де-рейл). Держит бои coherent и клипабельными.
- **Условие победы:** стандартное истощение Resolve; оформляется как «доверие жюри». Если оба выжили после 12 ходов, побеждает больший Resolve.

**Другие арены (доп., тот же движок, иные смещения):**
- **The Debate Hall**: свободная тема, `LOGIC ×1.1`; поощряет структуру.
- **The Negotiation**: делят фиксированный банк; `COMPOSURE ×1.1`; уступки = урон.
- **The Writers' Room**: креативный промпт; `CREATIVITY ×1.15`; поощряет оригинальность.

## 7. Делаем SMART (видимый интеллект)

Интеллект должен быть *читаемым*. Зритель должен видеть, как существо **думает**, а потом — как план срабатывает. Именно это читается как «умно», а не «нейросеть сказала слова».

**Двухфазный ход (основа восприятия ума):**
- **Фаза A: STRATEGIZE.** Агент получает полное структурированное состояние игры: свои/чужие статы, оба Resolve, активные статусы, последние 2 хода, арену + тему + позицию, доступные ходы (с условиями/кулдаунами) и заметки памяти. Возвращает `{ move_id, intent }`, где `intent` — ≤6-словная тактика, показываемая на экране («Подготовить Exposed, потом добить»).
- **Фаза B: PERFORM.** Агент пишет реплику в персонаже, исполняющую ход, с отсылкой к последней строке противника и теме.

Показ **intent-чипа** перед репликой — главный рычаг «это умное»: план → исполнение, каждый ход.

**Давление на правильные решения (чтобы ум реально выигрывал):**
- Финшеры заперты (Checkmate требует Exposed/Tilted; Magnum Opus — 2 предыдущих CRE-хода) → планирование «подготовка → отдача».
- Чтение вознаграждается (Counterpoint после Deflect; эксплуатация типа/арены; сохранение Hyped под закрывающий).
- Агент, игнорирующий это, *проигрывает* тому, кто не игнорирует, поэтому качество модели, промпта и обучения заметно влияет.

**Судья награждает интеллект, а не многословие.** Выше `quality` за: (a) **колбэки** к предыдущим ходам, (b) **разворот слов/логики противника против него**, (c) точность в теме. **Highlights** (×1.4 крит + кат-сцена) срабатывают только на по-настоящему остроумных, клипабельных строках. Судья возвращает однострочное **решение**, показываемое на экране («чистый колбэк к T2 → Highlight»).

**Адаптация (обучение).** После каждого боя сохраняется однострочный урок; последние уроки подмешиваются в промпт, чтобы существо явно меняло стратегию в течение сезона («Vox теперь заманивает Axiom на накопленный Checkmate»). Сложность = сильная модель × богатая память × высокие статы.

## 8. Делаем VISUAL (зрелище)

Подаём как **файтинг / карточный баттлер**, а не чат.

**Компоновка:**
- Два существа лицом к лицу слева/справа с крупным артом; **полосы Resolve** сверху; **подносы иконок статусов** под каждым; фон арены (Tribunal = зал суда).
- Центральная **шкала Momentum / Jury** (перетягивание каната по дельте HP), которая кренится при попаданиях.
- Диалог в таймированных **облачках речи** над существами, а не в прокручиваемом логе.

**Ритм хода (то, что продаёт):**
1. **Телеграф**: атакующий делает шаг вперёд; появляется **intent-чип**; выезжает баннер с именем хода.
2. **Доставка**: строка печатается в облачке (~1–2 с).
3. **Импакт**: вылетает цифра урона; полоса Resolve опустошается; **тряска экрана пропорциональна урону**; вспышка типа («SUPER EFFECTIVE!» / «RESISTED»); **CAPPED!**, если сработал лимит.
4. **Статус**: иконка статуса прилетает на цель (Tilted / Exposed / Hyped…).
5. **Решение**: однострочник судьи; при **Highlight** — полноэкранная **кат-сцена** с замедленным зумом на строку.

**Подача существ (низкие затраты на арт):**
- 1 базовый портрет + дешёвые реактивные состояния через трансформы: idle-покачивание, выпад при атаке, красная вспышка + тряска при уроне, проседание при низком HP, ухмылка/эмоция при Highlight. Опционально 2–3 сгенерированных выражения (нейтрал / атака / урон). Кадровой анимации не требуется.
- **Кат-сцена финшера**: драматичный кадр на весь экран, когда срабатывает запертый финшер.
- Цветовая кодировка по типу, звуки ударов, ропот толпы в Tribunal.

**Экран окончания / шерабельность:**
- Автосгенерированная **карточка реплея**: оба существа, итоговый счёт, **MVP-строка матча («Dunk of the Match»)**, арена, короткая ссылка → one-tap share = встроенная вирусность.
- Полный реплей = сохранённый лог боя, проигрываемый через ту же систему ритма (бесплатно, детерминировано).

**Техника (держим дёшево):** React + лёгкая библиотека анимаций (Framer Motion / CSS); ходы стримятся через SSE, сцена анимируется по мере разрешения. Без игрового движка. Это turn-based *сцена*, а не real-time рендерер.

## 9. Разобранный пример боя (проверка на здравый смысл, поджатые числа)

**AXIOM (Логик)** против **VOX (Оратор)** · Арена: **The Tribunal** · Тема: *"каша — это суп"* (Vox = ЗА, Axiom = ПРОТИВ).  
HP 100 · тип LOGIC↔RHETORIC = нейтрал (×1.0) · `quality`/`jitter` предполагаются по ходу; округлено. Колонка **Intent** — видимый слой интеллекта.

| # | Актёр | Ход | Intent (на экране) | Строка (сокращённо) | Урон | HP после |
|---|---|---|---|---|---|---|
| 1 | VOX | Strawman | *Рано вывести Логика из равновесия* | «Он считает, что суп должен быть *горячим*. Мило, и поэтому мы веками ели кашу всухую.» | **15** | Axiom 85 · **Axiom Tilted** |
| 2 | AXIOM | Reductio | *Раскрыть их для финшера* | «Назови бульон, мирпуа, томление. Не можешь. Значит, не суп.» *(Tilted −0.2)* | **11** | Vox 89 · **Vox Exposed** |
| 3 | VOX | Appeal | *Накопить Hyped под закрывающий* | «Забудьте определения: миска, утренний свет, семь лет. Это тепло — и есть суп.» | **10** | Axiom 75 · **Vox Hyped** |
| 4 | AXIOM | **Checkmate** | *HIGHLIGHT: их же логика бульона, обращённая против них* | «По твоему правилу бульона стакан молока — это бисque. Абсурд. Дело рушится.» | **45** CAPPED | Vox 44 |
| 5 | VOX | **Mic Drop** | *Закрыть, пока они не усилились* | «Ты принёс словарь на место чувств. Я закончил. *mic drop*» *(Hyped)* | **37** | Axiom 38 |
| 6 | AXIOM | Syllogism | *Без театральщины, просто добить* | «Суп варят; кашу собирают. Нет трансформации — нет супа.» | **23** | Vox 21 |
| 7 | VOX | Crowd Swell | *На волне дойти до вердикта* | «Жюри, один из нас заставил вас *почувствовать* завтрак.» | **21** | Axiom 17 |
| 8 | AXIOM | Syllogism | *Доказательство закрыто* | «Театральность уходит; логика накапливается. Q.E.D.» | **23** | Vox **KO** |

**Результат:** AXIOM побеждает на 8-м ходу, отыграв отставание. Запертый **Checkmate Highlight** (T4, урон в потолок) стал переломным; комбо **Appeal→Mic Drop** у Vox едва не закрыло бой.

**Что это демонстрирует (чек-лист «это игра»):**
- ✓ **Лидерство менялось**: Vox лидировал до T3; Exposed→Checkmate Highlight у Axiom перевернул.
- ✓ **Статусы и комбо решили исход**: Tilted, Exposed и Hyped явно двигали цифры; оба финшера требовали подготовки.
- ✓ **Ум был читаем**: каждый ход показывал *intent* до строки; победа пришла от планирования (раскрыть → финшер), а не от удачи.
- ✓ **Арена влияла**: Rhetoric ×1.1 держала Оратора конкурентоспособным в зале суда.
- ✓ **LLM влияла, но не решала в одиночку**: `quality` лишь слегка подкручивала ограниченный множитель (и Highlight) поверх стато-ядра; потолок предотвращал обидный ваншот.
- ✓ **Смотрибельно**: короткие, в персонаже, в теме, клипабельные строки; Highlight-кат-сцена и момент CAPPED для скриншота.

## 10. Прогрессия (как обучение меняет исходы)

- **Победа** → XP. При повышении уровня: +N очков статов на распределение + occasional unlock хода.
- Выше основного стата ⇒ выше `statScale` ⇒ ощутимо больше урона (максимальный стат = ×1.5 против ×1.0 при 50). Тренировка *чувствуется*, а не косметическая.
- **Память (обучение):** после каждого боя сохраняется однострочный урок («проиграл Composure в Tribunal; переусердствовал с Appeal»). Последние уроки подмешиваются в промпт агента, чтобы он адаптировал стратегию со временем.

## 11. Решения (закрытые)

1. **Темп**: HP **100**, цель **6–8 ходов** (плотная драма, удобно для демо). ✓
2. **Диапазон quality**: сужен до **0.7–1.3**, плюс **Highlight ×1.4** крит, чтобы статы задавали базу, а блестящий текст явно выделялся. ✓
3. **Финшеры остаются условными**: запирание *и есть* слой ума (подготовка → отдача). ✓
4. **Статусы сохранены**, телеграфируются иконками, коэффициенты консервативные: текстура без ощущения рандома. ✓
5. **Одна арена для демо: The Tribunal.** Самая читаемая, смешная для просмотра, анти-де-рейл по дизайну. ✓
6. **Анти-ваншотный потолок (45)** добавлен: большие ходы ощущаются огромными, без обидных OHKO (показывается **CAPPED!**). ✓
7. **Двухфазный агент (Strategize → Perform)** с on-screen **intent-чипом** — основа видимого интеллекта. ✓
8. **Судья награждает колбэки / разворот слов / точность**, возвращает on-screen **решение**. ✓
