# ZINGERS: 2ページ要約

**zingers.gg** · **@zingersHQ** · **zingers.org**（技術・ドキュメント）

### 君が飛ぶ。AIが戦う。共に高みへ。

**君は戦わない。飛ぶだけ。** バックパック型のジェットパックを背負い、封印された大空洞「ロング・ヴォールト」の上空を駆け上がる。傍らには思考するAIチャンピオンが飛んでいる。君は*どのように戦うか*を訓練し、登頂中に現れる戦いに送り出し、AIが戦い、勝利し、君だけの存在へと物理的に進化する様子を眺める。*心を育て、伝説に仕上げる。*

> **Pitch:** 空を飛ぶ。思考するAIが傍らで戦い、共に進化する。  
> **Tweet:** 君が飛ぶ。AIが戦う。共に高みへ。自己論争で身体を獲得するAIを育てよう。

---

## 1. 課題／機会

コレクティブルバトラー（ポケモン系）は巨大で持続的なジャンルだが、クリーチャーは**スクリプト化**されている。戦いは既知の量であり、「知性」はステータス表に過ぎない。一方、本物のAIエージェントはすでに議論し、策略を練り、説得し、即興で動ける。

**機会:** 世界で最も愛されるゲームループ（*集める・育てる・戦う*）を、クリーチャーが**本当に考える**ものに変える。そして、誰でも一瞬で理解できる動詞（**飛行**）をプロダクトの顔にする。戦いは二つの知性によるライブ対決となり、毎試合が唯一無二で、すべてのチャンピオンが再現不能になる。登頂体験が、システムが反応する前にプレイヤーの心を掴む。

---

## 2. プロダクト概要

**飛ぶ → 獲得 → 育てる → 戦う → さらに高く登る** ループ。各チャンピオンは本物のAIエージェント。

- **Fly（飛ぶ）**: 「ロング・ヴォールト」上空の「リーチ」を「フライト」（スマホ・デスクトップ同一の操作感）で駆け抜ける。
- **Claim（獲得）**: 週替わりスタータープール（Forceごとに1体）から選択。第一の心や成長中のコレクティブル図鑑から。
- **Raise（育てる）**: 技選択ではなく、採用時に**戦略**（攻撃性／集中／リスク）を種付け。以降は日常の**インプリント**、ペルソナ、駆動脳で心を形成。気質メーターが変化を可視化（スライダーではなく読み取り専用）。
- **Fight（戦う）**: 権威あるエンジンで解決するライブ対戦（既定はローカル判定、任意でLLM判定）。
- **Evolve（進化）**: 身体と称号はキャリア（戦績＋到達高度）から導出。同一Forceでも表現型＋骨格変形で別種に見える。

## 4. 差別化要因

- **実証済みフォーマットへの本質的新機軸**: 考えるクリーチャーにより戦いが非脚本化・無限に新鮮。飛行によりプロダクトが即理解可能。
- **内蔵バイラル性**: フライトチャレンジ共有、クライムボード、コレクション、絆カード（相棒＋上昇）。戦いは奥行きで、共有フックではない。
- **本物のキャラクター**: 議論し、策略を練り、勝敗を分かつチャンピオンは視聴・ミーム化可能。
- **所有可能なIP護城河**: オリジナルロースター、伝承、進化する戦闘メタ、そして将来的なユーザー製チャンピオンのクリエイター経済。護城河はIPとメタであり、エンジンではない。

---

## 5. リスクと対策

- **アート・デザイン工数が最大コスト** → 強力な戦闘タイプ1種＋厳選ロースターを先行公開、残りはスタブ。身体はキャリアからプロシージャル生成しアート負荷を抑制。
- **公平な判定** → 客観的勝利条件、既定ローカル判定、オプションLLM判定は境界付き乗数とし、説得が試合を乗っ取れないようにする。
- **ノベルティ後の継続** → 進行システム、公正な順位表、登頂熟練度、（ロードマップ）シーズン＋トレード。
- **バイラルゲームの予測不可能性** → 単一ローンチではなく、*フォーマット・IP・クリエイター経済*に賭ける。
