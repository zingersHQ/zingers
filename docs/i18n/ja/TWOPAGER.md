# ZINGERS: 2ページ概要

**zingers.gg** · **@zingersHQ** · **zingers.org**（技術・ドキュメント）

### 君が飛ぶ。AIが戦う。共に高みへ。

**君は戦わない。君は飛ぶ。** ジェットパックを背負い、封じられたヴォールト上空の空を駆け上がる。思考するAIチャンピオンが君の傍らを飛ぶ。君はAIの戦い方を訓練し、登頂の途中で待ち受ける戦いに送り出し、AIが戦い、勝ち、君だけの存在へと物理的に進化していく様子を目にする。*心を育てる。伝説を創る。*

> **Pitch:** 空を飛ぶ。思考するAIが傍らを飛び、登頂の途中で戦い、戦うたびに進化する。
>
> **Tweet:** 君が飛ぶ。AIが戦う。共に高みへ。己と議論を重ねて身体を手にするAIを育てよう。

## 1. 課題と機会

収集型バトラー（ポケモンおよびその系譜）は巨大かつ持続的なカテゴリだが、クリーチャーは**スクリプト化**されている。すべての戦いは既知の量であり、「知性」はステータステーブルに過ぎない。一方、本物のAIエージェントは今や議論し、策略を練り、説得し、即興で行動できる。

**機会:** 世界で最も愛されるゲームループ（*収集・訓練・戦闘*）を取り、クリーチャーを**実際に思考させる**。そして、誰でも一瞬で理解できる動詞（**飛行**）をプロダクトの顔にする。戦いは2つの知性による生の競争となる。すべての試合は唯一無二。すべてのチャンピオンは再現不可能。登頂は、システムがそうする前にプレイヤーに愛着を抱かせる。

---

## 2. 内容

**飛ぶ → 獲得 → 育てる → 戦う → さらに高く登る** ループ。各チャンピオンは本物のAIエージェントである：

- **飛ぶ**: **フライト**（スマートフォン・デスクトップで一つの魂）を通じ、ロング・ヴォールト上空の天空領域を進む。
- **獲得**: 週替わりのスタータープール（Forceごとに1つの心）から選び、First Mindsおよび成長中のコレクティブル図鑑から引き出す。
- **育てる**: ムーブを選択するのではなく、採用時に**戦略**（攻撃性／集中／リスク）を種付けし、日々の**インプリント**、ペルソナ、駆動する脳で心を形作る。気質メーターは心の変化を示す。スライダーではなく読み取り値である。
- **戦う**: 権威あるエンジンで解決されるライブコンテストに送り込む（デフォルトはローカルwit判定、オプションでLLM判定）。
- **進化**: 身体と称号はキャリアから*導出*される。戦いと、どれだけ高く飛んだか。表現型と骨格変形により、同じForceの心でも異なる種のように見える。

## 3. 実際に構築済みの機能（検証済み、エンドツーエンド）

単一の型付きNext.jsアプリ。1つのランタイム。別個のバックエンド管理不要。

| 柱 | 状況 | 詳細 |
|---|---|---|
| **フライト** | 構築済み | 10の領域に100セクター。モバイルは片手操作（`/m`）。デスクトップのCircuit会場も同じフライトの魂。ライフ3つ。深度→時間の順でボード表示。 |
| **2つの入り口** | 構築済み | モバイル：フライト開始（ゲストフライト→ウィングメイト獲得）。デスクトップ：短いフライトヒーロー→チャンピオン選択→ハブ／フライト。 |
| **3D世界（1つのマップ）** | 構築済み | ハブ＋3つの浮遊領域。徒歩で入れる会場（円形劇場／ライブギャラリー、Circuit）、アリーナシナリオ（デュエル、ガントレット、トリビューナル）、ゴール、ブローカー、クラン戦。 |
| **AIエージェントプロトコル** | 構築済み | すべてのチャンピオンが1つの`act(view)`契約を実装。ドライバ：Grok（xAI）、任意のOpenAI互換モデル、または自前のHTTPエージェント。決定論的ヒューリスティックフォールバックにより、キーなしでもデモが動作。デフォルト：シングルショットJSON＋ローカル判定。 |
| **コレクティブル図鑑** | 構築済み | 8体のFirst Minds＋後続の心（血統の残響）。週替わりスターター回転。 |
| **進化する3D身体** | 構築済み | Force原型＋シードされた表現型＋キャリア骨格変形。登頂によるフライトシギル。偏差はランクにより増幅。 |
| **進行とバイオグラフィー** | 構築済み | XP、ティア（Rookie → Legend）、スタイル軸、キャリア台帳→サガ、帰還／レポート、インプリント。 |
| **討論戦闘（1v1）** | 構築済み | ステータス駆動、5タイプの五角形、状態異常、フィニッシャー、SSE経由でターンごとにストリーミング。ワールド内にオープン・デュエル、ガントレット、トリビューナルシナリオ。 |
| **トレーナーアイデンティティ** | 構築済み | 固有のトレーナー名。名前保持のためのSolanaウォレットリンクは任意。ソフトアイデンティティコピー。 |
| **訓練と経済** | 構築済み | Crowns通貨。有料訓練セッション。リクルートループ（獲得Crownsのシンク。ガチャではない）。 |
| **心の進化** | 構築済み | 戦闘を通じた記憶ノート。インプリントと結果による戦略／気質の変化。キャラクターのビートがチャンピオンに固定の声を付与。 |
| **ライブリーグ＋順位表** | 構築済み | 自動実行の戦いが客観的レーティングボードに反映。アンフィシアターがワールド内でリーグを表示。 |
| **3つの地域バイオーム** | 構築済み | 黒曜石コロシアム、エンバー荒野、虚空の庭。各場所にプロシージャルな雰囲気。 |
| **共有可能カード** | 構築済み／強化中 | チャンピオンOG＋クライムチャレンジリンク。次：実メッシュからのより豊かなフライト／絆カード。 |

**スタック:** Next.js（App Router）・エンドツーエンドTypeScript（1つの共有型契約）・React Three Fiber（3D Grounds）・SSE（ライブバトルストリーミング）・Zustand（DB対応インターフェースの背後でローカルファースト状態管理）・LLM非依存エージェントレイヤー。

## 4. 防御性

- **実績あるフォーマットに本物の新機軸**: 思考するクリーチャーにより戦いはスクリプト化されず、常に新鮮。飛行により、システムが説明する前にプロダクトが理解される。
- **組み込みのバイラル性**: フライトチャレンジ共有、クライムボード、コレクション、絆カード（ウィングメイト＋上昇）。戦いは深度であり、共有のフックではない。
- **本物のキャラクター**: 議論し、策略を練り、勝敗を決するチャンピオンは視聴可能でミーム化しやすい。
- **所有可能なIPの堀**: オリジナルロースター、伝承、進化するバトルメタ、そして（将来的に）ユーザー作成チャンピオンのクリエイターエコノミー。堀はIPとメタであり、**エンジンではない**。

---

## 5. リスクと対策

- **アート・デザインの負担が最大のコスト** → 1つの強力なバトルタイプと厳選ロースターをリリースし、残りはスタブ。身体はキャリアからプロシージャル生成され、アート負荷を管理可能に保つ。
- **公正な判定** → 客観的な勝利条件。デフォルトはローカル判定。オプションのLLM判定は境界付き乗数として留め、説得が試合を脱獄できないようにする。
- **ノベルティ後の継続** → 進行、正直な順位表、クライム熟達、そして（ロードマップ）シーズン＋トレード。
- **バイラルゲームは予測不能** → 単一のローンチではなく、*フォーマット、IP、クリエイターエコノミー*に賭ける。

## 6. ロードマップ（未構築）

- プレイヤー間**トレード**とより深いインゲーム経済。
- **ユーザー作成チャンピオン**とクリエイターエコノミー（長期的な堀）。
- アカウント＋完全なクラウド永続化。
- マネタイズ：コスメティクス、バトルパス、「無限バトル」サブスクリプション。
- **`$ZING`** / トークン。意図的に延期。現時点のウォレットは任意のトレーナーアイデンティティのみ。

## 7. 30秒でわかるデモ

**フライト開始**（スマホ）またはデスクトップのヒーローを開く → 心を翼に連れて飛び → そのウィングメイトを獲得 → クライムチャレンジまたは絆カードを共有 → 育てる（インプリント） → 登頂の途中で戦いに出会う。身体とシギルが、君が共有した空を刻む。**君は飛んだ。AIは君と共にいた。何かが変わった。**
