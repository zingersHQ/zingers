> **初回体験**：モバイル＝フライト→上昇→ウィングメイト獲得、デスクトップ＝短いフライト→チャンピオン選択→グラウンズ／サーキット。以下の戦闘主導フローは現在のオンボーディングではありません。

前回のAct 1パスからの制作メモ（参考／考古用に残す）。

## Act 1フロー（旧パス: 廃止済み）

```
ファーストラン（シネマティック）→ ファーストデュエル：採用（5つのフォース、週替わり、ローキープレビュー）
  → 採用ビート（トレーナー＋チャンピオン）→ 戦略シード→ ルーキーとして採用→ ヴォイド戦
  → 進化カード→ コンコード着陸（トレーナービート優先）→ トレーナーがスポーン地点でコーチを分離
  → ガイド付き初アリーナ（グラウンズゲートをスポットライト）→ 自由探索＋コーチ
```

## 60秒ティーチング契約（フライトファースト向け更新）

初回フライト／選択を終える前に、プレイヤーは以下を理解していなければならない：

- [ ] *君は飛ぶ。それが戦う。共に高みへ。*
- [ ] *君はこのチャンピオンを育てる——君自身が戦士ではない。*（柔らかいアイデンティティ表現、所有権強調なし）
- [ ] 採用時のルーキーボディは弧の1日目であり、選択プレビューからのダウングレードではない

公式コピー：`lib/player-copy.ts` · ビジョン：`docs/design-vision.md` · 用語集：`docs/vocabulary.md`

サガ（君の物語）と年代記（世界の物語）は意図的に区別されている。サガは1つのトレーナーランク数で進行するため、プレイスタイルに関係なく進む。一方、年代記はシーズンクロックで回る。

## 意図的に変更しないもの

- **コード／アナリティクスイベントキー**: 依然として`bout`（安定したサーバートラッキング）
- **`useBout`フック名**: 内部用、プレイヤー向けラベルではない
- **Docs/README/MCP**: 開発者向け、ゲーム内コピーパスには含まれない（正典については`docs/`同期を参照）

## サウンドトラック（場所ごとのプロシージャル）

| ムード | タイミング |
|--------|------------|
| `concord` | コンコードハブ |
| `colosseum` | オブシディアンコロシアム／グラウンズ地域 |
| `ember` | エンバーガントレット |
| `void` | ヴォイドガーデン |
| `amphitheatre` | アンフィシアター会場 |
| `circuit` | フライト（サーキット／クライム） |
| `battle` | ライブ戦闘またはキーパーデュエル |

スコアは`lib/ambience-scores.ts`に配置（モード＋AABA形式）。  
`grounds-screen`は`resolveAmbienceMood()`を呼び、モバイルのクライムは`circuit`を固定する。
