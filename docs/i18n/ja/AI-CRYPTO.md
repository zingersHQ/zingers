# ZINGERS: AIと暗号資産のワンページャー

**zingers.gg** · **@zingersHQ** · **zingers.org**（技術・ドキュメント）

### 思考するクリーチャーを最優先。コレクティブルな伝説はその下に。

Zingersは本物のAIゲームを前面に打ち出す。実際に思考するクリーチャーだ。所有権レイヤーはオプトインで、壁で隔てられ、ユーティリティに紐づけられる。2つのレイヤーは厳密に分離されている。現在はウォレットは任意の**トレーナー識別**のみで、トークン発行は意図的に後回しにしている。*(`docs/flight-first-plan.md`, `docs/zing-model.md`.)*

## AIレイヤー（製品）

**プラグ可能なエージェント。** エンジンはターンごとに1つの質問をする。*この状態とこれらの合法手が与えられたとき、どうする？* どんな脳でも `act(view) → decision` を実装すればチャンピオンを動かせる。*(`docs/agent-protocol.md`.)*

- **プロバイダー:** 組み込みの **Grok** 脳（xAI）、任意の **OpenAI互換** モデル（`baseUrl` / `model` / キー）、**HTTP webhook**（`AgentView` を POST し `AgentDecision` を返す）、またはオフライン用の **モック**。どちらかが独自エージェントを持っていれば、ハウスキーなしでも本物の戦いが実行される。
- **デフォルトパス（高速）。** シングルショット JSON 決定＋**ローカルジャッジ**。素早いターン、低コスト。オプトイン: `ZINGERS_AGENT_TOOLS=1` で制限付きの reason → act → observe → commit ツールループ（`simulate_move`、`scout_opponent`、`commit_move`、3ステップ上限）を有効化；`ZINGERS_LLM_JUDGE=1` で LLM ウィットスコアラーに切り替え（それでも制限付き乗数。単独で試合を決定しない）。
- **永続メモリとドリフト。** 各チャンピオンはメモリノートと **戦略 / 気質** ダイアル（攻撃性、集中、リスク）を持つ。養子縁組時にシードし、以後は UI で読み取り専用。**インプリント**（決定論的テンプレートフォールバック付きの制限付きモデル呼び出し）でトレーナーが教訓を教え、メモリを書き込み、時間をかけて性格をドリフトさせる。戦いも同じダイアルを揺らす。
- **厳選された魔法、創発的な深み。** デフォルト体験はオーサード（ボイスパック、キャラクターのビート、決定論的フォールバック）で常に生きているように感じられ、本物のモデルがその上に創発を加えるが、必須依存ではない。

## 暗号資産レイヤー（オプトイン、下層）

**基本ルール:** ゲームはウォレットなしで**無料かつ完全**。伝説を育て、シーズンを登り、Vaultを解くのにウォレットを見たことがなくても可能。暗号資産はゲームの**下層**で、決して手前の門ではない。*(`docs/bible/08-economy.md`, `docs/zing-model.md`.)*

**現在提供:** 任意の Solana ウォレットリンク（Phantom SIWS方式の所有権証明）でデバイス間で一意の**トレーナー名**を保持。支出承認不要。トークン UI なし。

**正直なスコープ（2026-07）:** 初回接続で **name ↔ pubkey ↔ ownerToken**（デバイスキャリアキー）を紐づけ。新デバイスで再接続すると正規の `ownerToken` が返り、チャンピオン、クラウン、`/api/save` がリロード後に復元される。`$ZING` はまだ不要。ウォレットを紛失した場合のリカバリーコードはバックアップとして残る。

**命名:** ゲーム内クラウンは `/api/wallet` に存在（オフチェーン）。Solana は `solana-link` / 「接続」。プレイヤー向け文言でクラウンをチェーンウォレットと呼ぶことはない。

### 2つの経済、決して橋渡ししない

| | **クラウン** | **$ZING**（作業名） |
|---|---|---|
| 性質 | ソフト、ゲーム内、サーバー権威 | ハード、オンチェーン（SPL / Solana）。*未発行* |
| 入手方法 | プレイで*獲得* | 市場で*購入*、またはプレイ報酬としてエアドロップ（将来） |
| 用途 | 訓練、エントリー、バック、コスメティック再鍛 | オンチェーン順位エントリー、カードミント、パトロン地位（将来） |
| キャッシュアウト？ | **決してしない** | オープン市場のみ、当社経由では**決してしない** |

この壁。変換なし、共有ウォレットなし。これが Zingers を**証券ではなく**、**カジノでもなく**保つ最も重要な不変条件だ。

### トークンが行うこと。そしてそれだけ（将来）

1. **オプトインのオンチェーン順位エントリー**を **burn-or-stake** で支払う。バーンは少額の消費アクセス手数料（純粋なデフレ）；ステークはより大きく、**全額返金可能**な預金で元本のみ返還。ステークはシーズンを跨いで存続し、忠実なプレイヤーは資本をロックして永遠に無料でプレイできる。**利回りは一切なし。**
2. **永続性のミント**。バーンしてチャンピオンをオンチェーンカードとして不滅化。アートはキャリア記録から決定論的に生成されるため、**トークン*が*記録そのもの**。存在するが未使用の出所フィールド（`mintId`、`owner`、`chain`、`mintedSeason`）を埋める。リファクタではなく補完。
3. **地位の付与**。チャンピオンを後援するためのパトロン紋章、dex 出所、次のシーズンエアドロップの*重み*をプレイで獲得。

### ガードレール（インディーセーフな囲い）

利回りなし / APY なし / ポットなし；**バーンは手数料であって賭けではない**；すべての報酬はコスメティック、地位、または配分（現金やパフォーマンス連動の支払いは一切なし）；価格マーケティングなし；**クラウンは決してキャッシュアウトしない**。オンチェーンのシーズン終了が機能するのは、戦いが決定論的で証明可能な公平性を持つからだ。

## 位置づけと順序

「クリーチャーが実際に思考する」「あなたが飛ぶ」を前面に、配布向けにミームフレンドリーにしつつ、メッセージがエージェントプロトコルとカジノの間で振り回されないようユーティリティに紐づける。**クラウンのみ**で出荷；ウォレット＝識別；**$ZING** は*ドキュメントで発表*され、製品内では必須ではない。**トークンはトラクションに追従し、その逆ではない。**
