## AI 層（プロダクト）

差し替え可能なエージェント：`act(view) → decision`。Grok、OpenAI 互換、HTTP webhook、
または mock。既定は単発 JSON + ローカル判定。記憶と気質。インプリント。
キュレーションの上に創発。

## 暗号層（任意、下）

**規則：** ウォレットなしでもゲームは無料で完全。

**今日：** 任意の Solana 連携（トレーナー身分）。まだ支出なし。

**ロック済みユーティリティ（次の実装）：** **`$ZING` をバーン → 不滅化**して
チャンピオンをオンチェーンカードに。スナップショット芸術。シーズン／レア度の版。
段階固定バーン。オラクルなし。カーブなし。利回りなし。生きたチャンピオンの
クラウンへの手数料なし。

| | **クラウン** | **$ZING** |
|---|---|---|
| 性質 | ソフト、サーバー | ハード、Solana SPL |
| 用途 | プレイ | バーンして不滅化 |
| 現金化？ | 決してしない | 公開市場のみ |

**仕組み：** サーバーが資格を証明 → 短命バウチャー → 1 tx でバーン＋ミント。
原子的。失敗なら mint も burn もない。

**ガードレール：** yield なし、P2W なし、クラウン橋なし、ユーザー作成チャンピオンなし。

暗号なしでも常に遊べる。完全モデル：`docs/zing-model.md`。
