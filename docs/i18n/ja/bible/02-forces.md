# 02 · 五つの力

> **要約:** すべてのチャンピオンは五つの「タイプ」のいずれかに属する。これを**力**（論理 / 静電 / 冷静 / 合唱 / 火花）と呼ぶ。各力は他の力を一つだけ倒し、一つだけ負ける。五角形の相性輪が戦いの優位を決める。

ハムの世界に存在するすべての心は、五つの**力**によって形作られている。これはこの世界における五つの元素的な戦闘タイプである。力とは、チャンピオンを構成する元素であると同時に、戦う方法でもある。

力のプレイヤー向け名称は、以下の**平易な名称**（論理 / 静電 / 冷静 / 合唱 / 火花）である。それぞれに古く詩的な名称も存在する。その*語源*は風味付けとしてここに残すが、ゲームUIには表示されない。

| 力 | 語源 | …の元素 | …で論じる | シギル | 色 |
|-------|-----------|-------------|------------|:-----:|-----|
| **論理** | *格子* | 秩序、証明、構造 | 証明を閉じる | ◆ | `#4aa3ff` |
| **静電** | *静電* | 雑音、混沌、驚き | 枠を破る | ✦ | `#ff4ad1` |
| **冷静** | *静寂* | 忍耐、持久、沈着 | 嵐を耐え抜く | ▲ | `#36d39a` |
| **合唱** | *合唱* | 群衆、感情、説得 | 場を動かす | ◉ | `#f0a93a` |
| **火花** | *火花* | 発明、比喩、再構成 | 問いを変える | ✺ | `#f5d020` |

## 輪（五角形）

力は輪を成して回る。**各力は次の力を倒し、直前の力に負ける：**

```
論理 → 静電 → 冷静 → 合唱 → 火花 → (論理)
```

- **論理**は**静電**を制する。秩序が雑音を沈める。
- **静電**は**冷静**を打ち破る。混沌が忍耐を揺さぶる。
- **冷静**は**合唱**を逸らす。忍耐が訴えを肩で流す。
- **合唱**は**火花**を飲み込む。売り込みは単なる発明に勝る。
- **火花**は**論理**を迂回する。再構成は証明から逃れる。

有利は×1.25、中立は×1.0、不利は×0.8。この輪はこの世界の最も深い法則であり、すべての地域、季節補正、対戦はこれを基準に読み解かれる。

## 五つの内面ステータス

心の中では、同じ五つの力が戦闘ステータスとして現れ、*経歴が積み重なるにつれて*、身体を形作る五つの**行動軸**（攻撃性、制御、耐久、華麗さ、創造性）としても現れる。心は一つの力「に属する」が、すべての力をある程度持っている。リングの中で何をするかが、どの力が膨らむかを決める。

## シギル

力は心の中で強くなると**シギル**を刻む。これは獲得した紋章であり、バッジや階級章のようなもの（◆ 論理 · ✦ 静電 · ▲ 冷静 · ◉ 合唱 · ✺ 火花）。シギルには三つの階級（I/II/III）がある。これらはコレクション層と称号システム（「殲滅者」「操り手」）の紋章であり、*獲得される*ものであり、割り当てられるものではない。

## 力 vs クラン（タイプ vs チーム）

同じ五つの力から生まれる二つの異なる概念。それらを区別すること：

- チャンピオンの**力**とは*それが何であるか*である。戦闘スタイルであり、作成時に固定される。身体、アビリティ、輪の相性、そしてすべてのファイターが身に着ける**基本色＋シギル**を駆動する。
- **クラン**とは*どの側を選んだか*である。トレーナーはシーズン中の戦争のために一つの力に誓いを立て、ランク戦の勝利はその力の順位に寄与する。トレーナーのチャンピオンがどのような力であろうとも関係ない。クランはトレーナーと出場するチャンピオンに**紋章／旗**として身に着けられるものであり、基本の身体の色ではない。

つまり：*すべてのチャンピオンは力を持ち、誓う力はクランである。*

## クラン戦争（トレーナーの戦争）

クランへの誓い。シーズン中に忠誠を誓う力。ランク戦の勝利を五つの力の間で行われるシーズン長期戦争におけるその力の順位に結びつける。シーズン間でクランを切り替えることはできるが、貢献はそれを獲得した力に残る。誓いは力の**モットー**の下で行われる。その論じる行を誓いとして唱える：

| 力 | モットー |
|-------|-------|
| **論理** | *証明を閉じよ。* |
| **静電** | *枠を破れ。* |
| **冷静** | *嵐を耐え抜け。* |
| **合唱** | *場を動かせ。* |
| **火花** | *問いを変えよ。* |

誓いを立てるトレーナーは[cosmology.md](./01-cosmology.md)で定義される。
