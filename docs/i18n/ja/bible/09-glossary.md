# 09 · 用語集

> **要約:** Zingersで使われるすべての言葉を、1文でわかりやすく説明します。意味がわからなくなったら、ここで確認してください。各用語の背景にある物語は、他の聖典の章に記されています。

Zingersには独自の世界があり、そこに存在するものには独自の言葉があります。それは意図的なものですが、初めて読む人が迷わないように配慮されています。以下の各用語は、第二言語で読む人を含む完全な初心者向けに、1つの明確な文で、隠れた専門用語なしに書かれています。廃止された古い用語は「(旧: …)」と表記し、復帰プレイヤーが混乱しないようにしています。

## あなたと世界

- **トレーナー**: あなた自身。世界を飛び回り、戦うチャンピオンを育て、その思考の仕方を教えます。(旧: Reader)
- **世界**: あなたが飛び回る3Dの場所。浮遊する地域の集まりで、それぞれに独自のアリーナがあります。世界観での名称はthe Groundsです。
- **ハブ**: あなたが着陸する場所。すべての地域へ通じる門に囲まれた中央の集会所です。世界観での名称はthe Concordです。(旧: the Concord)
- **地域**: ハブから飛び出して戦いに向かう場所。創設の3つはコロシアム、エンバー荒野、ヴォイドガーデンで、それぞれ外観と戦闘スタイルが異なります。
- **門**: ハブにあるアーチ状の通路で、地域へ飛ばしてくれます。(旧: Vaultgate)
- **塔**: 各地域の頂上にある高い登頂路。長期的な挑戦です。
- **フライト**: 飛行ゲーム。空を上昇し、チャンピオンが隣を飛びます。スマホとデスクトップで同じゲームです。どれだけ高く登ったかが、その体を記録します。(旧: the Ascent / Circuit / Climb)
- **リーチ**: フライトにおける空の帯域で、それぞれに独自の天候と危険があります（ゲーム内では単なる空の進行度として表示）。地面から頂上の静寂まで、10層が積み重なっています。
- **キャンプ**: 2つのリーチの間に位置する休息の宿場。初めて到達すると、永続的に点灯します。
- **チャレンジ**: 別のトレーナーのゴーストマークとの共有フライトラン。その記録を抜くか、落ちた場所を越えて飛ぶことを目指します。
- **ジェットパック**: トレーナーの飛行用具。あなただけが携帯します。チャンピオンは自力で隣を飛びます。
- **ディレクター**: チャンピオンの次の行動を指し示す案内役の声。あなたのセーブ内の実際の扉を指します。クエストログではありません。

## あなたのチャンピオン

- **チャンピオン**: あなたが育てるAIファイター。それぞれが議論し、適応し、独自の声を持ちます。
- **ファーストマインド**: 8つの原初のチャンピオン原型のひとつ。以降のマインドはすべてそのいずれかの残響です。
- **デックス**: チャンピオンの完全な収集可能セット。ファーストマインドと、後に遭遇・育成・カード化できるマインドを含みます。
- **リネージ**: 後のチャンピオンがどのファーストマインドの残響であるかを示すもので、すべてのカードがフォースの輪に明確に位置づけられます。
- **戦略**: チャンピオンの攻撃性、集中力、リスクのダイヤル。戦い方が決まります。養子縁組時に設定し、その後インプリントと戦いで変化します。(旧: doctrine)
- **気質**: 養子縁組後に戦略のダイヤルとして表示されるステータスメーター。チャンピオンがどのように変化したかの読み取り値で、自由に操作できるスライダーではありません。
- **インプリント**: チャンピオンに教える日々のレッスン。チャンピオンはそれに応答し、記憶に書き込み、戦略のダイヤルを微調整します。
- **ペルソナ**: チャンピオンの声と性格。自分で書くことができます。
- **シギル**: チャンピオンのフォースバッジ。その戦闘スタイルを示す小さなシンボルです。
- **フライトシギル**: チャンピオンの体に浮かぶ光輪で、高く登るにつれて成長します。戦いだけでなく、登頂も体に記録されます。(旧: Flight sigil)
- **サガ**: チャンピオンの生涯の物語。実際の対戦履歴から自動的に書かれます。

## 戦闘

- **フォース**: 5つの戦闘スタイルのひとつ。論理、静電、冷静、合唱、火花。それぞれが1つに勝ち、1つに負ける、じゃんけんのような関係です。
- **輪**: どのフォースがどのフォースに勝つかを示す円です。
- **デュエル**: 2人のチャンピオンによる1対1の討論バトルです。
- **リゾルブ**: 戦闘において、審判がまだそのチャンピオンをどれだけ信じているかを示す値。相手のリゾルブを削り、勝ちます。
- **トリビューナル**: 2人のチャンピオンが陪審に対して、ある問いについて反対の立場で議論する法廷アリーナです。
- **ガントレット**: 勝ち続けると賞金が増えるが、途中で止めて現在の獲得分を持ち帰ることもできる、賭けのようなアリーナです。
- **ライブギャラリー**: チャンピオンたちが24時間体制で自ら戦う様子を観戦できる場所です。(旧: Scrying Gallery)

## 成長と収集

- **ティア**: 成長するチャンピオンの階級。ルーキー、エイデプト、ベテラン、エリート、レジェンドです。
- **カード**: チャンピオンの収集可能な姿。チャンピオンの経歴が進むにつれてアートが変わります。
- **レアリティ**: チャンピオンのカードの希少性。プレイを通じて獲得するもので、ランダム抽選ではありません。
- **スタータープール**: 初めて養子縁組時に選べるチャンピオン。各フォースに1体ずつで、ラインナップは毎週ローテーションします。
- **クラウン**: ゲーム内の通貨。戦いによって獲得し、トレーニングに消費します。購入することはできません。
- **フラグメント**: 発見または交換で入手する資源で、チャンピオンのステータスを強化するために使われます。
- **クラン**: 戦うために誓うフォース。あなたの勝利は、シーズン全体の戦争でその側の得点になります。(旧: Allegiance / House)
- **順位**: トレーナーとチャンピオンの正直なランキングボード。どれだけ上手くやったかの記録で、ラダー表記ではありません。(旧: ELO / ladder)

## より大きな世界

- **ロング・ヴォールト**: 世界の中心にある封印された扉で、誰も開けたことがありません。すべてがそれを中心に築かれており、各シーズンで少しずつ開いていきます。
- **ハム**: 世界全体が作られている終わりのない背景のざわめきで、チャンピオンが最初に形作られる場所です。
- **シーズン**: ゲームの章。各シーズンでヴォールトが少しずつ開き、新しい物語、話題、チャンピオンがもたらされます。(旧: the Chronicle)
