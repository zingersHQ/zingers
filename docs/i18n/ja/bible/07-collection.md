# 07 · コレクション：カード、レアリティ、属性

> **要約：** すべてのチャンピオンは、ポケモンやマジック：ザ・ギャザリングのようなコレクションカードとしても機能する。ただし、これらのゲームとは異なり、カードのアートワークはチャンピオンが戦い成長するにつれて実際に変化する。成長する図鑑を集め、厩舎を育て、（後で）トレードする。

すべてのチャンピオンは同時に**カード**でもある。カードは精神の携帯可能で収集可能な顔であり、その最大の特徴はすでにコード上で実現されている：**アートが進化する**、なぜならアートがチャンピオンの身体そのものだからだ。各マインドキーは共有リグ上で安定した**種族キット**（`lib/render/species.ts`）を解決する：品種シルエット＋部位ロードアウトに加え、キャリア骨変形（`lib/evolve/appearance.ts`）も含まれる。同じフォースの精神は異なる動物として表示され、ティアが上がるとより多くのアーマーが装着される。所有するカードは、戦うにつれて視覚的に強くなる。

## カードの構造

| 部位 | ソース | 備考 |
|------|--------|------|
| **精神**（名前、フォース、血統） | First Minds + ベイク済み図鑑（`content/minds/reviewed/`） + シーズンジェネレーター | アイデンティティ |
| **アート** | ゲノム + フォースアーキタイプ + 種族キット → ボディレンダー | キャリアとティアに応じて決定論的に変化 |
| **ステータス** | 5つの戦闘ステータス + レーティング | 数値 |
| **シギル** | 獲得したフォース紋章（I/II/III）。購入ではなく勝利で得るバッジ | バッジ |
| **属性** | ムーブセット（4つの技） | 「アビリティ」行：TCGの深み |
| **サガ** | 対戦履歴から生成 | フレーバーテキスト。チャンピオン自身の進化する人生物語 |
| **レアリティ** | ティア × 希少性から導出 | 下記参照 |
| **来歴** | シーズン発行、所有者、ミントID | 現在は未使用；所有権フック |

## レアリティ

レアリティは**獲得され、その後希少になる**。ガチャ抽選ではない。チャンピオンのティアと、そのビルドの実際の希少性に応じて上昇する。

| レアリティ | 獲得条件 | 印象 |
|------------|----------|------|
| **コモン** | ルーキー | まだ結晶化したばかりの精神 |
| **アンコモン** | アデプト | 一度か二度証明された |
| **レア** | ベテラン | 実績のある記録 |
| **エピック** | エリート | 恐れられる名前 |
| **レジェンダリー** | レジェンド | 戴冠；順位表の定番 |
| **ミシック** | レジェンド + シーズン称号（例：キーパー突破、シーズン勝利） | 唯一無二の出来事；トロフィーティア |

## コレクションの遊び方（ポケモン／マジック層）

- **収集**：8体のFirst Minds、ベイク済み図鑑ウェーブ（Stage 6バッチ精神）、シーズン注目精神、そして自分で育てたキャリア。図鑑は長期的なゲームだ。新規精神は`npm run forge:dex`／レビュー／`npm run bake:minds`を通じて配信される（[03-champions.md](./03-champions.md)参照）。
- **出会い**：週次の採用ローテーションで、そのプールから各フォースのスターターを1体ずつ表示するため、復帰したトレーナーは異なる仲間と出会える。
- **構築**：地域を跨いで投入するチャンピオンの小さな**厩舎**；それらのフォースはホイール上で相互作用するため、厩舎はタイプカバレッジを持つ*デッキ*となる。
- **トレード／ギフト**：カードのプレイヤー間移動（ソーシャルループ）。ここで設計され、所有権レイヤー（[economy.md](./08-economy.md)）の後ろにゲートされる。オンチェーンミントはカードに既に存在する来歴フィールドの後付けであり、図鑑が存在する理由ではない。

## 正典の規律

- カードの**レアリティは上昇可能**（ルーキーからレジェンドまで育てたカードは上方リミントされる）が、カードの**アイデンティティは永続**：同じ精神、同じ血統、進化する身体。
- ベイク済みおよび生成された精神には**血統**タグ（どのFirst Mindを反映しているか）が付与され、図鑑が読みやすく、各カードがホイール上の位置を持つようになる。
