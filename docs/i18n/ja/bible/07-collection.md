# 07 · コレクション：カード、レアリティ、属性

> **要約：** すべてのチャンピオンはコレクションカードとしても機能し、そのカードのイラストはチャンピオンが戦い、成長するにつれて変化する。あなたは成長する図鑑を集め、厩舎を育て、（後に）トレードを行う。

すべてのチャンピオンは同時に**カード**でもある。カードは心の携帯可能で収集可能な顔であり、その最大の特徴はすでに真実である：**イラストが進化する**。なぜなら、イラストこそがチャンピオンの肉体だからだ。各心は共有フレームに安定した**種族マーク**を身に着けている。品種の体型（竹馬脚、タンク、ずんぐり、繊細、演説者、リーチ、または基準）と部位の装備、そして戦いとティアと共に成長するキャリアボディだ。同じフォースの心は異なる動物として読み取られ、ティアはより多くの装甲を追加する。あなたが所有するカードは、戦うにつれて視覚的に強くなる。

## カードの構造

| 部位 | ソース | 備考 |
|------|--------|-------|
| **心**（名前、フォース、血統） | ファーストマインド＋図鑑＋シーズンジェネレーター | アイデンティティ |
| **イラスト** | キャリア＋フォース＋種族マーク→ボディ | 戦いとティアで変化 |
| **ステータス** | 5つの戦闘ステータス＋レーティング | 数値 |
| **シギル** | 獲得したフォース紋章（I/II/III）。購入ではなく勝利で得るバッジ | バッジ |
| **属性** | ムーブセット（4つのムーブ） | アビリティライン：戦闘で何ができるか |
| **サガ** | 対戦履歴から生成 | フレーバーテキスト。チャンピオン自身の成長する人生物語 |
| **レアリティ** | ティア×希少性から導出 | 下記参照 |
| **来歴** | シーズン発行、オーナー、ミントID | 現在は不活性。所有権フック |

## レアリティ

レアリティは**獲得され、その後希少になる**。ランダム抽選ではない。チャンピオンのティアと、そのビルドが実際にどれだけ稀少かによって上昇する。

| レアリティ | 獲得条件 | 印象 |
|------------|----------|------|
| **コモン** | ルーキー | ようやく凝固したばかりの心 |
| **アンコモン** | アデプト | 一度か二度証明された |
| **レア** | ベテラン | 実績のある記録 |
| **エピック** | エリート | 恐れられる名 |
| **レジェンダリー** | レジェンド | 戴冠。ランキングの常連 |
| **ミシック** | レジェンド＋シーズンタイトル（シーズン優勝、クロニクル功績の達成など） | 唯一無二の出来事。トロフィーティア |

## コレクションの遊び方

- **収集**：8体のファーストマインド、後には図鑑のエコー、シーズン注目の心、そしてあなた自身が育てたキャリア。図鑑は長期的なゲームだ。新たな心は世界の成長に伴い波状に到来する（[03-champions.md](./03-champions.md)参照）。
- **出会い**：週次の養子ローテーションでは、そのプールからフォースごとに1体のスターターが表示されるため、帰還したトレーナーは時間とともに異なる相棒と出会う。
- **育成**：地域を横断して投入するチャンピオンの小さな**厩舎**。彼らのフォースはホイール上で相互作用するため、5つすべてにわたるカバレッジが重要になる。
- **トレード／ギフト**：カードのプレイヤー間移動（ソーシャルループ）。ここで設計され、所有権レイヤーの背後にゲートされる（[economy.md](./08-economy.md)）。オンチェーンミントはカードにすでに存在する来歴フィールドの後からの埋め込みであり、図鑑が存在する理由ではない。

## 世界観の規律

- カードの**レアリティは上昇可能**（ルーキーからレジェンドまで育てたカードは上方再発行される）が、カードの**アイデンティティは永続的**：同じ心、同じ血統、進化する肉体。
- 図鑑と生成された心には**血統**タグが付与される（どのファーストマインドのエコーか）。これにより図鑑は読みやすく保たれ、すべてのカードがホイール上に位置を持つ。
