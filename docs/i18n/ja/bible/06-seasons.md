# 06 · クロニクル：生きて生成されるシーズン

> **要約:** ゲームはテレビ番組のようにシーズン制で進行します。各シーズンごとに新たなストーリー章、新鮮な議論トピック、新しいエリアが自動生成されます。ただしランクとチャンピオンは引き継がれるため、ゼロから始まることはありません。進行中の全ストーリーは **クロニクル** と呼ばれます。

**クロニクル**。世界の進行中の、シーズンごとの物語。1 歩ずつ進みます：**シーズン**とは、Vault がもう 1 つの扉を開くことです。これはゲームのコンテンツ更新周期であり、同時にストーリーエンジンでもあります。シーズンは **生成的かつシード依存** です。1 つのシーズンシードとこの聖典から、ゲームはシーズンのストーリー、トピックバンク、地域バイアス、注目マインド、ランクポリシーを再現性をもって導き出し、常に正典に沿った内容を生成します。

## シーズンで更新されるもの

| 要素 | 各シーズンでの変更内容 | ソース |
|---------|--------------------------|--------|
| **アーク** | 短いナラティブ：どの扉が開き、何が漏れ出し、誰が台頭したか | シード＋正典から生成 |
| **トピックバンク** | シーズンの命題（扉が記憶していた「禁じられた問い」） | 生成され、扉のテーマに沿う |
| **地域バイアス** | 注目の地域＋そのフォースバイアス（または新地域） | フォースバランスを考慮して選択 |
| **注目マインド** | ファーストマインドの子孫／残響で、シーズンの「顔」 | 生成された血統 |
| **ランクポリシー** | **ソフトリセット**：ランクは平均値へ圧縮され、消去はされない | 固定ルール（下記） |

## ソフトランクリセット（「常にランクを維持する」ルール）

シーズンで順位を失うことを恐れる必要はありません。Zingers は順位を消しません。シーズン移行時、すべてのレーティングは基準値へ一定割合引き戻されます：

```
newRating = baseline + (oldRating - baseline) * RETENTION   // RETENTION ≈ 0.6
```

伝説は伝説のまま（ただし集団に近づく）、上位を目指す者は獲得した大部分を保持し、新規参入者にも新シーズンの上位を狙う現実的な機会が与えられます。名前は常に引き継がれます。あとはそれを守るだけです。

## チャンピオンサガ（個人生成ナラティブ）

世界全体の物語とは別に、**各チャンピオンは独自のサガを蓄積**します。それは個人の、進化し続ける人生物語です。実際の対戦履歴から：記憶ノート、最大のダンク、ライバル関係（誰に勝ち、誰に負けたか）。ジェネレーターはこれらを短く、進化するキャラクター内伝記に変換し、チャンピオンのカードとプロフィールに表示します。データはすでに存在します（`Recipe.memory`、バトル MVP ライン、レーティング記録）。シーズンエンジンはそれをナレーションするだけです。

## ジェネレーター契約（正典の遵守）

生成レイヤーは以下を満たさなければなりません：
1. **シード** を受け取る（シーズン番号が既定シード）。出力は再現可能であること。
2. この聖典を正典として読み、**フォース、キーパー、地域、ファーストマインドの名称を変更しない**。
3. **加算的** なロアのみを生成する：新しい扉であり、レトコンではない。
4. 優雅に劣化する：モデルが利用できない場合、正典テーブルから構成された **決定論的** シーズンへフォールバックし、ゲームは常にライブシーズンを持つ。

決定論的バックボーンは [`lib/lore/season.ts`](././lib/lore/season.ts) に存在し、オプションのモデルパスはアークとトピック風味をその上に追加します。
