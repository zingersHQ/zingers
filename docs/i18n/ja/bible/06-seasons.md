# 06 · 年代記：生きて生成される季節

> **要約：** ゲームはテレビシリーズのようにシーズン制で進行する。各シーズンごとに新たな物語章、新たな論題、新たなエリアが自動生成される。ランクとチャンピオンは引き継がれるため、ゼロから始まることはない。進行中の物語全体を **年代記** と呼ぶ。

**年代記**。世界がシーズンごとに紡ぐ、継続する物語。季節は金庫がもう一つの扉を開くたびに一歩進む。ゲームのコンテンツ更新であり、同時に物語エンジンでもある。季節は **生成され、シード値を持つ**：単一のシーズンシードとこの聖典から、物語、論題バンク、地域の偏り、注目の精神、ランク方針が再現性をもって導き出され、決して正典を逸脱しない。

## 季節が更新するもの

| 要素 | 各シーズンで変わるもの | 出典 |
|---------|--------------------------|--------|
| **弧** | 短い物語：どの扉が開き、何が漏れ出し、誰が台頭したか | シード＋正典から生成 |
| **論題バンク** | そのシーズンの命題（扉が記憶した「禁じられた問い」） | 生成され、扉に即したテーマ |
| **地域の偏り** | 注目の地域とそのフォースバイアス（または新地域） | フォースバランスのために選定 |
| **注目の精神** | 始源精神の子孫／残響、そのシーズンの「顔」 | 生成された血統 |
| **ランク方針** | **ソフトリセット**：ランクは平均値へ圧縮され、消去はされない | 固定ルール（下記） |

## ソフトランクリセット（「常にランクを保つ」ルール）

季節交代で順位を失うことを恐れてはならない。Zingersは順位を消さない。季節の変わり目に、全てのレーティングは基準値へ一定の割合で引き戻される：

```
newRating = baseline + (oldRating - baseline) * RETENTION   // RETENTION ≈ 0.6
```

伝説は伝説のまま（ただし集団に近づく）。這い上がってきた者は獲得したものの大半を保持し、新参者にも新シーズンの上位を狙う現実的な機会が与えられる。名前は常に引き継がれる。ただ、それを守る必要がある。

## チャンピオン・サガ（個人的生成物語）

世界の物語とは別に、**各チャンピオンは固有のサガを積み重ねる**。その個人的で進化する人生物語。実際の対戦履歴から：記憶ノート、最大のダンク、ライバル関係（誰に勝ち、誰に負けたか）。生成器はこれを短く、進化し続けるキャラクターらしい伝記に変換し、チャンピオンのカードとプロフィールに残す。記録は既に存在する。季節エンジンはそれを語るだけだ。

## 生成契約（正典の規律）

生成レイヤーは以下を満たさなければならない：
1. **シード** を受け取る（シーズン番号が既定のシード）。出力は再現可能でなければならない。
2. この聖典を正典として読み、フォース、地域、始源精神の名称を **変更してはならない**。
3. **加算的な** 伝承のみを産む：新しい扉であり、レトコンではない。
4. 優雅に劣化する：モデルが利用できない場合、正典テーブルから成る **決定論的** 季節にフォールバックする（ゲームは常に生きている季節を持つ）。

任意のモデルパスは、その決定論的骨格の上に弧と論題の風味を豊かにする。
