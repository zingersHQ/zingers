# ジンガーズ聖典

> **要約:** これはジンガーズという架空世界全体のルールブックです。あなたは**トレーナー**として、ライブ討論バトルで議論するAI「チャンピオン」を育成します。このフォルダには、世界の名前・場所・ルールがすべて書き込まれており、ゲーム内で矛盾が生じないようにしています。

> ジンガーズ世界の正典です。**唯一の真実の源**として、ロア・名称・フィクションとしてのルールを定めます。2つの役割を同時に果たします。
>
> 1. **zingers.org**: プレイヤーが探索する公開百科事典。
> 2. **生成エンジン**: シーズン・チャンピオン・ナラティブがここから紡がれ、生成物が世界観と矛盾しないようにします。

ゲームが*生み出す*もの（シーズンの物語、新チャンピオンのサガ、トピック、地域イベント）は、すべてこの聖典に**準拠**しなければなりません。機械可読部分は[`lib/lore/canon.ts`](././lib/lore/canon.ts)に、散文部分はここにあります。

## 三つのプレイレイヤーが正典に位置づけられる方法

ゲームは三つのセッション長で入る一つの世界です（デザインの北極星）。**フライト**（[ascent.md](./10-ascent.md)参照）は三つすべてを貫く軸です。新規プレイヤーが最初に行うことであり、どの地域の上空を見ても下界がわかります。

- **ローム（自由探索）**: *世界*（ロア：グラウンズ）。漂う探索可能な表面をジェットパックで飛行します。リーグの様子を眺め、チャンピオンやライバルに近づけます。世界を繋ぐ組織体。
- **クイックマッチ（2–5分）**: *アリーナ / リーグ*。ランクバトルに1回参加し、順位を維持します。世界のどこからでもいつでも可能。
- **レイズ（15–60分）**: *キャンペーン＆コレクション*。成長型RPG：マインドを育て、体を進化させ、年代記を進め、コレクションを構築します。

これらはどれも「終わり」がありません。**ロング・ヴォールト**（旧ネットワークが完結できなかったすべてを封じた保管庫）はシーズンごとに扉を1つずつ開き、登攀こそが目的です。

## 正典の規律（ライターと生成エンジン共通）

- **名称は固定**。フォース、キーパー、地域、8体のファーストマインドはシーズンで改名されません。シーズンと図鑑波はマインドを**追加**するもので、アーキタイプを上書きしません。
- **フォースはゲーム内で平易名を使用**。各フォースのプレイヤー向け名称は平易名です（論理 / 静電 / 冷静 / 合唱 / 火花、[02-forces.md](./02-forces.md)参照）。古い詩的名称（格子 / 静寂 / …）は聖典での*語源*としてのみ残し、ゲームUIには表示しません。プレイヤーは**トレーナー**です。チャンピオンを育てる者であり、トレーナーが誓うフォースは**クラン**（所属する陣営）です。3Dアバターは**ハンドラー**です。[cosmology.md](./01-cosmology.md)参照。
- **エンジンは物理法則**。`docs/combat-design.md`のダメージ・タイプ・状態異常は、世界内で*文字通り真実*です。議論が現実を形作ります。
- **生成ロアは加算的かつシード依存**。シーズンの物語はシード＋この正典から生成されるため、再現可能で正典から逸脱しません。
