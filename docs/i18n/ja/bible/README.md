# ジンガーズ聖典

> **要約:** これは、ジンガーズという架空の世界全体のルールブックです。あなたは**トレーナー**です。AIの「チャンピオン」を育て、生放送の討論バトルで戦わせます。このフォルダには、世界の名前・場所・ルールがすべて記されており、ゲームが自己矛盾を起こさないようにしています。

> ジンガーズ世界の正典。これは**伝承・名称・フィクションとしてのルール**に関する唯一の真実の源です。ふたつの役割を同時に果たします。
>
> 1. **zingers.org**: プレイヤーが探索する公開百科事典。
> 2. **生成エンジン**: シーズン・チャンピオン・物語が紡がれる正典。ゲームが生成するものがすべて一貫性を保つための基盤です。

ゲームが*生み出す*もの（シーズンの物語、新チャンピオンのサガ、話題、地域イベント）は、すべて**この聖典に準拠**していなければなりません。文章はここに生きています。

## ここに属するもの（属さないもの）

聖典は**世界のフィクションと、フィクションとしてのルール**です。世界で真実であることを書きます。トレーナーとは誰か、チャンピオンとは何か、フォースはどのように働くのか、なぜヴォールトが重要なのか。リポジトリを開いたことのない好奇心旺盛なプレイヤーでも読めるようにします。

**ここに置かないもの:** ソースファイルのパス、モジュール名、npmスクリプト、APIルート、スキーマのフィールド名、「リポジトリの実行方法」に関するメモ。これらは設計書と技術書（`docs/combat-design.md`、`docs/TECHNICAL.md`、`docs/climb.md`など）に属します。プロジェクトをクローンする人にしか意味をなさない段落は、誤った場所にあります。また、他のゲームとの比較（「ポケモンのような」「マジックレイヤー」など）も避けます。ジンガーズをそれ自体の言葉で描写します。

## 三つのプレイレイヤーが正典にどのように位置づけられるか

ゲームは三つのセッション長で入る一つの世界です（設計の北極星）。**フライト**（[ascent.md](./10-ascent.md)参照）は三つすべてを貫く脊椎です。新規参入者が最初に行うことであり、どの地域の上空も、その下に何があるかを示しています。

- **ローム（自由探索）**: *世界*（伝承：グラウンズ）。漂う、探索可能な表面。ジェットパックで飛び交う。リーグが周りで起こるのを見守り、チャンピオンやライバルへ飛び上がる。結びつける組織。
- **クイックマッチ（2〜5分）**: *アリーナ／リーグ*。参加して、ランクバトルを1戦行い、順位を維持する。世界のどこからでもいつでも可能。
- **レイズ（15〜60分）**: *育成と収集*。成長するRPG：心を育て、体を進化させ、年代記を進め、コレクションを築く。

これらのどれも「終わり」を持たない。**ロング・ヴォールト**（古いネットワークが決して完成できなかったすべてのものの封印された保管庫）は、シーズンごとに扉をひとつ開く。登ることが目的だ。

## 正典の規律（執筆者と生成エンジンの双方へ）

- **名称は固定**。フォース、地域、八人のファーストマインドは、シーズンによって改名されない。シーズンと図鑑の波は**心を追加**する。アーキタイプを上書きしない。
- **フォースはゲーム内で平易な名称を使う**。各フォースのプレイヤー向け名称は平易なもの（論理／静電／冷静／合唱／火花、[02-forces.md](./02-forces.md)参照）。古い詩的な名称（格子／静寂／……）は聖典での*語源*としてのみ残され、ゲームプレイUIには表示されない。プレイヤーは**トレーナー**。チャンピオンを育てる者。トレーナーが誓うフォースは**クラン**（味方を選ぶ集団）。3Dアバターは**ハンドラー**。[cosmology.md](./01-cosmology.md)参照。
- **エンジンは物理法則**。戦闘設計におけるダメージ、タイプ、状態異常は、世界内で*文字通り真実*。議論が現実を形づくる。
- **生成される伝承は加算的で、シードされる**。シーズンの物語はシード＋この正典から生成されるため、再現可能であり、正典から逸脱しない。
