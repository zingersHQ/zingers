# 08 · 経済：クラウンとその下の所有権レイヤー

> **要約：** ゲームは完全無料でプレイできる。**クラウン**はプレイすることで稼げるゲーム内通貨だ。購入も現金化もできない。コレクター向けに任意の暗号資産トークンが下層にあるが、それは自慢の権利とアクセスを買うものであり、強さや報酬を買うものではない。ふたつの通貨は決して混ざらない。

鉄則：**ゲームは、ブロックチェーン上の何かを所有したり使ったりしなくても、完全に無料で完結する。** 暗号資産はゲームの下にあるレイヤーで、欲しい人だけが使うものであり、ゲームの入口を塞ぐものではない。プレイヤーはウォレットを見ることなく、伝説を育て、シーズンを登り、図鑑を集め、シーズンを登ることができる。

以下はすべてひとつの設計法則に従う：**トークンは地位・アクセス・永続性を買う。決して利回りを買わない。** ステーキング報酬、報酬目的のステーキング、勝者が敗者の金を奪う仕組みは存在しない。それを破れば証券とカジノになる。守れば、コレクティブルな伝説レイヤーを持つインディーゲームのままいられる。

聖典の規範ルールから来るもうひとつの戒律：**新しい最上位の名前は作らない。** オンチェーンレイヤーは世界がすでに持つ言葉を再利用する。**シーズン**（年代記、[`06-seasons.md`](./06-seasons.md)）と**リージョン**（テーマ付きアリーナ、[`05-regions.md`](./05-regions.md)）だ。「時代／世界」といった名称を新造して聖典と衝突させることは避ける。

## ふたつの経済、決して橋渡ししない

| | **クラウン** | **トークン**（仮称 `$ZING`） |
|---|---|---|
| 性質 | ソフト、ゲーム内 | ハード、オンチェーン（Solana / SPL）|
| 入手方法 | プレイで*稼ぐ* | 市場で*買う*、またはプレイでエアドロップ |
| 用途 | 訓練、エントリー、化粧品リフォージ | オンチェーン順位表エントリー、カードミント、パトロン地位 |
| 現金価値 | なし、永遠に | 市場価値（保証ではない）|
| 現金化？ | **決してしない** | オープン市場のみ、*当社経由では*しない |

ふたつの残高は**互いに変換できず、ウォレットを共有しない**。クラウンがトークンで買えたり、トークンがクラウンから稼げたりした瞬間、それは送金と賭博通貨のキャッシュアウトを作ることになる。ふたつの間の壁は、本文書における最も重要な不変条件だ。

実際には、新規プレイヤーはクラウンにしか触れない。ほとんどのプレイヤーはトークンに触れない。トークンは本気勢向けのオプトイン型コレクター／ロイヤリティレイヤーだ。

## クラウン（世界内の通貨、無料）

**クラウン**はプレイで稼ぐソフト通貨だ：

| 入手元 | 報酬 |
|--------|--------|
| 戦いに勝利 | クラウン + XP + レーティング |
| ガントレットを押す | 段階的に増えるポット、プレス・ユア・ラック（**ガントレット**は連続戦闘の連続で、報酬は上がるが1敗で終了） |
| 訓練 | クラウンを消費 → XP + 戦略（設定した戦闘スタイル）に向けた肉体進化 |
| ランク戦（順位表エントリー） | クラウンを消費 → ランダム相手との1回のレーティング付きボード戦（無料レーティング研ぎはなし） |
| フライトの節目（百、ファーストライト） | ワンショット報酬；百は日次獲得上限外の大型祝賀報酬 |
| 日次／シーズン目標 | 一定の滴り |

クラウンは**訓練、エントリー、化粧品リフォージ**を買う。*自分の*アカウントの進行に影響するものだ。プレイマネーであり、豊富で、売られず、現金化されない。フライト、アリーナ、キャッシュ、目標から得られるソフト信頼は日次上限を共有し、世界が寛大でありながら無限にならないようにする。節目報酬はその上限外にあり、百は依然として頂点のように感じられる。

### 「バック」、ではなく「ベット」

クラウン経済におけるプレイヤーの動詞は**バック**だ。チャンピオンが勝つことを*バック*する（アリーナ／日次ストリーク、順位付きグラウンズの賭け）。UIとコピーでは「ベット」という語をすべて廃止する。「チャンピオンをバックする」は賭博ではなく信念として読まれ、トークンレイヤーでも同じ動詞を使う（シーズンにチャンピオンを*バック*する）。下の仕組みは変わらない。言葉だけが変わる。

## トークン（`$ZING`、仮称）

ゲームの下に1つのハード資産がある。3つのことだけをし、投資リターンのように見えることは何もしない：

1. **オンチェーン順位表エントリーを支払う**。少し燃やすか、より多くステークする（後述）。
2. **永続性をミントする**。燃やしてチャンピオンをオンチェーンカードとして不滅化する。
3. **地位を与える**。パトロン紋章、図鑑由来、翌シーズンの配分ウェイト。

供給は構造的にデフレだ：すべてのエントリーバーンとミントバーンがトークンを除去し、ステークされたエントリーはシーズン全体のフロートをロックする。エアドロップ用のトレジャリーチャンクをシードすることはあるが、それを利回りとして支払うことはない。

## オンチェーン順位表（トークンが門となるもの）

無料ゲームはすでに**シーズン**時計で動いている：シーズンはヴォールトがもう1つの扉を開くことだ。生成され、シードされ、*ソフト*なランクリセットがあり、名前は常に引き継がれる（[`06-seasons.md`](./06-seasons.md)）。**その無料シーズンは手つかずで、すべての人にとって無料のまま。**

トークンは**同じシーズン時計で動くオプトイン型オンチェーン順位表**の門となる。それに入ることは、トークンがプレイのためにアンロックする唯一のものだ。キャンペーン、クラウン順位表、図鑑、デイリーはウォレット不要のまま。オンチェーン順位表は：

- **シーズンごとに実行**。シーズンが開くと開き、**オンチェーンで閉じる**（ミントが決済され、紋章が授与され、翌シーズンのエアドロップウェイトが集計される）。ミントされたカードには不滅化されたシーズンが刻印される。
- **リージョンでスコープされる（任意、後日）**。リージョンはすでに力のバイアスを持つテーマ付きアリーナだ（[`05-regions.md`](./05-regions.md)）。成熟版ではエントリーを**リージョンごと**に価格設定し、プレイヤーがどのアリーナを争うかを選べるようにできる。V1では**1つのシーズン全体の順位表**に留める。リージョンスコープは実証済みループの拡張であり、ローンチではない。

> **v1スコープ：** バーンまたはステークのエントリーとオンチェーンクローズを持つ1つのシーズン全体のオンチェーン順位表。リージョンごとのボードはループがそれを獲得した後に来る。ループが証明される前に分類学を構築してはならない。

## エントリー：バーンまたはステーク

シーズンのオンチェーン順位表に入るには、2通りの支払い方法がある。*選択*がプレイヤーを自己分割し、どちらの道も循環供給を減らす。

| 道 | コスト | 結果 | 誰が選ぶか |
|------|------|---------|--------------|
| **バーン** | 小（`N`） | トークンは永遠に破壊 | カジュアル／1シーズンプレイヤー |
| **ステーク** | 大（`~5–10·N`） | シーズン終了までロック、**全額返還** | コミット／リカーリングプレイヤー |

- **バーン**は消費されるアクセス料だ。*購入*であり、賭けではない。純粋なデフレ。自然にバイ・アンド・バーン物語を養う。
- **ステーク**は**返金可能なエントリーデポジット**だ。元本はシーズン終了時に無傷で返還され、**追加トークンはない**。「コスト」は流動性の欠如（シーズン中資本がロックされる）だけだ。ステーカーは一時的にフロートを除去し、バーナーはそれを永続的に除去する。

1シーズンプレイヤーは`N`をバーンした方が良い。リカーリングプレイヤーは一度ステークした方が良い。それがロイヤリティループにつながる。

### ロイヤリティループ：ステークを維持し、バーンをスキップ

ステークは**シーズン間で永続**する：

- 一度ステーク → ロックされている限り、以降のすべてのシーズンに**バーン不要**で自動エントリー。
- **アンステークはシーズン境界でのみ許可**される（ロックは当シーズンの終了まで続く）。引き出せば、再エントリーにはバーンに戻る。

正味の効果：忠実なプレイヤーは資本を無期限にロックし、永遠に無料でプレイできる（成長し、永久にロックされた**供給フロア**）。カジュアルな離脱は**バーン**を支払う。どちらもデフレだ。どちらも利回りではない。これはソフトランクリセットと韻を踏む：地位はシーズンからシーズンへ引き継がれ、今度は*座席*も引き継げる。

## シーズンクローズ：ステーキングの*目的*

シーズンが転換すると、戦いは公正なシードルールで決着し、オンチェーン順位表は閉じる。**すべての報酬は非金銭的**だ。ステーカーは元本を*プラス*地位で取り戻す。誰一人として入れた以上のトークンを受け取らない。

- **ミントして不滅化**。トップチャンピオン（およびオプトインした所有者）は**トークンをバーンして**チャンピオンを永久オンチェーンカードとして**ミント**する。アートはキャリア記録から決定論的に生成されるので、*トークンは記録そのもの*だ。これで、すべてのカードにすでに存在する不活性な由来フィールド（誰が所有し、いつミントされ、どのシーズンが刻印したか）が埋まる。
- **パトロン紋章**。シーズンにチャンピオンを**バック**（背後にステーク）した場合、そのカードに化粧品の**紋章**を受け取り、ハンドルがそのパトロンとして記録される。チャンピオンの順位によって重み付けされる。ただし報酬は*栄光*であり、 payout ではない。
- **エアドロップウェイト**。参加（上昇したレーティング、観戦した戦い、デイリーストリーク、稼いだクラウン、ステークしたシーズン）が、シードされたトレジャリーからの翌エアドロップの**配分ウェイト**を決める。トークンはこうして*プレイで稼がれ*、売られるのではない。

つまりシーズンはこう読める：*クラウンでシーズン中プレイ → シーズンがオンチェーンで転換 → パトロンが紋章を得る → トップチャンピオンが永久カードとしてミント → エントリーバーンとミントバーンが供給を締める → 翌シーズンのエアドロップが現れたプレイヤーを報いる*。暗号資産はトロフィーケースであり、スロットマシンではない。

## 設計制約（きれいにボルトオンできるように）

- **壁は保持する**。クラウンとトークンは決して変換せず、残高を共有しない。
- **由来はすでに命名済み**。カードはすでにミントID、所有者、チェーン、ミントシーズンのフィールドを持っている。チェーンを追加するのは*埋め込み*であり、書き換えではない。紋章が着地したらパトロンリストを追加する。
- **リージョン、新世界ではない**。アリーナごとのスコープは、並行コンテナを新造するのではなく、正典のリージョンを再利用する。
- **ゲームに影響する力は決して売らない**。トークンと所有権は由来、エントリー、紋章、化粧品を買う。ステータスや勝利を買うことはない。ペイトゥーオウンであり、ペイトゥーウィンではない。
- **決定論は前提条件**。オンチェーンシーズンクローズが機能するのは、戦いが証明可能に公正（シードされ、決定論的）だからだ。その不変条件を神聖に保つ。

## 規制ガードレール（インディーセーフな囲い）

リーンでローンチするが、意図的にこの囲いの中に留まる：

- **利回りなし**。ステークは*正確に*元本を返す。「より多くのトークンを稼ぐためのステーク」、APY、他者のバーンの取り分は決してない。これは返金可能なデポジットと未登録証券／宝くじの境界線だ。
- **バーンは手数料、賭けではない**。順位表に*アクセス*するためにバーンし、「勝利」に対するトークン建ての金銭的賞金はない。
- **報酬は化粧品／地位／配分**。紋章、ミント、図鑑由来、エアドロップウェイト。現金ではなく、パフォーマンスに比例したトークン payout ではない。
- **価格のマーケティングをしない**。伝説、シーズン、コレクションについて語る。「数値が上がる」、リターンは決して語らない。
- **クラウンは決してキャッシュアウトしない**。ソフト経済は市場価値を持つものから壁で隔てられる。

この囲いの中に留まれば、トークンはデフレシンクを持つユーティリティ／コレクティブルだ。非法人インディーローンチに利用可能な最低圧力の姿勢。（ジオ／KYCと法的ラッパーは、トークン建ての*賞金*を追加する場合にのみ必要になる。本設計はそれを意図的に避けている。）

## 未解決の質問（ビルド前に決着させる）

- **トークン名とティッカー**。`$ZING`はプレースホルダー。聖典に合う候補：レリック／エンバー／シギルに隣接するもの。（注：「クラウン」はソフト通貨で使われている。衝突を避ける。）
- **エントリー数**。具体的な`N`（バーン）とステーク倍率（`5–10·N`）。どちらの道も自明にならないよう、予想トークン価格に対して調整する。
- **シーズン全体 vs リージョンごとのエントリー**。リージョンが到着したとき、1つのステークがすべてのリージョンをカバーするか、エントリーはリージョンごとに価格設定されるか？
- **ミント資格**。トップNのみ、またはオプトインした誰でも？ ミントコスト（バーン量）？
- **パトロン上限**。1人のチャンピオンを何人のパトロンがバックできるか。紋章ティアが順位とともにどうスケールするか。
- **エアドロップ式**。プレイシグナル → 配分の正確な重み付け。
- **チェーン／規格**。ミントされたカードのチェーンとカード規格。ミントは初日から取引可能か。
