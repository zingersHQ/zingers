# 08 · エコノミー：クラウンとその下の所有権レイヤー

> **要約：** ゲームは完全無料でプレイ可能。**クラウン**はプレイすることで得られるゲーム内通貨で、購入や現金化は一切できない。コレクター向けに任意の暗号資産トークンが下層に存在するが、これは自慢権とアクセス権のみを提供し、ゲーム内パワーや配当は一切ない。2つの通貨は決して混ざらない。

鉄則：**ゲームはオンチェーンでの支出や所有なしで完全に無料かつ完結する。** 暗号資産はゲームの「下層」で、欲しい人だけが使うものであり、ゲームの入り口を塞ぐものではない。プレイヤーはウォレットを見ることなく、レジェンドを育て、シーズンを登り、デックスを集め、Vaultを攻略できる。

以下のすべては一つの設計法則に従う：**トークンは地位・アクセス・永続性を買う。決して利回りを生まない。** ステーキングAPY、「ステークして稼ぐ」、勝者が敗者の資金を奪う仕組みは一切ない。この法則を破れば証券・カジノ化し、守ればインディーゲーム＋コレクティブルジェンドレイヤーとして成立する。

第二の規律（用語聖典より）：**新語を最上位に作らない。** オンチェーン層は世界が既に持つ語を再利用する。**シーズン**（年代記、[`06-seasons.md`](./06-seasons.md)）と**リージョン**（テーマ付きアリーナ、[`05-regions.md`](./05-regions.md)）。正典と衝突する「Era/World」などの造語は避ける。

## 2つの経済、決して橋渡ししない

| | **クラウン** | **トークン**（仮称 `$ZING`） |
|---|---|---|
| 性質 | ソフト、ゲーム内 | ハード、オンチェーン（Solana / SPL） |
| 入手方法 | プレイで*獲得* | 市場で*購入*、またはプレイ報酬でエアドロップ |
| 用途 | トレーニング、エントリー、コスメティック再鍛 | オンチェーン順位表エントリー、カードミント、パトロン地位 |
| 現金価値 | 一切なし | 市場価値（当社保証なし） |
| 現金化？ | **絶対にしない** | オープン市場のみ、当社経由は一切なし |

2つの残高は**互いに変換できず、ウォレットも共有しない。** クラウンがトークンで買えたり、トークンがクラウンから得られたりした瞬間、送金サービスと賭博通貨のキャッシュアウトを作ったことになる。この壁は本ドキュメントで最も重要な不変条件である。

実務上：新規プレイヤーはクラウンしか触れない。大半のプレイヤーはトークンに触れない。トークンは本気勢向けのオプトイン・コレクター／ロイヤリティ層である。

## クラウン（世界内通貨、無料）

**クラウン**はプレイで稼ぐソフト通貨：

| 入手元 | 報酬 |
|--------|--------|
| 戦いに勝利 | クラウン + XP + レーティング |
| ガントレットを押す | 段階的上昇ポット、プレス・ユア・ラック（**ガントレット**は連続戦闘で報酬が上がるが1敗で終了） |
| トレーニング | クラウンを消費 → XP + 戦略（設定した戦闘スタイル）に向けた肉体進化 |
| ランク戦（エントリー） | クラウンを消費 → ボード上のレーティング戦1回（`RANK_FIGHT_COST`；無料のレーティング稼ぎは不可） |
| デイリー／シーズン目標 | 一定の滴り |

クラウンは**トレーニング、エントリー、コスメティック再鍛**に使う。アカウント進行に影響するもの。プレイマネー：豊富で、販売も現金化もされない。（正典値は `lib/economy.ts` にあり、サーバーが残高を所有、クライアントがミラーリング。`/standings` のランク戦は**エントリー**消費。）

### 「バック」、非「ベット」

クラウン経済内のプレイヤー動詞は **back**。チャンピオンを勝利に*back*する（Arena/Daily 連勝、ランク Grounds ワガー）。UI・コピーから「bet」という語を全廃。「Back your champion」は賭博ではなく信念として読める。トークン層でも同じ動詞を使う（シーズンにチャンピオンを*back*）。仕組みは変わらず、言語だけが変わる。

## トークン（`$ZING`、仮称）

ゲームの下に1つのハード資産が存在する。3つのことだけを行い、投資リターンのようなものは一切行わない：

1. **オンチェーン順位表エントリーを支払う**。少量をバーンするか、より多くをステーク（後述）。
2. **永続性をミント**。バーンしてチャンピオンをオンチェーンカードとして不滅化。
3. **地位を与える**。パトロン紋章、デックス来歴、次シーズン配分ウェイト。

供給は構造的にデフレ：エントリーバーンとミントバーンがトークンを除去し、ステークエントリーはシーズン全体フロートをロックする。エアドロップ用にトレジャリーチャンクをシードする可能性はあるが、利回りとして配ることはない。

---

## オンチェーン順位表（トークンが門戸となるもの）

無料ゲームは既に**シーズン**時計で動いている：シーズンはVaultがもう1つの扉を開く。生成され、シードされ、*ソフト*なランクリセットにより常に名前を持ち越す（[`06-seasons.md`](./06-seasons.md)）。**その無料シーズンは一切触れず、全員に無料のまま残る。**

トークンは**同じシーズン時計で動くオプトイン・オンチェーン順位表**の門戸となる。プレイのためにトークンがアンロックするのはこれだけ。キャンペーン、クラウン順位表、デックス、Dailyはウォレット不要のまま。オンチェーン順位表：

- **シーズンごとに実行**。シーズン開始時に開き、**オンチェーンで閉じる**（ミント決済、紋章授与、次シーズンエアドロップウェイト集計）。`mintedSeason` 来歴を再利用し、ミントカードには不滅化したシーズンが刻印される。
- **リージョンでスコープ可能（任意、後日）**。リージョンは既に力バイアス付きテーマアリーナ（[`05-regions.md`](./05-regions.md)）で、`/api/battle` で `regionBias` として接続。成熟版では**リージョンごと**にエントリー価格を設定し、プレイヤーが争うアリーナを選べる。V1は**1つのシーズン全体順位表**に留め、リージョンスコープはループが証明された後の拡張とする。

> **v1 スコープ：** バーンまたはステークによるエントリーとオンチェーンクローズを備えた1つのシーズン全体オンチェーン順位表。リージョン別ラダーはループが証明されてから。ループが証明される前に分類体系を作らない。

## エントリー：バーンまたはステーク

シーズンのオンチェーン順位表に入るには、2通りの支払い方法がある。*選択*によりプレイヤーが自己セグメントされ、どちらの道も循環供給を減らす。

| 道 | コスト | 結果 | 選ぶ人 |
|------|------|---------|--------------|
| **バーン** | 小（`N`） | トークンが永久破壊 | カジュアル／1シーズンプレイヤー |
| **ステーク** | 大（`~5–10·N`） | シーズン終了までロック、**全額返還** | コミット／リカーリングプレイヤー |

- **バーン**は消費型アクセス料。*購入*であってワガーではない。純粋なデフレ。自然に「買ってバーン」ナラティブを養う。
- **ステーク**は**返還可能なエントリーデポジット**。シーズン終了時に元本が無傷で返還され、**追加トークンは一切ない**。唯一の「コスト」は非流動性（シーズン間資本ロック）。ステーカーは一時的にフロートを除去、バーナーは永久に除去。

1シーズンプレイヤーは `N` をバーンした方が良い。リカーリングプレイヤーは一度ステークした方が良い。これがロイヤリティループにつながる。

### ロイヤリティループ：ステークを維持し、バーンをスキップ

ステークは**シーズン間で永続**：

- 一度ステーク → ロックを維持する限り、以後の全シーズンに**バーン不要**で自動エントリー。
- **アンステークはシーズン境界でのみ許可**（ロックは当該シーズン終了まで）。引き出せば再エントリーにバーンが必要になる。

結果：忠実プレイヤーは資本を無期限ロックし、永遠に無料でプレイ（成長し続ける**永久ロック供給フロア**）。カジュアル離脱は**バーン**を支払う。どちらもデフレ。どちらも利回りではない。これはソフトランクリセットと韻を踏む：シーズンごとに地位を維持し、今度は*座席*も維持できる。

## シーズン終了：ステーキングの*目的*

シーズンが回る（決定論的。戦いはシードRNGで証明可能に公平、`lib/engine/xai.ts:makeRng`）と、オンチェーン順位表が決済される。**報酬はすべて非金銭的。** ステーカーは元本＋地位を返還され、投入した以上のトークンは誰も得ない。

- **ミントして不滅化**。トップチャンピオン（およびオプトイン所有者）は**トークンをバーンして**チャンピオンを永久オンチェーンカードとしてミント。芸術はキャリア記録から決定論的であり、*トークンが記録そのもの*。これで既に存在する未使用来歴フィールドを埋める。`CardProvenance`（`lib/cards/card.ts`）の `mintId`、`owner`、`chain`、`mintedSeason`。スキーマ変更なし。
- **パトロン紋章**。シーズンにチャンピオンを**backed**（ステーク）した場合、そのカードにコスメティック**紋章**が付き、ハンドル／ウォレットがカードの来歴／パトロン一覧に記録される。チャンピオンの順位で重み付け。ただし報酬は*栄光*であって配当ではない。
- **エアドロップウェイト**。参加（レーティング上昇、観戦、Daily連勝、獲得クラウン、ステークシーズン数）が次回トレジャリーエアドロップの**配分ウェイト**を決定。トークンはプレイで*獲得*され、販売されるものではない。

したがってシーズンはこう読める：*クラウンでシーズン中プレイ → シーズンがオンチェーンで回る → パトロンが紋章獲得 → トップチャンピオンが永久カードとしてミント → エントリーバーンとミントバーンで供給が逼迫 → 次シーズンエアドロップが参加者を報いる*。暗号資産はトロフィーケースであってスロットマシンではない。

## 設計制約（クリーンに接続するため）

- **壁は保持**。クラウンとトークンは変換せず、残高も共有しない（`lib/economy.ts` はトークンフリーのまま、トークンは独自モジュール／コントラクトに存在）。
- **来歴は既に配線済み**。`CardProvenance` は初日から不活性 `mintId`、`owner`、`chain`、`mintedSeason` を保持。チェーンの追加は*埋め込み*であってリファクタリングではない。紋章実装時にパトロン一覧フィールドを追加。
- **リージョン、新世界ではない**。アリーナ別スコープは `regionBias` と正典リージョンを再利用し、並列コンテナを新造しない。
- **ゲームに影響するパワーは一切販売しない**。トークンと所有権は来歴、エントリー、紋章、コスメティックを買う。ステータスも勝利も買えない。Pay-to-own であって Pay-to-win ではない。
- **決定論が前提条件**。オンチェーンシーズン終了は、戦いが証明可能に公平（シード決定論的RNG）であるから機能する。この不変条件を神聖に保つ。

## 規制ガードレール（インディーセーフの枠）

リーンに立ち上げるが、意図的にこの枠内に留まる：

- **利回りなし**。ステークは*元本のみ*返還。「ステークしてトークンを増やす」「APY」「他者のバーン分配」は一切ない。これは返還可能デポジットと未登録証券／宝くじの境界線。
- **バーンは手数料であってワガーではない**。順位表に*アクセス*するためにバーンし、「勝利」に対するトークン建て賞金は一切ない。
- **報酬はコスメティック／地位／配分**。紋章、ミント、デックス来歴、エアドロップウェイト。現金やパフォーマンス比例トークン配当ではない。
- **価格のマーケティングをしない**。レジェンド、シーズン、コレクションについて語る。「数値が上がる」「リターン」については一切語らない。
- **クラウンは一切現金化しない**。ソフト経済は市場価値を持つものと壁で隔てる。

この枠内に留まれば、トークンはデフレシンクを持つユーティリティ／コレクティブルとなる。非法人インディー立ち上げに可能な最低圧力姿勢。（Geo/KYC と法的ラッパーはトークン建て*賞金*を追加する場合のみ必要。本設計は意図的に避けている。）

## 未解決事項（ビルド前に決定）

- **トークン名とティッカー**。`$ZING` はプレースホルダー。ロアに合う候補：relic/ember/sigil 関連。（注：「Crowns」はソフト通貨で使用済み。衝突を避ける。）
- **エントリー数値**。具体的な `N`（バーン）とステーク倍率（`5–10·N`）。想定トークン価格に対して調整し、どちらの道も「当然の選択」にならないように。
- **シーズン全体 vs リージョン別エントリー**。リージョン導入時、1つのステークで全リージョンをカバーするか、リージョンごとに価格を設定するか。
- **ミント資格**。Top-N のみ、またはオプトイン者全員？ミントコスト（バーン量）？
- **パトロン上限**。1チャンピオンに何人のパトロンがバック可能か、紋章ティアが順位でどうスケールするか。
- **エアドロップ式**。プレイシグナル → 配分の正確な重み付け。
- **チェーン／規格**。SPLトークン＋ミントカード用NFT規格（例：Metaplex）、ミントが初日から取引可能かどうか。
