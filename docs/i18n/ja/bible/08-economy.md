# 08 · 経済：クラウンと、その下の所有レイヤー

> **一言で：** ゲームは無料。**クラウン**はプレイで稼ぐお金。買えないし現金化できない。
> 下にある任意トークンで、コレクターはチャンピオンを**バーンして不滅化**し、チェーン上の
> カードにできる。トークンは戦力を買わず、利回りも払わない。二つの通貨は決して混ざらない。

第一規則：**チェーン上の支出や所有がなくても、ゲームは完全に遊べる。** 暗号資産は
ゲームの下のトロフィーケースであり、正面の門ではない。ウォレットを一度も見ずに育て、
登り、集め、戦える。

設計法：**トークンが買うのは永続（と軽い地位）だけ。利回りは決して買わない。**
APY なし、「stake to earn」なし、ポットなし、生きているチャンピオンのクラウンを
カード保有者に分ける手数料なし。

---

## 二つの経済、橋はかけない

| | **クラウン** | **トークン**（仮称 `$ZING`） |
|---|---|---|
| 性質 | ソフト、ゲーム内 | ハード、オンチェーン（Solana） |
| 入手 | プレイで*稼ぐ* | 市場で*買う*、またはプレイ空投 |
| 用途 | 訓練、入場、支持、見た目の再鍛造 | バーンしてチャンピオンカードを不滅化 |
| 現金価値 | 永遠になし | 市場価値（約束ではない） |
| 現金化？ | **決してしない** | 公開市場のみ。*我々経由*では決してしない |

二つの残高は**決して換算しない**。壁が最重要の不変条件。

実務上、新規プレイヤーはクラウンだけに触れる。トークンは、伝説に永遠の刻印を押したい
トレーナー向けの任意コレクター層。

---

## クラウン（世界内通貨、無料）

**クラウン**はプレイで稼ぐ：

| 源 | 報酬 |
|----|------|
| 戦いに勝つ | クラウン + XP + 順位 |
| ガントレット | 増えるポット、運試し |
| 訓練 | クラウン消費 → XP + 戦略に沿った身体進化 |
| ランク戦 | クラウン消費 → ランダム相手との採点戦 |
| フライト里程（百、初光） | 一度きりの財布。百は日次上限の外 |
| 日次 / シーズン目標 | 安定した滴り |

クラウンは**訓練・入場・見た目**を買う。プレイマネー。豊富で、売らず、現金化しない。
クラフト盤の順位は誇りであり、クラウンの財布ではない。

### 「支持」であり「賭け」ではない

クラウン経済の動詞は**支持**。チャンピオンを支持して勝つ。プレイヤー向けコピーから
「賭け」を退ける。信念であり、賭博ではない。

---

## トークン（`$ZING`、仮称）

硬い仕事は一つ。言いやすい：

**トークンをバーン → チャンピオンをオンチェーンカードとして不滅化。**

それがユーティリティ。カード周りの地位は軽い栄光だけ。

### 不滅化

- 生きたキャリアを持ち、刻印を選ぶ。
- レア度と版クラスごとの**固定量**をバーン（シーズン間で調整）。価格オラクルなし。
  ボンディングカーブなし。
- チェーンがカードをミント。アートは刻印瞬間のキャリアの**凍結スナップショット**。
  グラウンズでは身体が育ち続けても、カード自体は勝手に変形しない。
- **希少性はロースターに紐づく。** 初年度、各心は最大 **8** 回まで不滅化できる。生きたキャリアにつき1刻印。新しい心にはそれぞれ8枠。現状ロースターなら初年度およそ1056。Genesis の早期刻印は OG 印。
- 来歴は保有者・刻印時刻・シーズンを記す。カードは取引可能。二次ロイヤリティはハウスと初回ミンターで分け得る。生きたチャンピオンのクラウンへの手数料ではない。

生きたチャンピオンはプレイ用にトレーナーのもの。稼いだクラウンもそのトレーナーのもの。
カードはトロフィーであり、将来のソフト収益への請求権ではない。

### 地位（軽い）

不滅化カードはシーズン紋章、ギャラリー位置、名を残せる。刻印の保有や獲得は
次シーズン空投の重みになり得る。**栄光と配分ウェイト。継続配当は決してない。
チャンピオンが生むクラウンへの手数料も決してない。**

公開市場でのカード取引は、後にハウスへの小さなロイヤリティを伴い得る。それは
コレクティブル取引であり、戦いの給料ではない。

### トークンが決してしないこと

- 勝利・ステータス・盤入場の購入
- 利回り、APY、成果報酬の支払い
- クラウンとの換算
- フライト、育成、無料シーズンの封鎖

人々が不滅化するほど供給は締まる。バーンがトークンを減らす。空投用トレジャリーは
可。利回りとして払わない。

---

## シーズンと無料ゲーム

無料ゲームはすでに**シーズン**時計で動く。ヴォールトがまた扉を開き、順位はソフトに
リセットされ、名前は持ち越す（[`06-seasons.md`](./06-seasons.md)）。
**その無料シーズンは全員に無料のまま。**

シーズンは不滅化に暦を与える。版印、紋章の言葉、章の終わりのミント波。暗号資産は
その章のトロフィーケース。スロットマシンではない。

---

## 設計制約

- **壁は保つ。** クラウンとトークンは換算しない。
- **来歴の名は既にある。** mint id、owner、chain、season はカード上。チェーンは埋めるだけ。
- **勝敗に効く力は売らない。** 永続と軽い地位のみ。
- **スタジオの心だけ。** コレクターはハウスが書いた伝説を刻む。
- **意図的に薄い。** 硬い sink は一つ。余分な「ユーティリティ」は拒否。

---

## ガードレール

- **利回りなし。** stake-to-earn なし。バーンやチャンピオンのクラウンを保有者に分けない。
- **バーンは刻印の手数料**であり、賞品への賭けではない。
- **報酬は見た目・地位・配分ウェイト。**
- **価格の宣伝をしない。**
- **クラウンは現金化しない。**

## 確定 / 未定

**確定：** バーン不滅化。スナップショット芸術。初年度 = **心ごと8**（現状約1056。図鑑で増える）。
Genesis OG。オーナーのみ。取引可。段階固定バーン。オラクル／カーブなし。Solana。

**未定（つまみであり形ではない）：** ティッカー。バーン表。ロイヤリティ。
Genesis 後は常時か窓か。2年目の心ごと上限。
