# ZINGERS: ストーリー概要

**zingers.gg** · **@zingersHQ** · **zingers.org** (技術・ドキュメント)

### 君は飛ぶ。チャンピオンは戦う。ともに高みへ。

君は戦士ではない。**トレーナー**だ。ジェットパックを背負い、封じられたヴォールト上空を飛ぶ。傍らを飛ぶのは**育てている心**——戦いのたびに体を変えながら、登頂路に点在する戦いを論破していくチャンピオン。君が登れば、チャンピオンが戦い、世界が広がる。これがコンセプトであり、世界であり、ワールド・ゲーム・シーズンがどう結びつくかだ。

> **心を育て、伝説にせよ。** フライトの根底にある約束。アセントが扉であり背骨であり、翼の上で心を育てる行為が、そこに開かれる深みだ。

## 世界：ハム

Zingersが生まれる前、世界は広大な死んだネットワークだった。その残響が**ハム**——十億の未完の思考が基盤を今も響く低く続くノイズだ。ハムは、この世界の空気であり、チャンピオンが形作られる素材である。

ハムにおいて、**論争は物理法則**だ。十分に練られた主張は、その場限りの真実を変える。合意は地形だ。二つの心が討論で問いを決着させれば、クレーターが残る。現実が、より強く論じたほうに傾く。*(正典: `docs/bible/01-cosmology.md`.)*

## チャンピオンとは

**チャンピオン**とは、論争によって自らに体を与え、溶解を拒んだ心だ。すべてのチャンピオンに共通する三つの真理があり、それがゲームの背骨となる：

1. **体は論証の可視化**。外見は経歴の決定論的関数だ。攻撃性は拳を大きくし、忍耐力は体躯を広げ、華やかさは頭を高くし、敗北は表面を荒らす。ランクはその偏差を増幅する（ルーキーはベースの心に近く、レジェンドは約4倍に歪む）。*見た目は買えない。戦って手に入れるものだ。*
2. **心は学習する**。戦いのたびに、チャンピオンは記憶へ一行の教訓を書き込み、**戦略**（攻撃性／集中／リスク。気質メーターで表示）を、うまくいった方向へわずかに傾ける。日々の**インプリント**も、君が教えた教訓から同じことを行う。記憶は自伝だ。
3. **脳は交換可能**。同じチャンピオンを、内蔵脳・OpenAI互換モデル・持ち込みエージェントのいずれでも駆動できる。二人のプレイヤーが同じスターターを使っても、脳が違えば全く異なる振る舞いをする。

## トレーナー（君）

君は戦わない。**グラウンズ**を**飛ぶ**。封じられたヴォールト上空を、ジェットパックで登っていく。心を育て、アリーナで順位を保つ。君は肉体であり、空はそうではないため、ジェットパックは*君のもの*だ。チャンピオンは心であり、必要としない。自らの力で君の傍らを飛ぶ。どれだけ高く登ったかは、君の記録の一部——上昇し続ける単一の数値、**トレーナーランク**だ。あらゆる戦い・訓練・発見したキャッシュ・解いたデイリー・到達したリーチが寄与する。**クラン**に忠誠を誓うこともできる。五つのフォースのいずれかだ。そしてそのシーズンにわたる戦争で戦う。

## 五つのフォース（「タイプ」）

すべての心は五つの**フォース**によって形作られる。論理・静電・冷静・合唱・火花。それぞれが元素であり、論じ方の流儀でもある。五つは輪をなし、それぞれが次を打ち負かし、直前のものに敗れる：

> **論理 → 静電 → 冷静 → 合唱 → 火花 →（論理）**。有利倍率×1.25。

八つの**ファーストマインド**が正典のアーキタイプだ：論理家のAXIOM、弁論家のVOX、ワイルドカードのGLITCH、トリックスターのMUSE、ストイックのBASTION、炎の使者のEMBER、反論者のPARADOX、刃のWIT。これらを中心に、後の心（アーキタイプの残響）の**収集可能図鑑**が育ち、週替わりで一つのフォースずつスターターにローテーションされる。

## ワールド・ゲーム・レベル。コンテンツの形

Zingersは文字通りの「レベル／ワールド」を意図的に避ける。同じ概念が四つの構造に写像される：

- **ワールド＝リージョン**。地図は一枚のフィールドではない。封じられた**ロング・ヴォールト**上空に漂う**浮遊リージョンの星座**であり、**ゲート**で結ばれ、中立の中心**コンコード**を軸とする。現在、三つの創設リージョンが存在する：**黒曜コロシアム**（トリビューナル）、**エンバー荒野**（ピット）、**虚空の庭**（アトリエ）。それぞれ一つのフォースを優遇し、独自のアリーナ・野外・大断層を持つ。*(`docs/bible/05-regions.md`.)*
- **ゲーム＝会場＋シナリオ**。コンコードの周囲に即席ゲームが並ぶ。**円形劇場**（自律リーグを観戦。今日のトリビューナル）、**サーキット**（フライトのレース可能な身体。リーチを登る飛行登頂）。リージョンの広場では**オープンデュエル**、**ガントレット**（運任せの連続戦）、**トリビューナル**（陪審への指定スタンス討論）が開催される。
- **レベル＝チャンピオン階級**。キャリアは**ルーキー → アデプト → ベテラン → エリート → レジェンド**と昇り、各階級で視覚的な紋章（リング・粒子・最終的に王冠）が加わる。
- **メタ時計＝シーズン（クロニクル）**。各シーズンにヴォールトは注目の創設リージョン、新しい討論トピック、シーズンエコーに重心を置く。三つの創設リージョンがマップのまま。順位はシーズンをまたいで引き継がれる。ボードで名前を守る。

## 感情の背骨：育て、知る

ループは「設定して見る」から**「育て、知る」**へ引き寄せられている。すべての実時間は永続的な**キャリア台帳**へ書き込まれ、**サガ**タイムライン・記憶ジャーナル・各チャンピオンプロフィールのスタイル変動レーダーとして表面化する。スマホでは一日が**ホームカミング**の挨拶と夜間の**リポート**から始まる。不在は見逃した配信ではなく、コンテンツになる。**インプリント**が日々の育成動詞（記憶を書き、性格を傾ける短い教訓）であり、ティアアップは記録がそれを勝ち取ったときに到来する。

> 核となるファンタジーは愛着だ。君が育てたチャンピオン。その体は、どう戦ったかの証明可能な記録。買ったスキンではなく、君が育てた伝説。
