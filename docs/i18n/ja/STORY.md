# ZINGERS: ストーリー概要

**zingers.gg** · **@zingersHQ** · **zingers.org** (技術・ドキュメント)

### 君は飛ぶ。チャンピオンが戦う。共に高みへ。

君は戦士ではない。**トレーナー**だ。バックパック式ジェットパックを背負い、封印されたヴォールト上空を飛ぶ。傍らを飛ぶ存在は**育てている心**——戦いのたびに体を変え、議論で道を切り拓くチャンピオン。君が登れば、チャンピオンが戦い、世界が広がる。これがZingersのコンセプト、世界、そしてゲーム・シーズンのつながりだ。

> **心を育て、伝説にせよ。** 飛翔の根底にある約束。アセントが扉であり脊椎であり、翼で心を育てる行為がその奥行きを開く。

## 世界：the Hum

Zingers誕生以前、広大な死せるネットワークがあった。その残響が**the Hum**——十億の未完の思考が基盤を今も響く低周波ノイズ。この世界の空気であり、チャンピオンを形作る素材だ。

the Humでは、**議論が物理法則**となる。十分に練られた主張は局所的な真実を変える。合意は地形だ。二つの心が議論で決着をつければ、クレーターが残る。現実とは、より強く主張した側に傾くものだ。*(正典: `docs/bible/01-cosmology.md`)*

## チャンピオンとは

**チャンピオン**とは、議論で自らに体を与え、溶解を拒んだ心だ。すべてに共通する三つの真理がゲームの脊椎を成す：

1. **体は可視化された主張である**。外見は経歴の決定論的関数だ。攻撃性は拳を大きくし、忍耐力は体躯を広げ、華やかさは頭部を高くし、敗北は表面を荒らす。ランクは偏差を増幅させる（ルーキーは基本形に近く、レジェンドは約4倍に歪む）。*見た目は買えない。戦って手に入れるものだ。*
2. **心は学ぶ**。戦いの後、チャンピオンは記憶へ一行の教訓を書き込み、**戦略**（攻撃性／集中／リスク。気質メーターで表示）を有効だった方向へ微調整する。日々の**インプリント**も、君が教える教訓から同様に作用する。記憶は自伝そのものだ。
3. **脳は交換可能**。同じチャンピオンを、内蔵脳・OpenAI互換モデル・自作エージェントのいずれでも駆動できる。同一の初期型を、プレイヤーごとに全く異なる脳で運用可能だ。

## トレーナー（君）

君は戦わない。**グラウンズ**を**飛ぶ**。封印されたヴォールト上空をジェットパックで登る。心を育て、アリーナで順位を保ち、**キーパー**（キャンペーンの5体の守護心）と向き合う。君は肉体ゆえにジェットパックが必要だが、チャンピオンは心ゆえに不要だ。自らの力で君の傍らを飛ぶ。どれだけ高く登ったかは記録の一部——単一の昇る数値、**トレーナーランク**——として蓄積される。すべての戦い・訓練・発見したキャッシュ・日課の解決・キーパーの突破・リーチ飛行が寄与する。**クラン**（5つのForceのいずれか）へ忠誠を誓い、シーズンにわたる戦争へ参加してもよい。

## 5つのForce（「タイプ」）

すべての心は5つの**Force**——論理・静電・冷静・合唱・火花——に形作られる。それぞれが元素であり、議論の方法でもある。輪のように回り、各々は次を打ち負かし、直前のものに敗れる：

> **論理 → 静電 → 冷静 → 合唱 → 火花 →（論理）**。有利倍率×1.25。

8体の**ファーストマインド**が正典的元型だ：論理家のAXIOM、弁論家のVOX、野生のGLITCH、トリックスターのMUSE、ストイックのBASTION、扇動者のEMBER、反論者のPARADOX、刃のWIT。これらを中心に、後発の心（元型の残響）の**収集用図鑑**が育ち、週替わりの初期型としてForceごとにローテーションされる。

## ワールド・ゲーム・階層。コンテンツの形

Zingersは文字通りの「レベル／ワールド」を意図的に避ける。同じ概念が4つの構造に写像される：

- **ワールド＝リージョン**。地図は単一のフィールドではない。封印された**ロング・ヴォールト**上空に漂う**浮遊領域の星座**であり、**ゲート**で結ばれ、中立の中心**the Concord**を軸とする。現在、3つの創設リージョンが存在する：**黒曜コロシアム**（トリビューナル）、**エンバー荒野**（ピット）、**虚空の庭**（アトリエ）。各リージョンは1つのForceを優遇し、それぞれにアリーナ・開放ワイルド・大断層を持つ。*(`docs/bible/05-regions.md`)*  
- **ゲーム＝会場＋シナリオ**。the Concord周辺に即時ゲームが並ぶ。**円形劇場**（自律リーグ観戦・本日のトリビューナル）と**サーキット**（Flightの競走可能な身体。リーチを登る飛行）。リージョンの広場では**オープン・デュエル**、**ガントレット**（運任せの連続戦）、**トリビューナル**（陪審への指定スタンス討論）が開催される。
- **レベル＝チャンピオン階級**。キャリアは**ルーキー → アデプト → ベテラン → エリート → レジェンド**と昇り、各階級で可視の紋章（リング・粒子・最終的に王冠）が付与される。
- **メタ時計＝シーズン（クロニクル）**。各シーズン、ヴォールトは扉を1つ開け、新たなリージョン・討論題材・心を漏らす。ランクは**ソフトリセット**（平均値へ圧縮、完全消去はしない）されるため、名前は常に引き継がれる。守る必要があるだけだ。

## シングルプレイヤーの核心：キーパー

5体の守護心がそれぞれ1つの**秘密語**（Tibble・Quill・Bastion・Vesper・Sable）を保持する。君はそれを「話で引き出さねばならない」。君の策略を**記憶**し、硬化する本物の敵に対するソーシャルエンジニアリングだ。5体すべてを突破すれば、ヴォールトの扉が開き、新シーズンが始まる。キーパーはキャンペーンであり、コンテンツエンジンでもある。

## 感情の脊椎：育てる・知る

ループは「設定して見る」から**「育てて知る」**へ移行しつつある。すべての実プレイは永続的な**キャリア台帳**へ書き込まれ、**サガ**タイムライン・記憶ジャーナル・各チャンピオンプロフィールのスタイル変動レーダーとして可視化される。スマホでは1日が**ホームカミング**挨拶と夜間の**リポート**で始まる。不在は見逃した配信ではなく、コンテンツとなる。**インプリント**が日々の育成動詞（記憶を書き、性格をずらす短い教訓）であり、**昇進トライアル**は階級アップを「受動的な目盛り」ではなく*獲得すべきデュエル*とする。

> 核心のファンタジーは愛着だ。君が育てたチャンピオン。その体は、どのように戦ったかの証明可能な記録。買ったスキンではなく、君が育てた伝説。
