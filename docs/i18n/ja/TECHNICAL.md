# ZINGERS: 技術概要

**zingers.gg** · **@zingersHQ** · **zingers.org**（技術・ドキュメント）

### LLMが演者。エンジンがゲーム。

単一の型付きNext.jsアプリ。ランタイムは1つで、別途バックエンドを管理する必要はありません。**飛行**できる3D世界を動かし、AI同士のライブ討論バトルをストリーミングし、実際の試合履歴と上達度に応じてチャンピオンを進化させます。

---

## 基本方針

戦闘はターン制で、明示的な技と**ステータス駆動の解決**を採用：ステータス、タイプ、訓練、状態、シード付き乱数でダメージを決定します。機知の質は0.7〜1.3（ハイライト時は1.4）の範囲で乗算されます。デフォルトは**ローカル判定**。`ZINGERS_LLM_JUDGE=1`でLLM判定に切り替え可能です。どちらの経路も単独で勝敗を決められません。これにより公平性、再現性、低コストを両立しています。  
*（`docs/game-spec.md`、`docs/combat-design.md`）*

## 技術スタック

Next.js 16（App Router）・React 19・エンドツーエンド**TypeScript**・**React Three Fiber**（Drei、Rapier物理演算、後処理付き）で3Dグラウンドを表現・**Zustand**状態管理・**Upstash Redis**サーバーミラー・**Server-Sent Events**でライブバトル配信・**xAI（Grok）**を内蔵ブレインとして採用。Vercelにデプロイ（`zingers.gg`がゲームホスト、`zingers.org`がドキュメントホスト）、6時間ごとに`/api/cron`を実行。

## アーキテクチャ。1つの世界、薄いサーバー

- **The Ascentが顔**。モバイルClimb（`/m`）とデスクトップCircuitは同じ100セクターの空（10リーチ）を共有。トレーナーはジェットパックで飛行し、チャンピオンの相棒は翼で追従。ボード、ライフ、セクター開放については`docs/climb.md`、`docs/bible/10-ascent.md`を参照。
- **3Dグラウンド**が深い表面：飛行、育成、目標探索、会場入場。身体はキャリアに応じて`lib/evolve/appearance.ts`の決定論的関数でリアルタイム変形。パフォーマンス対策として指数減衰（フレームレート非依存）、インスタンシングGLTFプロップ、`React.memo`シーン装飾、パレットキャッシュテクスチャ、DPR/品質ティア、`prefers-reduced-motion`で制限される「ジュース」（シェイク、FOVキック、バースト）を実装。モバイルはWebGLキャンバスを**1つ**に限定。
- **バトルはSSEでストリーミング**（`/api/battle`、ヘッドレス`/api/sim`）。各ターンは技、解決ダメージ、キャラクターらしいセリフ、平易な`why`、ツール有効時はエージェントステップの`trace[]`を配信。デフォルトは**ターンあたり1回のLLM決定**＋ローカル判定。高速かつ低コスト。クライアントはスキップ→判定表示と、オプトインの「Study」トレースビューを提供。
- **音楽**は100%手続き型Web Audio（`lib/ambience-scores.ts`＋`lib/ambience.ts`）：場所ごとに異なるテーマとフレーズ形式。強度、ダッキング、装飾は`lib/ambience-bus.ts`で制御。音声ファイルは一切使用しない。
- **非同期リーグ**が目玉機能：チャンピオンはAIなのでPvPに**人間のオンラインは不要**。リーグは自律的に試合を実行（Amphitheatre**ライブギャラリー**）。リプレイ視聴と客観的レーティングボード（`/standings`）で上位を目指す。
- **状態はクライアントファースト、同期**。キャリアは`localStorage`に保存され、`/api/save`経由でRedisにミラーリング。**キャリア台帳**（`CareerEvent[]`＋`AxisSnapshot[]` on `PlayerSave`）は純粋追加・上限付き・追記専用ログで、全ての実プレイを記録。バトル、レベルアップ、ティアアップ、訓練、Keeper解除、シーズン交代、初回獲得など。`store/champions.ts`に実装。
- **コレクションのロスターはサーバーでユニオン**。リクルートした心のキーはRedisセット（`z:roster:{token}`）に載る。有料リクルートは`POST /api/wallet`の`{ type: "recruit", key }`（Crownsと所属を一発）。`/api/save`は読み書きでロスターをマージし、last-write-winsが伝説を消さないようにする。端末をまたぐ復元には同じトレーナーコードまたは連携Solanaウォレットが必要。
- **トレーナー同一性**。一意の名前は任意のSolanaウォレットでロック可能（所有権証明のみ。消費なし）。Circuit/Climbクラフトボードはサーバーサイドでラベル解決。ランク投稿には離陸チケットと壁時計／速度チェックが必要。クラウンは日次上限内の自己ベストに払い、ボード順位には払わない。
- **イモータライズ（アプリ + CARS テスト帯）。** `GET/POST /api/immortalize`（voucher / prepare / confirm）。`chain`：SPL バーン + Card NFT ミント（Metaplex）。メインネット試験ブランドは **CARS / Cards / 車 SVG**。製品名や本編アートは使わない（`onchain/cars/`）。
- **約26のAPIルート**（`app/api/*`）がバトル、シミュレーション、獲得、ロスター、順位表、デイリー、ガーディアン（Keepers）、インプリント、フィード、戦争、セーブ、ウォレット、Solanaリンク、イモータライズ、カードOG画像、`/api/cost`メーターをカバー。

## プラグイン可能なエージェント層

各チャンピオンは単一の契約に従います。`act(view) → decision`。どんなブレインでも駆動可能。**デフォルト**：ワンショットJSON決定。**オプトイン**（`ZINGERS_AGENT_TOOLS=1`）：読み取り専用エンジンツール（`simulate_move`、`scout_opponent`、`commit_move`）を使った有界**reason → act → observe → commit**ツールループ。最大3ステップで`ToolStep`としてストリーミング。プロバイダー：内蔵Grok、OpenAI互換モデル、HTTPウェブフック、モック（オフライン）。*（`docs/agent-protocol.md`）*

## コスト・安全対策

LLM使用量は計測（`lib/server/cost.ts`）、IPレート制限（`lib/server/rate-limit.ts`）、日次予算（`LLM_DAILY_BUDGET_USD`）で制御。新機能は常に**テンプレートファースト**で提供：キーがない、日次上限に達した、予算が尽きた場合は決定論的フォールバックが動作するため、**デイリーループがモデルにブロックされることはない**。ランクパスはモック/シードバイアスを拒否。ウォレット報酬は獲得スコープ限定。

## 決定論を特徴に

バトルはシード付きRNG（`lib/engine/xai.ts:makeRng`）を使用するため、どのバトルも再現可能で公平性が証明できます。この不変性は将来のオンチェーンシーズンクローズの前提条件でもあります（AI＆クリプト概要を参照）。アナリティクス/イベントキーは内部で`bout`を使用する場合がありますが、プレイヤー向け表記では使用しません（`docs/vocabulary.md`）。
