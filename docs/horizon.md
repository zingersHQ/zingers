# Horizon — post-launch continuing roadmap

> **Status: Proposed / internal.** Not a public commitment. Not registered on
> zingers.org. Companion to [`AGENCY.md`](../AGENCY.md) §Roadmap,
> [`zing-model.md`](./zing-model.md), [`bible/08-economy.md`](./bible/08-economy.md),
> [`growth-strategy.md`](./growth-strategy.md), [`long-game.md`](./long-game.md).
>
> Purpose: keep a **horizon after Launch v0.1** so success has a path, not a
> single crossroads. Phases unlock by traction and treasury, not by calendar.

This doc answers: *if Zingers works, and the token is how we monetize, what do we
keep doing next — and what options open later?*

---

## 1. Framing

**This game is Game One.** The web Flight-First loop (Climb / Circuit + raise +
fights as punctuation) is the first product. Everything else is earned by making
this one sticky, shareable, and fundable.

**Monetization bet (honest):** for an indie of this shape, **`$ZING` is the
realistic revenue path** once traction exists. Traditional IAP / App Store
subs are possible later but are not the spine we are building toward. The token
is fuel and standing ([`zing-model.md`](./zing-model.md),
[`bible/08-economy.md`](./bible/08-economy.md)): optional, never a gate to play,
never power, never yield. Crowns stay off-chain and never bridge.

**Collectibles (NFT / immortalized cards):** kept as a **later angle**, not the
launch story. They can become extraordinary *if* the IP is already loved and a
crypto-native audience shows up. They also exclude most players by default. So:
trophy case and provenance under the game, never the face. Mint-to-immortalize
in the economy bible is the right shape when we get there.

**Open-world sequel (Pokémon / Zelda scale):** not discarded, **not funded by
hope**. It is a horizon option if Game One generates real treasury and proof
that Trainers will follow the IP into a bigger body. Until then, depth stays in
this stack (run variance, seasons, creator economy) per [`long-game.md`](./long-game.md).

**Continuing, not forking.** Each phase below is "what we keep shipping when the
previous one is earning its keep." No single "do we go AAA or die" moment. The
franchise question only opens when the ledger says we can afford curiosity.

## 2. What "success" means before later phases

Rough internal gates (tune with real metrics; do not invent numbers yet):

| Gate | Signal we look for |
|------|--------------------|
| **Door works** | Cold → Take flight / Climb → claim is healthy; Climb feel playtests pass |
| **Bond retains** | Return flights / Imprints / season activity without paid push |
| **Shares work** | Climb challenge + bond cards drive cold opens (growth north star) |
| **Accounts exist** | Cloud persistence so legends survive devices |
| **Premium demand** | People ask for cosmetics / infinite battles / on-chain standing *before* we sell them |
| **Token follows** | Deploy `$ZING` when sinks and creator royalties have someone to serve |

Token after traction. Never traction after token.

## 3. Continuing spine (Game One)

Aligned with `AGENCY.md` phases. **CURRENT work stays Phase 4 ops → Phase 5.**

### Near — finish the product people already opened

| Phase | Horizon job |
|-------|-------------|
| **4 ops** | Playtests, ship notes, key art, growth push, moderation before fan-out |
| **5** | Collection depth: trading, user-made champions (creator moat). Roster follows Trainer identity. |
| **6** | Accounts + monetization rails: cosmetics, battle pass, infinite battles; `$ZING` when demand is real |

### Mid — seasons that fund the house

Once accounts + soft premium exist:

1. **Season machine.** Soft resets, Flight boards, body/sigil season marks, shareable recaps. Recurring ritual > one spike. Seasonal Flight boards refresh craft prestige; they are not attested proof-of-play and never gate hard purses or on-chain weight (see [`circuit-board.md`](./circuit-board.md)). Token/stakes stay on fight standings.
2. **Token live (opt-in).** On-chain standings entry (burn-or-stake), patron crests, airdrop weight for play. Still: no yield, no pay-to-win, Crowns wall intact.
3. **Creator royalties in `$ZING`.** User-made champions earn when adopted / fought. This is the durable moat bet.
4. **Inference product.** "Infinite battles" priced above measured marginal duel cost (`npm run cost`). Climb stays cheap; paid depth pays the LLM bill.
5. **Agent layer as distribution.** MCP / BYO ranked boards so committed players bring their own inference spend.

### Mid-late — collectible layer (only if the IP is already a thing)

Not required for monetization if token sinks work. Worth keeping as option B:

- **Mint-to-immortalize** career cards (art = deterministic body from record).
- Tradeable provenance for collectors; free game untouched.
- Optional limited drops only if crypto culture actually surrounds the game — never as the growth strategy for everyone else.

If collectibles never ship, the game can still be a success. They are upside on love + crypto adjacency, not the plan.

## 4. Far horizon — if treasury and love both exist

Three **options**, not a sequence. Pick by what Game One proved, not by vibes.

### Option A — Deepen this body (same stack, bigger world)

Spend money **inside** the current product: denser Grounds, more Reach identity,
Keeper arcs turned on carefully, House as Concord depth, better art pass,
native apps if the web loop is proven. Lowest risk. Same soul
([`essence.md`](./essence.md)): Flight face, champion as save file.

*Choose when:* retention and shares are strong but players ask for *more of this*,
not a different genre.

### Option B — Second game, same IP (open-world / console ambition)

A real 3D open world (Pokémon / Zelda-scale ambition): walkable Long Vault,
regions as places, Flight as traversal *or* as a mode, champions as companions
in space. New engine/team/budget. Game One remains the live service and
token/economy root; Game Two is the prestige body.

Rough shapes (ideas only):

| Working title | Pitch |
|---------------|--------|
| **Vaultwalk** | Grounded open world under the sky you already climbed. Concord is a real city. Regions are biomes you enter on foot. Fights and Flight are verbs in the world, not separate apps. |
| **Wingbound** | Open-sky adventure first. Contiguous flight world, camps and Keepers placed in space, battles as encounters on routes. Closest to "Zelda but you raise a mind." |
| **Legend Road** | Trainer journey across a map of arenas and Reaches; collection and raising are the spine; Flight is the travel fantasy between set pieces. Closest to "Pokémon with our bond." |

*Choose when:* `$ZING` + premium actually fund a multi-year build, and the IP is
recognized outside the current player base. Until then this is a sketch on the
wall.

### Option C — Franchise splinters (small, parallel)

Cheap experiments that reuse IP without AAA:

- Pure Flight score-chase (hyper-casual door, feeds back to full game).
- Spectate-first Live Gallery for streamers (depth, not face rewrite).
- Creator tooling as a product (forge minds, sell cosmetics/royalties).

*Choose when:* one surface is clearly outgrowing the others and deserves its own
store page / audience.

---

## 5. What never changes across the horizon

- **Flight is the face.** Growth and sequels still sell sky + bond first.
- **Engine authoritative; wit bounded.** No pay-to-win via token or cosmetics.
- **Crowns ↔ token wall.** Soft play money never becomes cash-out.
- **Token buys standing, access, permanence — never yield.**
- **Crypto optional forever** for the core loop.
- **IP + creator economy + evolving meta** are the moat, not the debate UI fad.

## 6. How to use this doc

- **Near-term planning:** ignore §4. Ship Phase 4 ops → 5 → 6.
- **Quarterly:** re-read §2 gates against real metrics; advance Mid only when gates clear.
- **When someone asks "are we doing the open world?":** point at §4 as options
  contingent on treasury + love; default answer is Option A until proven otherwise.
- **Public pitches:** do not promise Game Two or NFT drops. Keep
  [`TWOPAGER.md`](./TWOPAGER.md) / [`AI-CRYPTO.md`](./AI-CRYPTO.md) honest about
  deferred token and unfinished accounts.
